
## 🚀 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 拉取BTC最近30天1小时K线
python scripts/fetch_klines.py --symbol BTCUSDT --interval 1h --limit 720

# 3. 跑一个最简单的双均线策略回测
python scripts/backtest_demo.py

# 4. 看蒙特卡洛验证（策略是不是运气）
python scripts/monte_carlo.py
```
