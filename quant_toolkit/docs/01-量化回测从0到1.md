## 第1章：回测是什么，为什么必须做

### 1.1 定义

**回测（Backtest）** = 用历史K线数据，模拟一套交易策略在过去会怎么表现。

它回答三个问题：
1. 这个策略在过去赚钱吗？
2. 赚钱是**策略本身的能力**，还是**刚好碰对了行情**？
3. 如果实盘，我大概会经历多大的回撤？

### 1.2 为什么回测必须做

| 不做回测 | 做回测 |
|---|---|
| "我觉得会涨" → 下单 | 数据证明过去6个月该信号胜率38% |
| 亏了怪市场 | 提前知道最大回撤-40%，仓位管理有底 |
| 换一个策略继续亏 | 多策略对比，只留验证过的 |

**铁律：没有回测的策略 = 赌博。有回测的策略 = 有依据的赌博（至少知道赔率）。**

## 第2章：回测的6个环节

```
① 数据获取 → ② 指标计算 → ③ 信号生成 → ④ 仓位计算 → ⑤ 模拟执行 → ⑥ 评估
```

### 2.1 数据获取

**数据质量决定回测质量。** 垃圾数据 → 垃圾结论。

- K线字段：`[开盘时间, 开盘价, 最高价, 最低价, 收盘价, 成交量]`
- 周期选择：1h / 4h / 1d（新手从1h开始，不要用15m——信号太频繁，手续费吃死你）
- **数据必须新鲜**：超过7天没更新的数据 = 过期数据

免费数据源（无需API Key）：
- 币安公开接口：`https://api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=1h&limit=1000`

### 2.2 指标计算（示例）

```python
# EMA 指数移动平均
data['ema12'] = data['close'].ewm(span=12, adjust=False).mean()
data['ema26'] = data['close'].ewm(span=26, adjust=False).mean()

# RSI(14) 相对强弱指标
delta = data['close'].diff()
gain = delta.where(delta > 0, 0).rolling(14).mean()
loss = (-delta.where(delta < 0, 0)).rolling(14).mean()
data['rsi'] = 100 - (100 / (1 + gain / loss.replace(0, np.nan)))
```

### 2.3 信号生成

信号 = 指标的**决策规则**。规则必须**明确、可复现、无歧义**。

```python
# 双均线策略信号：EMA12上穿EMA26 → 买入(1)；下穿 → 卖出(-1)
data['signal'] = 0
data.loc[data['ema12'] > data['ema26'], 'signal'] = 1
data.loc[data['ema12'] < data['ema26'], 'signal'] = -1
```

**新手最常见的错误**：信号规则写得模棱两可（"感觉要涨了"不是信号）。

### 2.4 仓位计算（回测的灵魂）

**仓位比信号更重要。** 同样的信号，10%仓位和90%仓位结果天差地别。

| 参数 | 新手默认 | 建议 |
|---|---|---|
| 单笔仓位 | 全仓 | **≤10%** |
| 冷却期 | 无 | ≥20根K线（1h级别） |
| 止损 | 无 | **必须有**，5%起 |
| 止盈 | 无 | 15%左右 |
| 持仓超时 | 无限 | 72h强制平仓 |

**为什么必须有止损？**
> 实测教训：9个机构策略在30天1h K线上**全部返回-100%**——因为回测里"死扛不止损"，买入后价格一直跌到归零。止损不是可选项，是回测的基本盘。

### 2.5 模拟执行（手续费和滑点是隐藏杀手）

**回测必须计入交易成本，否则结果全部是虚的：**

```python
# 每笔交易都扣成本
buy_price = price * (1 + fee_rate) * (1 + slippage)   # 买入成本
sell_price = price * (1 - fee_rate) * (1 - slippage)  # 卖出成本
```

- 手续费：币安现货 taker 约 0.1%（合约0.04%）
- 滑点：主流币 0.02-0.05%，小币 0.5%+（小币滑点可能是大币的10倍！）

**实测数据**：手续费+滑点每年吃掉约 **6.5%** 收益。一个"年化8%"的策略扣完成本实际只有1.5%。

### 2.6 评估指标

| 指标 | 含义 | 健康值 |
|---|---|---|
| 收益率 | 总收益% | >0（废话但很多策略做不到） |
| 胜率 | 盈利交易占比 | >40% |
| 最大回撤 | 从峰值跌多少 | <20%（越大越拿不住） |
| Sharpe夏普 | 风险调整后收益 | >1 |
| 交易次数 | 样本量 | >50笔（太少不具统计意义） |

## 第3章：回测参数决定结果生死

**同一套策略，换个参数就是另一个策略。**

| 参数 | 错误设定 | 结果 |
|---|---|---|
| 15%仓位 + 每根K线都交易 | 8000+笔 | 2%胜率，全体亏损 |
| 10%仓位 + 20根K线冷却 | 500-800笔 | 42-45%胜率，正收益 |

**教训**：先验证引擎参数（仓位/频率/冷却）是否合理，再判断策略好坏。很多人骂"策略亏钱"，其实是**回测参数设置错了**。

## 第4章：新手必踩的坑（每一条都是真实学费）

### 坑1：单窗口回测 = 曲线拟合

**只用最近60天数据回测 → 结论不可信。**

实测：
- 某策略60天回测：均收益 **-0.10%**
- 同一策略4年回测：均收益 **+21.04%**（10x杠杆）
- 结论完全相反！

**正确做法**：至少跑 30d / 90d / 180d / 1y / 4y 多窗口。只在单一窗口赚钱 = 拟合历史，不是能力。

### 坑2：幸存者偏差（最阴险）

**"回测赚钱"可能是运气，不是策略。**

实测：某"冠军"策略表面 +3.47%，但用**蒙特卡洛打乱交易顺序**后，**正收益概率 = 0%** —— 收益完全是运气，顺序对了才赚。

**验证方法**：Bootstrap。把交易顺序随机打乱1000次，如果打乱后依然赚钱 → 策略有真本事；如果只有原顺序赚钱 → 纯运气。

### 坑3：杠杆反转效应

**杠杆不是简单放大收益，它会把亏钱策略变成"看起来赚钱"。**

| 策略 | 无杠杆 | 10x杠杆 |
|---|---|---|
| 策略A | -0.10% | **+21.04%** |
| 策略B | -1.65% | **-11.49%** |

10x杠杆把"亏损趋势策略"变赢家，把"均值回归"加速送死。**选实盘策略必须看杠杆下的结果 + 爆仓率。**

### 坑4：只看收益，不看爆仓率

某策略10x杠杆4年"高收益"，但**爆仓率96%**（48/50币爆仓）—— 实际早死透了。

**选策略双指标**：平均收益 + 爆仓率。收益高爆仓率也高 = 废策略。

### 坑5：单币高收益 = 幸存者偏差

"XX策略在AVAX上+1349%" —— **实盘你不可能预先知道是AVAX会涨**。

正确做法：跑 **50币种 × 多窗口**，看**平均收益**而不是单币最高收益。

### 坑6：把回测当实盘

**回测赚钱 ≠ 实盘赚钱。** 回测是历史，实盘是未来。
- 回测无心理压力，实盘-20%回撤你可能就手动平仓了
- 回测无宕机，实盘API可能挂
- 回测无滑点突变，实盘黑天鹅来临时流动性瞬间消失

**唯一可靠的验证链**：
```
回测多窗口正收益 → 最近30天模拟盘 → 虚拟盘7天 → 小资金实盘$50 → 逐步加码
```

## 第5章：完整评估流程（直接照做）

```bash
# Step 1: 数据新鲜度检查（<7天）
# Step 2: 跑回测（30d/90d/180d/1y/4y 六窗口，1x和10x双模式）
# Step 3: 蒙特卡洛Bootstrap验证（正收益概率 ≥95%）
# Step 4: 检查爆仓率（<20%）
# Step 5: 检查最大回撤（<50%）
# Step 6: 通过 → 进虚拟盘7天；不通过 → 回Step 2改参数
```

**通过条件（全部满足才考虑实盘）**：
- [ ] 多窗口平均收益 > 0
- [ ] Bootstrap正收益概率 ≥ 95%
- [ ] 爆仓率 < 20%
- [ ] 最大回撤 < 50%
- [ ] 胜率 > 35%
- [ ] 交易次数 > 50笔

**任何一条不满足 → 不上实盘。** 这个行业90%的亏损都源于跳过验证直接真金白银。
