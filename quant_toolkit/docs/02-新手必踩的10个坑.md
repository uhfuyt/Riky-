# 新手必踩的10个坑（真实学费换来的）

> 每一条都来自真实交易系统的迭代教训。看懂这10条，能帮你避开90%的弯路。

---

## 坑1：不做回测直接实盘 ❌

"我觉得BTC要涨"不是策略。**没有回测验证的策略 = 赌博。**

- 先回测 → 再虚拟盘 → 再小资金实盘
- 跳过任何一步，都是在给市场交学费

## 坑2：单窗口回测就下结论 ❌

只用最近30/60天数据回测 = 用一段行情代表所有行情。

**实测案例**：同一策略
- 60天回测：-0.10%
- 4年回测：+21.04%
- 结论完全相反！

✅ **至少跑6个窗口**：30d / 90d / 180d / 1y / 2y / 4y

## 坑3：幸存者偏差（最阴险，没有之一）❌

"回测赚了233%" —— 但可能只是**运气**。

**实测案例**：某策略表面+3.47%，蒙特卡洛打乱交易顺序后**正收益概率=0%**。
说明：收益是"顺序对了才赚"，不是策略本身有能力。

✅ **Bootstrap验证**：随机打乱交易顺序1000次，打乱后依然赚钱 = 真策略。

## 坑4：忽略手续费和滑点 ❌

回测不算成本 = 虚假繁荣。

**实测**：手续费+滑点每年吃掉 **6.5%** 收益。
"年化8%"的策略，扣完成本实际1.5% —— 连银行理财都不如。

✅ 每笔交易必须扣 `fee + slippage`，小币滑点按0.5%算。

## 坑5：全仓 / 重仓交易 ❌

全仓 = 一次判断错误就出局。

✅ 单笔 ≤10%仓位，止损5%，冷却20根K线。

## 坑6：没有止损 ❌

**实测**：9个策略没设止损，30天全部-100%（死扛到归零）。

✅ 止损不是可选项，是回测的基本盘。

## 坑7：只看收益排名，不看爆仓率 ❌

某策略4年"高收益"，但爆仓率96% —— 实际早死透了。

✅ 收益 + 爆仓率双指标：爆仓率>20%直接淘汰。

## 坑8：单币种高收益 = 幸存者偏差 ❌

"XX策略在AVAX上+1349%" —— 实盘你不可能预先知道是AVAX。

✅ 跑50币种看**平均收益**，不看单币最高。

## 坑9：杠杆当放大镜用 ❌

杠杆不是收益×N。**它会反转策略性质**：
- 亏损趋势策略 + 10x → 变成"+21%赢家"（假象）
- 均值回归策略 + 10x → "死亡加速"

✅ 选策略必须看**杠杆下**的回测 + 爆仓率。

## 坑10：回测赚钱就直接实盘全仓 ❌

回测是历史，实盘是未来。中间隔着：心理、宕机、滑点突变、黑天鹅。

✅ 铁律验证链：
```
回测多窗口正收益 → 30天模拟盘 → 虚拟盘7天 → 小资金实盘$50 → 逐步加码
```

## 🏁 一句话总结

> **回测是为了杀死坏策略，不是为了证明好策略。**
> 一个策略如果连严格的回测都过不了，实盘只会亏得更快。
