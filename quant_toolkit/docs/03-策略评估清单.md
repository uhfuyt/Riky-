# 策略评估清单（上实盘前的自查）

> 打印出来，每一条打勾。**全部通过才考虑实盘。**
> 任何一条不满足 → 不上实盘，先回炉。

---

## 📊 数据层

- [ ] K线数据新鲜（最后日期 ≤ 3天前）
- [ ] 数据来源可靠（币安官方API，非第三方爬虫）
- [ ] 数据覆盖至少6个窗口（30d/90d/180d/1y/2y/4y）

## 🧪 回测层

- [ ] 多窗口平均收益 > 0
- [ ] 无杠杆（1x）回测通过
- [ ] 10x杠杆回测通过（选实盘策略必须看杠杆下）
- [ ] 至少30个币种（不是只用4个）
- [ ] 交易次数 > 50笔（样本量够才有统计意义）
- [ ] 胜率 > 35%
- [ ] Sharpe中位数 > 0.5

## 🎲 验证层（防止幸存者偏差）

- [ ] **Bootstrap正收益概率 ≥ 95%**（打乱交易顺序后依然赚钱）
- [ ] 爆仓率 < 20%
- [ ] 最大回撤 < 50%
- [ ] 跨周期胜率 > 25%
- [ ] 单窗口TOP收益标注"疑似过拟合"（不做决策依据）

## 💰 成本层

- [ ] 手续费已计入（现货0.1% / 合约0.04%）
- [ ] 滑点已计入（主流币0.02-0.05%，小币0.5%）
- [ ] 成本后收益仍为正（不是"扣完成本就没了"）

## 🧠 心理层

- [ ] 最大回撤数值，我实盘扛得住（扛不住=仓位太重，减半）
- [ ] 连续止损3次，我不会手动干预
- [ ] 我明白"回测赚钱≠实盘赚钱"

## 🚀 实盘层（通过以上才到这里）

- [ ] 先在虚拟盘跑满7天（真实K线+真实手续费）
- [ ] 实盘首仓 ≤ 回测仓位的50%（安全垫）
- [ ] 首笔实盘 ≤ $50（试水）
- [ ] 连续3天正收益才考虑加码
- [ ] 写好了止损单（不是"心里有数"）

---

## 结论判定

| 勾选数量 | 判定 |
|---|---|
| 15+ 条通过 | ✅ 可以谨慎实盘（小仓位） |
| 10-14 条 | ⚠️ 回炉调参，重跑回测 |
| <10 条 | 🔴 这个策略还没准备好，别碰 |
