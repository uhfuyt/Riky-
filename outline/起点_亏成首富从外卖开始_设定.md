# 《亏成首富从外卖开始》— 核心设定

## 一、世界观

**现代都市·平行世界·2026年7月**

主角林北舟,28岁,前互联网大厂P7,被优化后欠下30万信用卡+20万网贷,妻子三个月前离婚,带着全部家当600块回到老家——一座三线小城「江城市」。

摆在他面前的只有两条路:送外卖,或者饿死。

**金手指触发**:在江城接下第一个外卖单的瞬间,他手腕内侧浮现一行半透明的数字——

> 【亏钱返利系统·已激活】
> 宿主:林北舟 | 等级:Lv.1
> 累计亏损:0元 | 累计返利:0元
> 规则:宿主每产生一笔「真实亏损」,返利10倍。
> 注:仅限合法商业行为。灰色/黑色亏损不计。

**核心反差**:所有人拼命赚钱,他必须拼命亏钱,才有钱赚。

## 二、金手指规则(铁律)

| 规则 | 说明 |
|---|---|
| **触发** | 任何商业行为产生的「净亏损」,亏1元返10元 |
| **返利倍数** | 随等级提升: Lv.1=10x, Lv.3=50x, Lv.5=100x, Lv.10=1000x |
| **等级提升条件** | 累计亏损金额达阈值(1万/10万/100万/1000万/1亿) |
| **限制** | 必须本人主导的商业行为;借他人名义不算 |
| **禁区** | 赌/毒/黄/骗/传销/洗钱等违法亏损不计 |
| **返利来源** | 系统生成,直接到账宿主个人银行账户 |
| **副作用** | 等级越高,"越想赚钱"的本能越弱,反之"越想亏"越强(Lv.5后性格改造) |

**金手指卖点**:不是无脑送钱,是「越亏越有」的反套路。读者和主角一起想办法亏钱,认知反差拉满。

## 三、主角人设

**林北舟·28岁**
- 性格:嘴贱、腹黑、心软、极度务实
- 口头禅:
  - "赚什么赚,我亏钱呢,别挡道。"
  - "您别买,真别买,求您了。"
  - "这单我赔本卖,谁劝我赚钱我跟谁急。"
- 缺陷:对前妻有执念(Lv.5之前);心软(Lv.3前容易被感情牌骗)
- 隐藏属性:前大厂P7的产品经理能力(数据敏感、用户洞察、商业嗅觉),这些能力用来"亏钱"反而无往不利
- 装备:一辆二手电动车、外卖服(系统赠)、一台破手机
- 觉醒标志:Lv.5后,看到"赚"字会生理性反胃,看到"亏"字会兴奋

## 四、爽点公式(每次爽的模板)

```
[困境/嘲讽] → 主角被迫要亏一笔钱 → 失败/意外 → 实际亏得更多 → 系统返利N倍 → 
围观者震惊 → 主角"嫌赚太多"吐槽 → 反派被打脸 → 章末更高目标钩子
```

**头三章必爽点**:
- Ch1: 第一单外卖,自掏腰包倒贴20,反获200
- Ch2: 老婆店搞活动送鸡蛋,他故意安排亏损套餐,日亏300,反获3000
- Ch3: 第一个大客户找茬,他故意赔偿500,反获5000

## 五、力量/财富等级表

| 等级 | 累计亏损 | 返利倍数 | 月入估算 |
|---|---|---|---|
| Lv.1 | 0-1万 | 10x | 几千 |
| Lv.2 | 1-10万 | 20x | 几万 |
| Lv.3 | 10-100万 | 50x | 几十万 |
| Lv.4 | 100-1000万 | 100x | 百万级 |
| Lv.5 | 1000万-1亿 | 200x | 千万级 |
| Lv.6 | 1-10亿 | 500x | 亿级 |
| Lv.7 | 10亿+ | 1000x | 十亿级 |

## 六、反派/配角生态

| 角色 | 身份 | 与主角关系 |
|---|---|---|
| **苏婉清** | 前妻,28岁,离婚后嫁给江城富二代 | 嫌贫爱富,但内心有愧 |
| **张德彪** | 外卖站站长,贪小便宜 | 给主角穿小鞋,被反复打脸 |
| **王大龙** | 江城首富之子,前妻现任丈夫 | 反复嘲讽,反复被打脸 |
| **何秀兰** | 母亲,58岁,不知主角现状 | 主角最大软肋 |
| **马化腾** | 系统本体(化名),只在Lv.10后露面 | 揭晓"系统为何选你" |

## 七、核心矛盾

1. **主线**:把"亏钱"做成全球最大的生意,亏成世界首富
2. **副线1**:修复母亲关系、重新赢得尊严
3. **副线2**:前妻回头追,主角不回头(爽点)
4. **副线3**:反派的连锁反应(从站长→首富之子→财阀→国际资本)
5. **隐藏线**:系统背后到底是谁?为什么选中一个被优化的loser?
