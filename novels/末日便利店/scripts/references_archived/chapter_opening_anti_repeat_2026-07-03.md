# 章节开头反重复铁律(2026-07-03 焊死)

> **触发场景**: 用户在批改番茄Ch1-Ch3开头时,3次强调
> **用户原话**:
> - "番茄Ch1-Ch3前面内容开头都是7月深圳,早上热,中午热,晚上热"
> - "内容要有逻辑"
> - 起点Ch3-Ch6开头"都是7月1,2345日"——同日复一日

## 🚨 根因诊断

我犯了**双重失误**:
1. **同质化复读**: 番茄Ch1-3全部都用"七月的深圳+X热"开头,只替换时间词,触发"AI味重"判定
2. **日期开头**: 起点Ch3-6都是 `2026年7月4日,早上7点`/`7月4日,早上9点10分`/`7月5日,早上8点40分`/`7月6日,中午12点` 模式,跟自己焊死的"章节开头7禁铁律"——禁日期——背道而驰

**核心bug**: 我加了铁律+detector,但 **detector 跑的是单章**, 没检测"跨章开头模式重复"。

## 🧪 教训:detector 必须3层

| 层 | 检测什么 | 谁负责 |
|---|---|---|
| **L1 单章内** | 1章内有没有日期/作者注/数据卡 | `_check_opening_format()` |
| **L2 跨章对比** | 连续2-N章开头模式/句式/场景是否雷同 | **本参考新增** |
| **L3 双书对比** | 起点vs番茄是否雷同(15维自查表已涵盖) | `双书差异化公式_15维自查表` |

**L2 跨章开头重复检测清单**:
- 抓取所有已发布章节的开头第2-3句(L1标题之后)
- 计算两两相似度(Jaccard / Levenshtein)
- > 0.6 相似度 = 报警
- 重点盯: 同句式("七月的X,Y热"——只换时间词)、同场景(连续N章都是同地点)、同感觉("热气/冷气/味道"反复出现)

## ⚡ 写作前3问(避免同质化)

1. **本章节的"地理锚点"是什么?** (跟上一章不同?)
2. **本章节的"开场动作"是什么?** (跟上一章不同?)
3. **本章节的"第一句句式"是什么?** (跟上一章不同?)

任何2项相同 = 必须重写开头。

## 🚫 5种最常见重复陷阱

| 陷阱 | 反例(番茄Ch1-3) | 改法 |
|---|---|---|
| **同句式只换时间** | "七月的深圳,X也热" (Ch1/Ch2/Ch3三次) | 删环境描写,改场景动线 |
| **同场景跨章** | Ch1在便利店/Ch2在便利店/Ch3还在便利店 | 每章必换场景类型(车站/夜市/华强北/出租屋/会所) |
| **同感官词复用** | "热气蒸得人眼前发白" (Ch1)/"夜里也热" (Ch2) | 换感官词:声音/气味/触感/光线 |
| **同情节开头** | 3章都是"主角看手机"开头 | 换动作:前章吃了/这章被问/下章发现 |
| **同角色开口** | 3章都是"钱小宝问行舟" | 主角不一定要对话开头,可以让环境/物品 |

**章节名风格总结**:
- 2-8字核心词
- 4种类型轮换: 系统/产品名 + 场景反转 + 人物动作 + 惊讶反转
- **没有日期开头**(反向证实我们git Ch3-Ch6的"7月X日"是模仿错位)

## ✅ 总结

**焊死铁律**:
1. 跨章开头句式必须异,相似度 < 0.6
2. 同质化20种模式至少每卷循环用5种,避免单模式成瘾
3. **写作前3问必跑**(场景/动作/句式)
4. detector L2 跨章对比 = 新增,跑前 N-1 章对比当前章第2-3句
5. 番茄/起点章节名风格=模仿原作2-8字简洁+4种类型轮换,不发明
