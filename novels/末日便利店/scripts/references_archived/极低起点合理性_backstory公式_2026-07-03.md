# 极低起点合理性 — backstory 公式(2026-07-03 焊死)

> 用户原话:"卡里就5块钱,还全花了买表,合理么?"
> 触发场景:任何"穷小子+金手指"类开篇,主角启动资金 ≤ 主角最低生存成本(月租+吃饭+交通)

## 病根:番茄Ch1 旧版踩的坑

| 层级 | 旧版(不合理) | 新版(合理) |
|---|---|---|
| 现金 | 卡里 5 块 | 卡里 5 块 |
| 来源 | 无交代 | **3年前父亲临终前留下5万 → 主角21岁挥霍3年 → 剩5块** |
| 全部花光风险 | 5块买表后卡里 0 → 当天饿死 | 5块买怀表后卡里 0 → 但怀表是父亲遗物,有情感重量 |
| 读者共情 | "穷鬼买表是不是傻" | "父亲留下的最后一点念想" |
| 反常识钩子 | 无 | **挥霍3年败光5万的过程 = 21-24岁主角浮沉三幕**(网贷/信用卡/赌球/被前女友坑/中介骗) |
| 与F001伏笔勾 | 无 | **怀表是父亲3年前临终前一天"欠父亲的人"送的**(保留 bible F002 神秘人伏笔) |

**读者第一反应对比**:
- 旧: "这人是不是傻?买完表饿死谁看?"
- 新: "父亲临走前留下的...我哭死"(情感钩)+ "3年怎么败光5万的?" (悬念)

---

## 通用公式:任何"低起步金手指"开篇必查4项

**触发条件**: 主角启动资金(卡里余额) ≤ 城市最低月租 × 1.5

立刻反查4项:

| # | 反查 | 合格标准 | 不合格反例 |
|---|---|---|---|
| 1 | **资金来源交代** | 必须 1-2 句话说明卡里 X 块从哪来 | "卡里5块钱"无说明 |
| 2 | **"花光"风险评估** | 主角全花光后能活 ≥ 7 天(借宿/赊账/蹭饭任一) | 主角花光后卡里0+无下家=当天饿死 |
| 3 | **情感钩子** | 钱是"别人的血/情" = 共情buff | 卡里5块=无来历无名=读者无感 |
| 4 | **悬念钩子** | 主角败光/欠债的具体故事 = 后续可挖 | 卡里5块=结束 = 没故事可讲 |

**4项全填齐 = "极低起步合理性 OK";任一空缺 = 必须返工**

## 3个 backstory 模板(可直接套用)

### 模板A:父亲遗产 + 挥霍败光(适合 男频爽文 + 父仇线)

```
卡里X块 = 3年前父亲"病逝"前留下最后一笔钱(金额5万-100万均可,主角21-24岁拿到)
3年挥霍过程 = 网贷/信用卡/赌球/前女友/中介/朋友骗 (列5-7个真实败光方式)
怀表/金手指 = 父亲临终前一天"欠父亲的人"送的 (保留神秘人伏笔=后续F002回收点)
怀表内部 = "别怕花钱/亏得其所"等父亲遗言,让金手指具备情感合法性
```

**为啥有效**:
- 父亲遗产=情感钩(番茄读者爱哭父仇)
- 挥霍3年=反常识钩(读者会想"怎么败光的?")
- 怀表是遗物=金手指跟情感绑定(不是无来源的"系统降临")
- 神秘人保留=伏笔链不断(bible F002 = 第2卷中段回收)

### 模板B:被骗光了 (适合 都市逆袭 + 反派线)

```
卡里X块 = 3年前合伙人/亲戚/前妻卷走所有积蓄(本金50万-500万)
现在X块 = 主角讨债/被骗光后剩的生活费
金手指 = 神秘转账/先祖账户激活/买到传家宝等
```

**为啥有效**: 反派钩子前置(读者想"谁骗的他?报仇!"),神秘金手指抵消"被骗"挫败感

### 模板C:攒了N年 (适合 生活流 + 现世安稳基调)

```
卡里X块 = 主角N年攒下的血汗钱(外卖员3年攒5万 / 工地5年攒20万)
怀表/金手指 = 主角买的第一件奢侈品 / 老家祖屋翻出来的
```

**为啥有效**: 真实感max(读者会觉得"我也攒不下来这么多"),但爽感最低,慎用

## 反例(必避)

❌ **"卡里5块钱"无来源直接开始** — 番茄Ch1 旧版踩过,读者第一反应"这人是不是傻"
❌ **"父母早亡+没积蓄+没朋友"全debuff** — 主角没人帮=读者没法共情
❌ **"卡里100万,但我偏要装穷"** — 起点老套路,读者一眼看穿,失去代入感
❌ **挥霍过程只写"网贷/信用卡"模糊带过** — 必须列5-7个**真实败光方式**,这种"细节堆"是网文读者最爱的"我也经历过"
❌ **怀表直接是"系统降临"** — 失去情感合法性,主角跟怀表没关系,读者不会为怀表激动
❌ **怀表是父亲"作品/手艺"** — 不是系统,跟金手指机制矛盾

## Ch1 落地示范(番茄《破财转运牌》B方案,2026-07-03 终版)

**幕一·开场**(~500字):
```
七月的深圳,热得像蒸笼扣在脑袋上。
顾行舟拖着二十寸旧行李箱,从罗湖火车站走出来。
屏幕上显示一条短信:【工商银行】您尾号7788账户余额5.00元。
他卡里5块,被200家公司拒,欠15万。
兜里那5块,是3年前父亲"病逝"前银行账户里剩下的最后一笔钱。
父亲临终那天人在深圳医院,卡里一共5万 —— 普通工人一辈子的积蓄。
母亲当时没告诉他,怕他扛不住。
他21岁那年从亲戚手里接过那张卡,卡里只剩5万。
三年,挥霍光了。
网贷,信用卡,赌球,买教训,交学费,被朋友骗,被前女友坑,被中介耍——
卡里那5万,一块一块地花出去,花到最后,就剩5块钱。
"爸。您留给我的那5万,我花光了。
但您留给我的另一样东西,我一直带在身边。"
他摸了摸行李箱最底层。
一个旧包裹,牛皮纸包着,没拆封。寄件人:顾建国。日期:3年前。备注:"等我走了再拆"。
```

**幕二·拆包裹 + 系统激活**(~500字): 父亲临终前一天,有个戴帽子的男人来过病房,跟父亲聊半小时,怀表是"欠父亲的人"给的。3天后主角发现包裹,没敢拆。今天拆,父亲信里说"别怕花钱,爸在天上看着你"。

→ 配合 bible F002伏笔"怀表来源" + F001伏笔"父亲3年前死因"双回收线

## 自检 Checklist (写完 Ch1 后必过 4 项)

- [ ] 卡里X块的来源 1-2 句话说明了吗?
- [ ] 主角花光后能活 ≥7 天吗?(借宿/赊账/蹭饭任一)
- [ ] 主角跟怀表/金手指之间有情感连接吗?(遗物/被骗回/救命稻草)
- [ ] 怀表/金手指来源是"父亲+神秘中间人"两层结构吗?(若直接是系统,失去 F002 伏笔回收)
