## 🎯 核心原则(升级到5条)

1. **题材方向同** — 都是"亏钱返利",读者群体能接受
2. **金手指机制根本不同** — 不能只改倍数,要从底层逻辑区分
3. **主角/城市/反派全独立** — 角色不能重名,伏笔不能互窜
4. **节奏按平台算法定制** — 起点追完读,番茄追钩子密度
5. **2026-07-03新增:已上传章节锁死原则** — 一端已发布的角色名/系统名,另一端必须**完全避开**,差异化只能在未发布端做

## 🚨 起点已上传锁死约束(2026-07-03 焊死)

**现实**: 起点Ch1-3已发布/上传,角色名/城市/系统名锁死,**改不了**。

### 决策树

```
"起点X章想改"
  → 已发布? 是 → 锁死,改另一端(番茄)
  → 未发布? 但Ch1-3已发布 → 锁死(关联约束)
  → 未发布 + 单独章节 → 可改,但要保持与前文一致
```

### 允许/禁止清单

| 操作 | 是否允许 | 原因 |
|---|---|---|
| ❌ 改起点Ch1-3角色名 | **绝对禁止** | 已发布,改=数据错乱+读者发现篡改 |
| ❌ 改起点系统名 | **绝对禁止** | 同上 |
| ✅ 改番茄全套 | **必须** | 番茄还没出,完全可塑 |
| ✅ 重做起点4-7章(同人物名) | **允许** | 还没发布,人物名不变,只重做剧情 |
| ✅ 起点设定/bible/大纲(同人物名) | **允许** | 内部文档,不影响发布 |
| ✅ 起点数字曲线调整(20x→30x→50x平滑) | **允许** | 内部一致性,不影响已发布内容 |

## 🆕 番茄新机制 v2(2026-07-03)

### 1. "花得冤"判定

```
普通花销(吃饭/交通/日常):不触发返利
商业花销(开店/雇人/捐赠):触发返利
"花得冤"加乘:花出去的钱"被身边人劝阻但主角偏要花" → 返利×1.5
```

### 2. 24h日清零机制

```
每日24:00结算:
- 当日"花出去的钱" < 当日"应花额度" → 差额部分返利扣50%(惩罚)
- 当日"花出去的钱" ≥ 当日"应花额度" → 正常返利
- 当日"花出去的钱" > 当日"应花额度" 50%以上 → 触发"超额奖",返利×1.5

"应花额度" = 前一日主角现金的 10% (动态调整)
```

### 3. "劝你省钱"副作用(Lv.2解锁)

```
Lv.2解锁后,主角身边的NPC开始"不自觉地劝主角省钱":
- 死党钱小宝:"哥,这餐厅太贵了,咱们去路边摊吧"
- 女主程晚棠:"行舟,你钱够花吗?我去做个兼职"
- 母亲宋桂枝:"儿啊,妈给你织了毛衣,别买新的了"
- 员工:"老板,这个供应商报价太高,我找了个便宜的"

→ 主角必须"反向操作"(花更贵的/拒绝省钱建议)才能维持返利
→ 喜剧冲突 + 推动剧情(主角得跟身边人"斗争")
```
