## 一、短剧 vs 普通网文 核心差异

| 维度 | 普通网文 | **番茄短剧** |
|---|---|---|
| 单章字数 | 4000-4400 (3200-4800 灵活) | 同左, **但下限更紧** (首章必满 4000) |
| 头三章爽点数 | ≥4 | **≥6** (短剧生命周期短, 前 3 集定生死) |
| 章末钩子 | 主+副+暗 (可平收) | **强反转/揭秘/惊吓 三选一** (断在动作点) |
| 视觉化 | 可选 | **必须** (每章≥3 项视觉锚点) |
| 名台词 | 鼓励 | **每章≥2 句** (能被短剧演员吼出来) |
| 节奏 | 可铺垫 | 每集必爆, 不许连续 2 集无高潮 |
| 单章结构 | 五幕可拆 | **必须内部闭环** (觉醒→战→升级→下集预告 全章完成) |

**核心**: 短剧首章 = 1 集, 必须自带 "全季预告" 感, 读者看完想刷下一章

## 二、首章 5 幕结构 (短剧版)

> 与普通玄幻同, 但 **幕五"钩子反转"必须能拍出"下集预告"画面**

| 幕 | 字数 | 短剧特定要求 |
|---|---|---|
| 幕一·开场冲突 | 500字 | 数字锚点 (余额/修为/寿命) + 即时危机 (死人/被追杀/反派上门) |
| 幕二·规则铺陈 | 500字 | 系统/金手指一次性说清, **不可跨集铺垫** |
| 幕三·试探验证 | 500字 | 第一次实战, **不许只试不战** (必须有结果) |
| 幕四·第一爽点 | 500字 | 数字 + 视觉 + 台词齐爆 (≥3 项视觉锚点) |
| 幕五·强反转 | 500字 | **下集预告点**: 反派出场 / 神秘线索 / 断在高潮 |

## 三、视觉化写作清单 (每章≥3 项)

### ✅ 必带

- **特效元素**: 金光/雷光/血雾/符箓燃烧/剑气冲天
- **动态描写**: 衣袂飘飞/剑气撕裂/风沙卷起/爆炸气浪
- **五行相克视觉化**: 金克木 (剑气斩藤蔓) / 水克火 (冰封火焰) / 火克金 (锻金熔化)
- **角色外貌锚定**: 身高/服饰/标志性物件 (短剧选角必需)

### ❌ 避免

- 长段心理独白 (>100 字) — 短剧拍不出
- 纯环境描写无人物 — 短剧必须有动作
- 时间跳跃不交代 — 短剧不能跳轴

---

## 四、名台词库 (每章≥2 句, 短剧适配)

每句必须满足: **≤15 字**, **可独立成镜头**, **有冲击感**

| 类型 | 模板 |
|---|---|
| 反派嘲讽 | "蝼蚁也敢妄言天道?" |
| 主角装比 | "我已让步三次, 这次不会了。" |
| 反杀前 | "既见 X 剑, 何须再问人间?" |
| 觉醒金句 | "这血脉...竟是 X?" |
| 钩子型 | "月光下, 一道从未见过的人影, 站在巷口。" |

**验收**: 每句能被短剧演员吼出来, 不超过 15 字, 不分两行

---

## 五、章末反转三件套 (短剧下集预告专用)

| 类型 | 用途 | 范例 |
|---|---|---|
| **反转型** | 主线剧情急转 (人设/阵营/规则反转) | "他说他不杀凡人, 但三日后他屠了一城。" |
| **揭秘型** | 一次性揭露关键信息 (身世/阴谋/线索) | "那道身影的轮廓, 是他死去二十年的父亲。" |
| **惊吓型** | 上一秒安全下一秒危机 (断在高潮点) | "他刚松了口气, 门被敲响了。门外, 是他师父的人头。" |

**铁律**: 短剧章末 **不许用** "且听下回分解" / "第二天清晨..." 等传统结尾, 必须断在动作点

## 六、章节 → 短剧集 拆条模板

每章交付时, **在章节正文后附"短剧集 N 拆条"**:

```
第 N 集拆条:
  镜头 1: [1 句话概述]
  镜头 2: [1 句话概述 + 特技需求 (CGI/特效动作/后期)]
  镜头 3: [...]
  下集预告: [一句话悬念]
```

### 本会话实证 (《剑荡红尘》Ch1)

```
第 1 集拆条:
  镜头 1: 沈回深夜读旧书 (铺垫)

  下集预告: "他踏入清风观, 却不知暗处有人已等他千年"
```

## 七、检测器误报豁免清单 (短剧/系统文特定)

> 跑 `check_dash_stack_v6.py` / `check_4dim.py` 时, 以下为已知误报, **不算 bug**:

| 检测器报告 | 误报原因 | 豁免理由 |
|---|---|---|
| 系统提示×N 次 | 短语重复 | 系统文必须高频出现 (设定需要) |
| 看着/盯着×N | 信号词超标 | 战斗章视觉焦点必需 |
| 主角名×N | 主角中心过重 | 首章合理, 后续降低 |
| 5 行破折号堆 | 短句堆积 | 战斗急促节奏需要 |
| 对话占比 <10% | 嘴炮缺失 | 短剧/玄幻战斗章特性 |
| 长叙事段 <3 段 | 场景段太少 | 纯战斗章允许 |
| wc 3993/4046 | 字数偏少 | 4000±20% 区间内, 算达标 |

**判定原则**: 检测器是工具, 不是合格证。误报豁免后真实问题才需要修

## 八、多本并行目录结构 (开新坑模板)

```
~/.hermes/mempalace/novel/
├── qidian/                  # 起点已有书 (独立 .git)
└── <新书拼音>/              # 新书独立目录
    ├── .git/                # 独立 git, 不混 history
    ├── bible/               # 设定圣经 + 金手指公式
    ├── outline/             # 卷一细纲 + Day-N 时间线
    ├── chapters/            # 章节正文 .md
    ├── dist/                # 纯文本 .txt (用户复制用)
    ├── scripts/             # 检测器副本 (cp 自 web-novel-production/scripts)
    ├── drafts/              # 重写/废弃稿
    ├── logs/                # 运行日志
    └── .gitignore           # dist/ logs/ .pyc 忽略
```

**铁律**: 每本小说 **独立目录 + 独立 git**, 绝不共用 history; 跨书引用走 Skill 圣经引用机制, 不复制粘贴
