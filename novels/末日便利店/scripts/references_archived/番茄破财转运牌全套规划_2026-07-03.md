## 🆕 番茄新规则5条

### 1. "花得冤"判定(铁律)
- ✅ 商业投资失败 / 进货被坑 / 请客被宰 / 捐款 / 投资朋友失败项目 / 高于市价买东西
- ❌ 日常吃饭 / 房租水电 / 交通通勤 / 个人消费 / 赌博(灰色)

### 2. 24h日限额(逼花钱)
- Lv.1: 1万/日
- Lv.2: 10万/日
- Lv.3: 100万/日
- Lv.4: 1000万/日
- Lv.5: 无限
- **花不出去当日额度清零** = 反向逼主角天天破产

### 3. Lv.3身边人"帮省钱"副作用
- 同事主动"帮主角省钱"(少点外卖/少打车)
- 朋友主动"帮主角省钱"(AA制/不收礼)
- 员工主动"帮主角省钱"(拒绝加班费)
- **核心冲突 = NPC 反向施压, 主角必须说服/欺骗/绕过他们才能花冤钱**

### 4. 旧怀表"特殊能量"维护费
- 系统每月扣1%返利资金作为"保管费"
- 怀表每月需要"特殊能量" = 主角必须继续花冤钱才能"养活"它
- 双重逼花机制

### 5. 数字曲线(防通胀, 与起点差异化)
- Lv.1: 5块→几天内过万 → 卷一资产过**百万**
- Lv.2: 500x → 卷一中段**千万**
- Lv.3: 1000x → 卷一中末**亿**
- Lv.4: 5000x → 卷二**百亿**
- Lv.5: 10000x → 卷三**万亿**

起点是 10x→200x→1000x;番茄是 200x→500x→1000x→5000x→10000x
