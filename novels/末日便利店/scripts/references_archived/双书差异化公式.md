# 双书差异化公式 — 同题材双本独立设计模板

[DS-0] 2026-07-03 已验证实例。**用于**: 同题材方向(亏钱返利/重生/穿越等)在起点+番茄双发时,如何做到"两本书互相独立、互不污染、给两个算法不同口味"。

---

## 🎯 核心原则

1. **题材方向同** — 都是"亏钱返利",读者群体能接受
2. **金手指机制不同** — 不能只是改个倍数,要从底层逻辑区分
3. **主角/城市/反派全独立** — 角色不能重名,伏笔不能互窜
4. **节奏按平台算法定制** — 起点追完读,番茄追钩子密度

---

## 🔑 关键差异化点(怎么"不同")

### 1. 金手指机制根本不同

**起点 = 渐进式升级**:
- Lv.1=10x → Lv.2=20x → Lv.3=50x → ...
- 读者追"什么时候升级"
- 主角是从"穷人→中产→富豪"渐进

**番茄 = 固定高倍数**:
- 10000x固定,无升级
- 读者追"还能多离谱"
- 主角是从"穷人→神豪"瞬间跳跃

### 2. 数值量级根本不同

**起点Lv.1**: 亏200 → 返2000(10x) → 主角"卧槽"
**番茄Lv.1**: 刷1块矿泉水 → 到账10000(10000x) → 主角"卧槽"

**起点Lv.3**: 亏50万 → 返2500万(50x)
**番茄Lv.1**: 一顿饭19.6万 → 到账19.6亿(10000x)

番茄数字量级天然比起点高2-3个数量级(因为番茄读者喜欢"夸张",起点读者喜欢"渐进")。

### 3. 女主类型不同

**起点**: 前妻(回头被拒型,情感张力在"拒绝")
- 主角拒绝复婚
- 反派是前妻现任
- 爽点:打脸前妻+打脸反派

**番茄**: 新女主(被家族扫地出门型,情感张力在"救赎")
- 主角收留女主
- 反派是女主家族的仇人
- 爽点:打脸反派家族+和女主日久生情

**不能两本都用前妻回头** — 读者一眼看穿"换皮"。

### 4. 反派规模不同

**起点**: 本地首富之子(地方型,势力范围江城)
- 反派能调动的资源有限(王氏建材城)
- 主角用本地律师+本地老板反击

**番茄**: 魔都金融世家(资本型,势力范围全国)
- 反派能调动百亿级资本(周氏金融集团)
- 主角需要更复杂的反击(可能是国际资本)

**两本反派规模要差一个量级**,否则两本看着没区别。

### 5. 伏笔必须完全独立

**起点伏笔**:
- F001 = 系统为什么选我(AI本体伏笔)
- F002 = 女儿暖暖
- F003 = 王大龙"马总"关系网
- F004 = 母亲收到神秘汇款
- F005 = 王小川大学室友

**番茄伏笔**:
- F001 = 父亲3年前死因(父仇线)
- F002 = 黑卡来源("欠父亲的人")
- F003 = 苏晚晴被家族扫地出门原因
- F004 = 母亲真实身份

**严禁两本共享伏笔** — 即使父仇线听起来相似,起点和番茄的"父亲"必须是两个完全不同的人,伏笔编号也不能复用。

## 🚫 反例(必避,踩过的坑)

### ❌ 错例1:复制起点 codex 改 title 初始化番茄
```python
# ❌ 错误:这样初始化番茄
import json, shutil
qidian_codex = json.load(open('books/qidian/codex.json'))
fanqie_codex = qidian_codex.copy()
fanqie_codex['title'] = '全球神豪'  # 只改标题
json.dump(fanqie_codex, open('books/fanqie/codex.json', 'w'))
```
**为什么错**: 起点伏笔/角色/规则会污染番茄,写番茄Ch3时AI会自动调起起点的"王大龙"角色 → 角色串戏。

### ✅ 正解
```python
# ✅ 正确:从零初始化
data = codex.init_book('fanqie', title='全球神豪', author='林北辰', platform='fanqie')
data['rules'] = {'trigger': '...', 'base_multiple': 10000, ...}  # 全新规则
data['characters'] = [...]  # 全新角色,不能与起点重名
data['hooks'] = []  # 全新伏笔,新编号
codex.save_book('fanqie', data)
```

### ❌ 错例2:两本都用"林北舟"
- 起点 `林北舟` 28岁 P7
- 番茄 `林北辰` 24岁 应届生

**为什么错**: 同一个姓 + 读音相近 → 读者(尤其是番茄算法)会判定为"换皮",降权。

### ✅ 正解
- 起点 = `林北舟`(成熟男人名字)
- 番茄 = `林北辰`(年轻人名字,带"辰"字寓意星辰)
- 两本名字首字不同,姓氏虽然都是"林"但**名字完全不同**

### ❌ 错例3:两本都用"亏钱返利系统"金手指
- 起点 `Lv.1=10x` + 升级机制
- 番茄 `固定10000x` + 无升级

**为什么错**: 金手指名字一样 + 都是"亏损→返利" → 读者一眼看穿"换皮不换核"。

### ✅ 正解
- 起点 `亏钱返利系统`(AI主动给出的系统,主角无法拒绝)
- 番茄 `神秘黑卡`(父亲遗产,主角以为是诈骗)
- 金手指"形态"不同(主动系统 vs 被动黑卡),底层逻辑也不同(升级 vs 固定)

## 💡 何时用这个模板

- 用户说"双发起点番茄"
- 用户说"同题材两本"
- 用户说"番茄再开一本"

**先问自己**: 这本跟已有书的差异化点是什么? 同方向但**底层机制不同**才是合格的差异化。
