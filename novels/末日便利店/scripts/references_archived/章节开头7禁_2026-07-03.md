## 7禁清单(任何一章产出必查)

| # | 禁 | 错误例子 | 正确做法 |
|---|---|---|---|
| 1 | **禁日期开头** | `2026年7月4日,早上7点。` / `7月3日,早上7点10分` / `周一夜里` | 用感官/动作/冲突开场:`七月的江城,热得像蒸笼扣在脑袋上。` / `苏婉清走的那天夜里,林北舟一单都没再送。` |
| 2 | **禁章节内【本章数据】块** | ```- 字数: 约2400字\n- 时间: 7月1日(第1天)\n- 五幕: ...``` | 数据卡**只放细纲**,正文不放 |
| 3 | **禁【下一章预告】段** | `第二章《5万的路边摊》:` / `## 【下一章预告】第二章《...》` | 钩子**自然嵌入对话/场景**,不用方括号剧透 |
| 4 | **禁"## 章节名+分隔线"** | `# 5块钱的怀表\n\n2026年7月1日\n\n---` | 第一行直接进场景:`七月的深圳,热得像蒸笼。` |
| 5 | **禁方括号剧透** | `[DS-0 备注]` / `[F001 回收]` / `[审核]` | 内部审计放单独 audit 文件,不放章节正文 |
| 6 | **禁元叙述** | `本章数据:` / `五幕:` / `字数:` / `爽点:` | 番茄/起点读者看不到后台, 编辑看的是第一章正文, 也别加 |
| 7 | **禁开篇大段 setup** | `故事发生在2024年的深圳,这一年...` / `话说...` / `背景:` | 第一句必须**有动作/冲突/钩子** |

## 8条正则 pattern (用于 detector 和 bulk-clean)

```python
import re

OPENING_FORBIDDEN = [
    # 1. 日期开头 — 锚定行首
    (r'^\s*\d{4}年\d{1,2}月\d{1,2}日', '日期开头 (YYYY年MM月DD日)'),
    (r'^\s*\d{1,2}月\d{1,2}日[^\n]*?(早上|上午|中午|下午|晚上|夜里|凌晨|晚)', '日期开头 (M月D日 + 时段)'),
    (r'^\s*\d{1,2}月\d{1,2}日', '日期开头 (M月D日)'),
    (r'^\s*周[一二三四五六日天]', '日期开头 (周X)'),
    (r'^\s*\d{4}\.\d{1,2}\.\d{1,2}', '日期开头 (YYYY.M.D)'),
    # 2. 【本章数据】块 / 3. 【下一章预告】段 / 6. 元叙述
    (r'【本章数据】|【数据卡】', '作者注/数据卡'),
    (r'【下一章预告】|【下章预告】|第[一二三四五六七八九十]+章《', '下一章预告剧透'),
    (r'本章数据[:：]|五幕[:：]|字数[:：].*?\d+|爽点[:：].*?\d+|钩子[:：].*?\d+', '元叙述'),
    # 4. 章节名+分隔线
    (r'^# .+\n\n---', '章节名+分隔线格式'),
    # 5. 方括号剧透
    (r'\[DS-0[^\]]*\]|\[F\d{3}[^\]]*\]|\[备注[^\]]*\]|\[审计[^\]]*\]|\[回收[^\]]*\]', '方括号剧透'),
    # 7. 开篇setup
    (r'^\s*故事发生在|^\s*这是一[个段]|^\s*背景[:：]|^\s*话说', '开篇setup'),
]

def check_opening_format(text):
    issues, score = [], 100
    for pattern, label in OPENING_FORBIDDEN:
        if re.search(pattern, text, re.MULTILINE):
            score -= 25
            issues.append(label)
            # 每个label只算一次(同label可能match多次)
            break
    score = max(score, 0)
    failed = score < 60
    return score, issues, failed
```

**score 评分规则**:
- 100 起,触发任一 `-25`
- 触发2条 `-50`(小于60 → FAIL)
- 触发3条及以上 `0分 → FAIL`

## Bulk-clean 脚本起点 Ch1-6(仅做参考 — 用户已接受锁死)

如果未来用户同意清理已上传章节的违规,运行:

```python
import re, glob

CLEAN_RULES = [
    # 删第1-3行任何"日期"行(在标题之后)
    (r'^(\s*\d{4}年\d{1,2}月\d{1,2}日[^\n]*\n)', ''),
    (r'^(\s*\d{1,2}月\d{1,2}日[^\n]*\n)', ''),
    # 删【本章数据】整段
    (r'\n*##\s*【本章数据】\n.*?(?=\n##\s|\n#\s|\Z)', '', re.DOTALL),
    # 删【下一章预告】整段
    (r'\n*##\s*【下一章预告】\n.*?(?=\Z)', '', re.DOTALL),
    # 删正文里的"[DS-0...]"等元标记
    (r'\[DS-0[^\]]*\]', ''),
    (r'\[F\d{3}[^\]]*\]', ''),
]

for fp in glob.glob('起点_第*章_*.md'):
    text = open(fp).read()
    original_len = len(text)
    for rule in CLEAN_RULES:
        if len(rule) == 2:
            text = re.sub(rule[0], rule[1], text, flags=re.MULTILINE)
        else:
            text = re.sub(rule[0], rule[1], text, flags=rule[2])
    if len(text) != original_len:
        with open(fp, 'w') as f:
            f.write(text)
        print(f'清理: {fp} (删 {original_len - len(text)} 字符)')
```

⚠️ **不要自动跑**!已发布章节清理属于"二次编辑",需用户明确同意。
