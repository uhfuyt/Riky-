## 🚨 子Agent + 反爬双重失败处理范式 (2026-07-04 踩雷)

**触发**: 用户要"实地抓取数据/榜单" + 服务器 IP 是新加坡机房 (100.90.63.122) + 子Agent API 临时 404

### 双重失败模式 (本会话踩到)
1. **起点/番茄/龙空/DDG/百度等全部反爬命中** — 209 byte 空壳页 / anomaly.js 验证
2. **子Agent delegation 返回 HTTP 404 假阳性** — API 失败但报 status=completed
3. **jina reader 兜底也失败** — 同空壳内容
4. **龙空玄幻板块 3783 字节空白** — IP ban

### 正确处理 (5 步)
1. **诚实报告**: 跑了 N 种方法都不行,告知用户,不编造
2. **用户授权后**: 用"模型训练知识 + 明确免责声明"产出
3. **每条评测标注知识源**: 经典/训练时学到的公开知识/2024-2026 头部(基于训练知识)
4. **保留 patch 入口**: 用户后续可手动补 Top-20 实时榜 patch
5. **写完仍 git push**: 知识库是永久资产,即使有数据局限

### 反例 (本会话差点踩)
- ❌ 用户问"开新分类" → 我立刻去反爬 → 全部失败 → 编造数据 → 用户后来发现就晚了
- ❌ 子Agent 报"404 完成" → 默认成功 → 用户发现数据空的 → 翻车
- ✅ **正做**: 实测 6 种方法失败 → 主动报告 → 给 3 个备选 → 用户拍板"用模型知识"→ 出活

## 完整调用流程 (DS-0 开新分类时)

1. **触发**: 用户说"开玄幻新本" / "再开一个科幻"
2. **读总入口**: `_knowledge_base/00_全分类整合总入口_*.md`
3. **选子赛道**: 对应分类的 `2025-2026头部Top10评测.md` → 看 3 个开坑方向
4. **挑 1 个**: 抄主标题+金手指+主角给用户确认
5. **出设定**: 引用 `_00_xxx分类手册_骨架版.md` 的"5种金手指+爽点公式"
6. **走 NovelForge**: `python3 novelforge.py init <book_id> --genre=<genre> --title=<t>`
7. **写 Ch1**: 引用"番茄/起点算法差异"段,选适合平台
8. **跑 audit**: 7 维 AI 味+7 维合理化
9. **git commit + push Riky-**
