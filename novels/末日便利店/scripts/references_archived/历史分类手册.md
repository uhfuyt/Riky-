# 历史分类参考手册 (2026-07-04)

> ⚠️ **数据来源声明**: 同玄幻手册,基于行业知识 + 经典头部作品(《明朝那些事儿》《赘婿》《唐家三公》《庆余年》等)经验。**涉政敏感零容忍**——历史分类红线最复杂。

## 一、5种已验证的历史金手指爆款模式

### 模式1: 穿越改变史(《赘婿》/《唐家三公》)
**核心**: 主角现代人魂穿到X朝代 → 知道历史走向 → 提前布局 / 改变历史
**爽点公式**: 知道历史 → 抢先布局 → 打脸当年敌人 → 弥补历史遗憾(避免某些悲剧)
**优势**: 智斗感 + 历史情怀
**铁律**: 朝代选择直接决定安全度(详见第四节红线)

### 模式2: 技术流种田(《带着仓库到大明》/《北宋大丈夫》)
**核心**: 主角带现代知识/仓库系统 → 用现代技术提升古代生产力(火药/水泥/印刷术)
**爽点公式**: 解决古人难题 → 震惊古人 → 名利双收 → 反派酸
**优势**: 知识壁垒+爽感双重,适合慢热长篇
**铁律**: 技术必须有历史根据,不能"超越时代太多"变玄幻

### 模式3: 历史直播型(《汉乡》/《庆余年》)
**核心**: 主角穿越后被"历史直播间"评论 → 来自现代的点赞/吐槽引导剧情
**爽点公式**: 直播点醒 → 主角破防 → 调整策略 → 再次震惊观众
**优势**: 双视角代入 + 现代读者强共鸣
**铁律**: 评论区观众不能剧透太狠,要保持"半遮半掩"

### 模式4: 将军/谋士型(《铁血大明》/《带着军火库到大明》)
**核心**: 主角现代军人魂穿古代 → 用现代军事思想打仗 → 一路封侯拜相
**爽点公式**: 用现代战术破古人 → 单骑破万军 → 反派震惊 → 翻盘
**优势**: 战场爽感强 + 男频受众大
**铁律**: 战术描写必须有现代理论依据(火力配置/通讯/后勤)

### 模式5: 帝王种田型(《我在古代当皇帝》/《唐宝二皇》)
**核心**: 主角穿越成皇帝/太子 → 收拾奸臣 → 改革变法 → 称霸天下
**爽点公式**: 上位 → 打脸权臣 → 改革成功 → 异族来犯 → 击败
**优势**: 权力感爽 + 节奏宽
**铁律**: 帝王描写要避免影射(不能拿XX皇帝的真实事迹当主线)

## 二、历史头章5幕结构实战模板

### 幕一·开场冲突(500字)
- 主角开场处境:**现代人/古代小卒/市井乞丐**(身份越底层越有代入)
- 时间锚点:**朝代 + 皇帝年号**(精确到年,如"贞观二年三月")
- 刺激源: 乱世/灾荒/权臣逼宫/外族入侵/灭门之祸
- 朝代背景一次性铺:**一段话交代朝代大势**

### 幕二·规则铺陈(500字)
- 系统/前世记忆/金手指激活瞬间(脑抽/撞头/火灾重生)
- 规则: 这本是异世架空还是真实历史
- 主角知道的历史**只透露一半**(留悬念)
- 金句: 古代常用的"犯我强汉者虽远必诛"/"天子守国门"等

### 幕三·试探验证(500字)
- 主角用现代知识第一招(比如造简易水泥做地砖/用阿拉伯数字记账)
- 围观者反应: 看不懂 → 尝试 → 成功
- 关键钩子: 现代知 识的优势只演示一种,留下更多悬念

### 幕四·第一爽点(500字)
- 一次具体的"古人震惊": 打脸/反杀/破解难题
- 反派/权臣反应: 怀疑 → 调查 → 反而提供机会
- 主角金句: "大汉的疆土,绝不因一纸和约而退让。"
- 内心独白: 历史使命感 + 个人的野心交织

### 幕五·钩子反转(500字)
- 主角算账: 距离历史XX事件还有多久 → 必须布局
- 外部刺激: 异族头领/权臣/后宫斗争
- 暗钩子: 地图上一处自己还没去的地方 / 一段历史只有自己知道的事件

## 三、历史爽点密度标准

| 阶段 | 每章爽点数 | 钩子数 |
|---|---|---|
| 头三章 | ≥3 | ≥3 |
| 卷一前30章 | ≥2 | ≥2 |
| 卷一中段 | 1-2 | 1-2 |
| 卷一高潮(每20章) | 5+ | 3+ |
| 卷二/卷三 | 1-2/章 | 1-2/章 |

**铁律**: 历史比玄幻节奏慢,**每个爽点必须配一个"古人震惊"反应**,否则爽感不足

## 四、历史红线(🔴最高优先级)

### 朝代安全度评级

| 朝代 | 安全度 | 原因 |
|---|---|---|
| **远古(夏商周)** | ✅绿 | 离当代远,无涉政 |
| **秦汉** | ✅绿 | 文化符号正面 |
| **三国** | ✅绿 | 演义层,无涉政 |
| **两晋南北朝** | ✅绿 | 同上 |
| **隋唐五代** | ✅绿 | 大唐盛世,正面 |
| **宋(北宋南宋)** | ⚠️黄 | 涉及辽金蒙古,需谨慎 |

| **明中后期** | ✅绿 | 海上/资本主义萌芽 |
| **清初/清中(康熙-乾隆)** | ⚠️黄 | 政治敏感度高 |
| **清末(1840-1911)** | 🔴红 | **绝对禁止！** |
| **民国** | 🔴红 | **绝对禁止！** |
| **当代** | 🔴红 | **绝对禁止！** |

### 铁律(2026-07-04 焊死)

- **必须知道朝代**: 起点前5本在榜的历史文,2026年**90%是宋/明/架空三国**(安全度高)
- **必须避开时间**: 1840年鸦片战争以后,**任何描写=404风险**
- **必须避开人物**: 真实在位皇帝的负面行为(顺治多尔衮雍正乾隆的争议事件)
- **必须避开地标**: 北京/南京/西安的真实历史现场描写太多敏感事件

## 五、历史伏笔5条起步包

- **F001**: 主角前世身份 → 卷末回收(前世是某朝代某历史人物)
- **F002**: 主角穿越的钥匙/玉佩 → 中段回收(穿越非偶然)
- **F003**: 反派权臣的背景 → 卷二揭露(其实是某个历史大事件的幕后)
- **F004**: 主角的"知识金手指"极限 → 卷一末解释(只能改小,不能改大势)
- **F005**: 身后的神秘窥视者 → 卷三反杀(原来一直有高维观察者)

## 七、AI产历史文 5 大陷阱

1. **穿越身份太好**: 主穿成王爷/太子/首富 → 失去爽感,要"开局废柴"
2. **历史知识失真**: 古代人讲白话、抽水马桶/阿司匹林 → 必须用"符合时代"的物品替代
3. **权谋幼稚**: 反派全是蠢材 → 必须让反派有真实手腕,被反杀才有成就感
4. **官职/职位乱写**: 尚书/侍郎/将军/节度使乱用 → 必查《大辞海》/《中国古代职官大辞典》
5. **地名/货币失真**: 银两/铜板随意换算 → 严格按时代物价(唐代米价/明代盐价查数据)

## 九、历史开坑可选方向(基于安全度排序)

### 🟢 方向1: 三国穿越(首选)
- 安全度最高,读者基数大,有家国情怀
- 推荐角度: 文臣路线 / 武将路线 / 山贼种田路线
- 金手指: 系统召唤前世武将/前世记忆/火药配方

### 🟢 方向2: 大宋(寇/宋传奇层)
- 包公/狄青/岳飞(但避开风波亭)/水浒(民间故事层)
- 金手指: 系统召唤水浒好汉 / 间谍指南
- 注意: 岳家军/风波亭需谨慎,不能正面政治影射

### 🟡 方向3: 明中后期(郑和下西洋/东南倭寇)
- 避开了明初靖难敏感 + 避开了清末,中间地带
- 金手指: 火器路线/航海路线/抗倭

### 🔴 必须避免的方向
- ❌ 清末 / 民国 / 任何现当代背景
- ❌ 真实历史人物负面化(讽刺皇帝/抹黑清官)
- ❌ 把穿越者塑造得太强(虚无历史感)
