# "会花冤钱奇女子"原型 + 装比门槛细节(2026-07-03 番茄Ch3 实战)

> 起源: 番茄Ch3 第一次引入"会花冤钱的女性员工"角色, 用户原话"爽感要有,玩女人,装比,消费,创业" → 创造了一个新beat类型,**可复用于任何金手指爽文**系列

## 一、"会花冤钱奇女子"原型(Beat Type)

### 1.1 角色三件套(必填)

| 三件套 | 番茄Ch3 模板 | 复用模板 |
|---|---|---|
| **职业** | 30岁,曾在5家公司把老板的钱花光(求职简历写的就是这个) | 任何"金手指+创业"题材, 都需要一个"懂金手指" 的女性角色(不是工具人) |
| **家族/资源** | 自己花光父亲的50万养老钱 → 父亲去年走了 → 她自责 | 任何带"自我毁灭/重生"元素的爽文女主 |
| **秘密/伏笔** | (留到Ch15+ 揭晓: 她花光父亲钱有更深原因, 不是单纯败家) | 必有"她为啥这么会花冤钱"的伏笔链 |

### 1.2 为什么她是"奇女子"不是"工具人女主"

✅ **自己懂机制, 不是等主角教** — 周映雪第一次面试就能算出"一天1万×200倍=4亿/月", 这种"比自己还懂"的女主 = 读者爽感max
✅ **有"花冤钱的道德底线"** — 她买10台折叠屏是**送给电子厂穷学生**, 不是自用 → 主角被爽感+读者被爽感双收
✅ **是死党的暧昧, 不是主角的** — 钱小宝"盯上她了", 主角"我没注意她漂不漂亮" = 喜剧反转 + 三人关系动态网
✅ **有清晰的入职动机** — "你是我遇到的第六个老板, 但你是第一个让我花钱还给我钱的" → 情感弧光完成

### 1.3 复用模板(任何"金手指爽文" Ch3-Ch5 必填)

```
[奇女子角色卡]

【名字】 (双书并查后命名, 意像匹配人设)
- 清冷爽利人设 → 映雪/冰/寒/霜 → 例: 楚映雪/林若冰/赵冬寒
- 烟火气人设 → 燕/桃/杏/春 → 例: 魏小燕/钟桃溪/尤春杏

【年龄】 28-32 (有阅历, 不是20出头小白花)

【职业】 必须是"懂行业" 不是"懂金手指"
- 金手指返利 → 做过老板的花冤钱助理
- 重生年代 → 在供销社/国营厂当过会计
- 鉴宝流 → 在拍卖行当过学徒
- 神医流 → 在医学院当过旁听生

【家族/资源】 必有"被家族伤害/利用/抛弃"的过去
- 父亲: 她把父亲养老钱花光 → 父亲去年走了
- 家族: 她是私生女, 家族不认她
- 前夫: 离婚分走她一半积蓄, 她"花冤钱"是报复式消费

【秘密/伏笔】 必有"她这么会花冤钱" 的根因
- 例: 她曾在另一个平行世界是"亏成首富"的角色原型 → 跟主角金手指同源
- 例: 她的花冤钱天赋是被反派资本改造过 → F003伏笔回收用

【首次登场剧本模板】 (Ch3-Ch5 任意一章):
1. 主角发招聘启事"招会花冤钱的人"
2. 她10分钟内出现, 简历就是"花光5个老板的钱" (反常识)
3. 主角面试, 她现场算出"1万×200=4亿/月"
4. 主角震惊, 当场录用
5. 她用第一天启动资金10万 → 买10台折叠屏送穷学生 (爽点+道德底线双收)
6. 死党一眼看上她, 她说"你愿意陪我送吗?" → 暧昧钩子
```

## 二、装比门槛细节(装比不出戏的7条铁律)

用户原话: "爽感要有,装比" — 装比写过头 = 油腻/失真/读者出戏

### 2.1 装比的7条铁律

| # | 铁律 | 反例 | 正例 |
|---|---|---|---|
| 1 | **主角不能穿错衣服** | 主角穿格子衫去五星级会所 | 钱小宝"强行"给主角换装 (白衬衫+黑西裤+皮鞋) |
| 2 | **必须有"被包装"环节** | 主角生来就会装 | 钱小宝"行舟, 你现在的身份不一样了, 去谈生意不能穿格子衫" → 给读者"主角被包装"的爽感 |
| 3 | **反派/前辈要"被折服"后给出金句** | 主角夸自己 | 林建业"顾总, 您到底是什么人?" → 主角"我是您这辈子见过的, 最会花钱的人" |
| 4 | **装比场景要有"反差锚点"** | 主角单独装 | 深圳湾会所门口蹲着抽完一根烟再进 (从五环外小老板突然五星级会所 = 反差锚点) |
| 5 | **装比时必须有"细节"** | "林总, 500万, 成交" (一句话) | 林建业点最贵的茶 (一壶5800), 主角喝了没出声, 等主角先出手 (细节堆显示"主角不差钱") |
| 6 | **装比结尾要有"意外钩子"** | 装比完就完 | 谈500万成交后 → 怀表震动 → 主角看到"新功能:身边人劝省钱"启动 = 装比+伏笔双收 |
| 7 | **装比不能毁"主角人设"** | 主角装比之后变"高冷霸总" | 主角装比完跟钱小宝"行舟,你看这个女人..."马上接日常 → 人设不漂移 |

### 2.2 番茄Ch3 装比模板(已验证 4587字 🟢91.8分)

```
【场景】 深圳湾某高档会所
【主角造型】 白衬衫 + 黑西裤 + 擦得锃亮的皮鞋 (钱小宝强行买)
【对手】 林建业 (50岁, 西装革履, 劳力士, 副总裁)
【茶】 一壶5800 (林建业点, 等着主角"被价格吓到")
【主角动作】 喝了一口, 没出声, 等林建业先出牌
【对手出价】 "顾总, 那厂子值800万, 500万我卖不了" → 想压主角
【主角反杀】 "那厂子去年亏了三千万, 设备老产品落后, 我出600万" → 林建业震惊
【金句】 "我是您这辈子见过的, 最会花钱的人"
【成交】 500万, 怀表震动 → Lv.1→Lv.2 + 副作用"劝省钱"启动
【钩子】 怀表显示"劝省钱副作用" → 钱小宝马上要劝主角"行舟, 别再花冤钱了"
```

**为什么有效**: 5800的茶(细节) + 顾总(对手称谓) + 顾总您到底是什么人(对方被折服) + 一句金句(主角弧光) + 怀表震动(意外钩子) = 装比5件套一个不少

## 三、"钱小宝追奇女子" beat(可复用喜剧模板)

### 3.1 三幕结构

```
【幕1 - 主角不在意 → 死党在意】
主角: "我注意她会不会花冤钱。"
死党: "你他妈——! 你招了个女的, 你居然没注意她漂不漂亮?!"
主角: "我没病。"
死党: "行舟, 我盯上她了!"

【幕2 - 奇女子给死党表现机会】
楚映雪: "你有钱?"
钱小宝: "有!"
楚映雪: "那行, 你愿意帮我送吗?"
钱小宝: "我愿意!"
楚映雪: "那走。"

【幕3 - 死党真的"入局"】
钱小宝发现: 楚映雪把10台折叠屏送给电子厂穷学生 (不是自己用)
钱小宝内心戏: "她花冤钱, 是为了别人。不是为我。"
= 死党从"看脸" → "懂她" 的瞬间成长
```

### 3.2 为什么这是"玩女人"而不是"撩女主"

❌ 错: 主角跟周映雪调情 → 跟"前妻苏婉清"对比 = 读者觉得"换皮"
❌ 错: 周映雪一登场就是女主 → 没暧昧弧光 = 工具人女主
✅ **对: 周映雪一登场是"员工" + 钱小宝(死党)追她 = 三人关系动态网**
- 主角跟周映雪是"纯老板-员工" (纯业务, 不调情)
- 钱小宝跟周映雪是"追她" (爱情线副CP)
- 周映雪自己的"花冤钱道德底线" 是她自己的伏笔 (反哺主线)

**这种结构的爽感**:
- 主CP不乱 (主角专心升级)
- 副CP有看头 (死党的爱情线是喜剧调剂)
- 女主不被工具化 (周映雪有自己的秘密/伏笔)
- 番茄读者爱看副CP (尤其当副CP有"成长弧光"时)

### 3.3 复用: 任何"金手指爽文" 需要"女主/暧昧"时的 beat

| 场景 | 推荐配置 |
|---|---|
| 创业流/商战流 | 死党追女主 (副CP), 主角纯业务, 女主有秘密/伏笔 |
| 系统流/重生流 | 死党是"和事佬", 女主跟主角直接暧昧 (主CP) |
| 鉴宝流/神医流 | 女主是"行业前辈", 主角追她 (主CP反转, 女主高冷) |
| 末世流/玄幻流 | 女主是"战力担当", 主角纯挂件 (主CP, 女主强) |

## 四、Lv.2升级爽感模板(可复用)

番茄Ch3 升级到 Lv.2 (500x + 日限10万 + "劝省钱"副作用) 的写法模板:

```
【升级提示出现位置】 装比现场, 怀表震动
【升级显示】 半透明光字变化: Lv.1 → Lv.2, 倍数200x → 500x, 日限1万 → 10万
【主角反应】 不激动 (装比刚完, 人设稳) → "行。500x。"
【死党反应】 激动 → "500x? 日限10万?"
【副作用启动】 身边人开始"劝省钱" (钱小宝/母亲/程晚棠/员工)
【副作用第一幕】 钱小宝立刻劝: "行舟, 那餐厅太贵了, 咱们去路边摊吧" (喜剧反转, 主角被动+主动双爽)
【钩子】 主角必须"反向操作" (拒绝钱小宝, 去更贵的) 才能维持返利
```

**为什么这是爽感max**:
- Lv.1 → Lv.2 = **数字量级跃迁** (200x → 500x)
- "劝省钱"副作用 = **被动+主动双爽** (别人劝省钱=有戏剧冲突, 主角偏要花=主角主动爽)
- 死党不知道主角已经升级 = **喜感反转** (读者比角色先知道)
