# 章节连贯性 9 类检查清单 (2026-07-04 焊死)

**来源**: 起点 Ch7 + 番茄 Ch4 双双"假完成"事故,9 类根因归纳。
**用法**: 写完每章后跑这 9 类检查,任何一类失败 → 重写章节(不通过)。

---

## C1 — 时间线漂移

**症状**: Ch{N} 的 Day/时间接不上 Ch{N-1} 末态。

**检测**: 读 Ch{N-1} 末段最后 50 行 → 提取时间锚点 → 跟 Ch{N} 开头时间对比。

**反例(2026-07-04 起点 Ch7)**:
- Ch6 末 = 7月6日23:00 主角关灯睡觉
- Ch7 开头 = "七月的江城,夜里十一点半"(没说是7日还是8日,且"从汉庭府出来"跟 Ch6 末"在汉庭府里准备睡"矛盾)

**反例(2026-07-04 番茄 Ch4)**:
- Ch3 末 = Day 2 16:42 升级 Lv.2
- Ch4 开头 = "Day 2,晚上九点半"(看似对,但剧情位置算 Day 2 的晚间,**跳过了 Ch3 升级后的剧情节点**)

---

## C2 — 数字漂移

**症状**: 累计花销/累计返利/等级自相矛盾。

**检测**: 跑算术 — 上章末值 + 本章新花销/返利 = 本章末值,跟 codex 比对。

**反例(2026-07-04 起点 Ch7)**:
- codex `cumulative_return = 14,661,900`,Ch7 写"累计返利:16,661,900" → 多 200万 → 来源不明

**反例(2026-07-04 起点 Ch7 系统提示框)**:
- "50万×20x + 500万×50x + 750万×500x = 2500万" → 20x/50x/500x 三种倍数混搭,**Lv.3 最高只 50x**,500x 哪来的?

**反例(2026-07-04 番茄 Ch4)**:
- "妈账户里多了两百万" → 200万
- "累计返利:12,000,000元" → 1200万
- 自相矛盾

---

## C3 — 剧情反转

**症状**: 反派立场/主角立场跟前文对不上。

**检测**: 读 Ch{N-1} 末段对话 → 提取关键立场 → 跟 Ch{N} 立场对比。

**反例(2026-07-04 起点 Ch7)**:
- Ch6 末: 主角要求王大龙给500万,王大龙拒绝,主角要反诉 → 主角=攻势方
- Ch7: 王大龙要求主角签500万协议价 → 王大龙=攻势方
- **完全反转**

---

## C4 — 大纲越界

**症状**: 把 Ch{N+5} - Ch{N+10} 的剧情压缩进 Ch{N}。

**检测**: grep `卷一细纲.md` 里 Ch{N} 的关键词 → 对照 Ch{N} 实际出场。

**反例(2026-07-04 起点 Ch7)**:
- 起点细纲 Ch7 处于"Ch6-15 单王之路",无独立明细
- 但 Ch7 一章塞了: 接机/讨债/春风帮扶会/振邦调查/金陵饭店60万/周映雪白浴袍/江城日报
- 这等于**Ch7-12 五章的剧情节点压缩进 Ch7**

**反例(2026-07-04 番茄 Ch4)**:
- 番茄细纲 Ch31-40 才是"母亲来深圳"
- Ch4 直接把"母亲被骗+报警"塞进 → **提前 27 章**

## C5 — 角色抢戏

**症状**: 暖暖/母亲/反派等不该在 Ch{N} 出场的角色出场了。

**检测**: 维护"角色首次出场表",对照 codex.characters.first_appearance。

**反例(2026-07-04 起点 Ch7)**:
- 暖暖: codex 里无 first_appearance,但 Ch1-3 锁死事实中**从未出场**
- 何秀兰: codex F004 planted_ch=8,应在 Ch8 后才能给主角打电话
- Ch7 直接"暖暖从门缝后探出头,何秀兰开门" → **角色抢戏**

## C6 — 倍数瞎编

**症状**: Lv.X 用了非该等级倍数。

**检测**: 对照 `codex.rules.level_curve`。

| 书 | 等级 | 合法倍数 |
|---|---|---|
| 起点 | Lv.1 | 10x |
| 起点 | Lv.2 | 20x |
| 起点 | Lv.3 | 50x |
| 番茄 | Lv.1 | 200x |
| 番茄 | Lv.2 | 500x |
| 番茄 | Lv.3 | 1000x |

**反例(2026-07-04 起点 Ch7)**:
- 写"500x" → 起点最高只 50x → **瞎编**

---

## C7 — 日限爆表

**症状**: 单日花销 > 当日等级日限额。

**检测**: 对照 `codex.rules.level_curve.daily_quota`。

|---|---|
| 起点 Lv.1 | 1万 |
| 起点 Lv.2 | 10万 |
| 起点 Lv.3 | 100万 |
| 番茄 Lv.1 | 1万 |
| 番茄 Lv.2 | 10万 |
| 番茄 Lv.3 | 100万 |

## C8 — 副作用时序错位

**症状**: 系统副作用在解锁前就使用。

**检测**: 对照 `codex.rules.level_curve.<lv>.side_effect_unlock`。

**反例(2026-07-04 番茄 Ch4)**:
- "身边人帮省钱" 副作用 = Lv.2 解锁,Ch3 末 16:42 才解锁
- Ch4 (按错误时间线算 Day 2 = Lv.1) 已经在用这副作用 → **时序错位**

**修复**: Ch4 时间线改成 Day 2 晚(Lv.2 已解锁)即可对得上。

## C9 — 4D 爽点一锅炖

**症状**: 4D 男频爽点(消费装比/打脸反派/暧昧追妹子/玩资本)全塞一章。

**铁律**: **每章 1-2 个爽点**, 别塞 5+ 个。

**检测**: 列出本章所有爽点,数一下。

**反例(2026-07-04 起点 Ch7)**:
- 7 个爽点: 王大龙威胁/春风帮扶会/振邦/金陵饭店60万/3 老板/白浴袍/江城日报
- 应该拆成 Ch7-11 五章各 1-2 个爽点

## 速查命令

```bash
# 跑所有 9 类自检
python3 -c "
import re, json
with open('chapters/起点_第7章_xxx.md') as f: text = f.read()
with open('novelforge/books/qidian/codex.json') as f: codex = json.load(f)

# C6 倍数瞎编
max_multiple = max(v.get('multiple', 0) for v in codex['rules']['level_curve'].values())
for m in re.findall(r'(\d+)x', text):
    if int(m) > max_multiple:
        print(f'C6 命中: {m}x 超过 codex 最大倍数 {max_multiple}x')

# C9 爽点一锅炖 (粗略: 数 '!')
exclam = text.count('!')
print(f'C9 感叹号: {exclam} (>30 疑似一锅炖)')

# 禁词
for kw in ['江北新区','暖暖','春风帮扶会']:
    cnt = text.count(kw)
    if cnt > 0 and kw != '暖暖':  # 暖暖可能在末段提及
        print(f'禁词命中: {kw} = {cnt}次')
"
```
