### 5 段推进链 (替代 v3 7 步思维链)

```
幕一·场景锚点 (800字)
    - 实物景 + 时间标 + 主角状态
    - 不用"年月日"开头,用"晚上 8 点半 / 凌晨 4 点 / 上午 9 点 47 分"
    - 例:"晚上八点半,蛇口老张便利店的二楼"

幕二·动作+系统提示 (600字)
    - 主角看怀表演示 / 银行短信
    - 系统状态数字 (Lv.x / 倍数 / 累计花销 / 累计返利)
    - 例:怀表内盖那一行字:今日剩余额度:9.4万元 倍数:500x

幕三·对话+动作 (1500字) ← 用户原话"对话全是废话"
    - ❌ 不能用:"妈——" "嗯。" "妈——" "嗯。" "妈——" "嗯。" (6 条来回)
    - ✅ 用:"妈"+"长句回应"+"妈的反应"+"场景描写"穿插
    - 例:妈说:xxx——儿子说:xxx(长句, ≥10 字)——妈问:xxx(长句)——儿子答:xxx

幕四·事件+结果 (500字)
    - 一笔花冤 + 系统返利
    - 数字具体(不是"一万五"而是"15,675,000")

幕五·章末钩子 (400字)
    - 妈妈要走 / 程晚棠要来 / 钱小宝要拜师
    - 不写方括号剧透,只自然嵌入
```

### 破折号堆 3 种识别 + 修复

**模式 1: PPT 分条堆** (用户原话"滥竽充数凑字数")
```
❌ 反例:
——她儿子 3 年前是从这里出发的吗?
——不,她儿子 3 年前从宿迁去南京。
——她儿子是从南京飞到深圳的吗?
——她儿子没跟她说过。
——她儿子没骗她。
——她儿子在深圳有个店,叫老张便利店。
——她儿子在华强北等她。
——她儿子说要带她去派出所。

✅ 正例:
他妈 3 年前送他出门,他提着一个蛇皮袋去南京读书,她站在车窗外说"行舟,妈等你"。他 4 年大学每学期回家,毕业后说"妈,我找到工作了",然后 3 年没回过宿迁。她等了 3 年 × 365 天 × 2 次 = 2190 次看手机,等到 7 月 2 号晚上她账户多了 500 万。
```

### 对话真密度 vs 废话型对话

**真对话** (信息推进剧情):
- "妈,这钱是正经生意赚的。" → 14字有意义
- "行舟——你——你跟妈说清楚——" → 12字有意义(追问细节)

**废话对话** (注水):
- "嗯。" → 1 字无意义
- "妈——" → 1 字无意义
- "行舟——" → 1 字无意义(叫名字不推进剧情)

**3 个修法**:
1. **删独立成行的 1-3 字应答**,合并到上一段或下一段
2. **"嗯。"可以保留**,但不能连发 5+ 次
3. **"妈——"独立成行 ≤ 3 次/章**,超过则改成"她说"或"妈妈说"
