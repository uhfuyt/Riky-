## 5秒检测脚本(任何番茄初始化后必跑)

```python
# fanqie_signals_check.py
# 用法: python3 fanqie_signals_check.py fanqie
import codex, json, sys

book = sys.argv[1] if len(sys.argv) > 1 else 'fanqie'
data = codex.load_book(book) or {}
s = json.dumps(data, ensure_ascii=False)

signals = {
    '1. platform 不是 fanqie': data.get('platform') != 'fanqie',
    '2. 含起点角色名(林北辰/苏晚晴/周公子/林秀芝/王大龙/李秀芝)': any([
        name in s for name in
        ['林北辰', '苏晚晴', '周公子', '林秀芝', '王大龙', '李秀芝', '马总']
    ]),
    '3. 规则 base_multiple == 10000(起点固定10000x的标志)':
        data.get('rules', {}).get('base_multiple') == 10000,
    '4. city 含 魔都/江城(起点城市)': any([
        city in s for city in ['魔都', '江城', '宿迁' + '上海']  # 起点城市串
    ]),
    '5. current_state.cash == 11763900(起点Ch3末值)':
        abs(data.get('current_state', {}).get('cash', 0) - 11763900) < 1,
    '6. timeline 含"神秘黑卡"(起点系统名)':
        '神秘黑卡' in s or '亏钱一万倍' in s,
    '7. voice_style.signature_phrases 还提"林北舟"':
        any('林北舟' in phrase for phrase in
            data.get('voice_style', {}).get('signature_phrases', [])),
    '8. outline.volumes 仍写"小亏怡情/大亏伤身/亏成首富"(起点三卷名)':
        '亏成首富' in s and '小亏' in s,
}

hits = [k for k, v in signals.items() if v]
if hits:
    print('⚠️ 番茄 codex 仍是起点模板残留, 需整套重写')
    for h in hits:
        print(f'   触发: {h}')
    sys.exit(1)
else:
    print('✅ 番茄 codex 干净, 无模板残留')
```

**任一信号触发 → 整套重写,不要试图局部修**。

## 8 字段 must-rewrite 清单(任何番茄初始化必须全填)

只调 `init_book` + `add_character` 是不够的。下面 8 个字段都要**独立覆盖**:

| # | 字段 | 起点模板值(错位示例) | 番茄正确值(本会话示例) |
|---|---|---|---|
| 1 | `characters[]` | 林北辰/林秀芝/赵大海/苏晚晴/周公子/马总 | 顾行舟/顾秀芝/钱小宝/程晚棠/程建国/沈昭/周建国/神秘人 |
| 2 | `rules.base_multiple` | `10000`(起点固定) | **`200`**(番茄Lv.1起步) |
| 3 | `rules.level_curve` | Lv.1=10x/Lv.5=200x | **Lv.1=200x/Lv.2=500x/Lv.3=1000x/Lv.4=5000x/Lv.5=10000x**(全独立) |
| 4 | `current_state.cash` | `11763900`(Ch3末) | **`705.0`**(番茄Ch1末) |
| 5 | `current_state.level` | `Lv.1` (起点10x对应) | `Lv.1` (番茄200x对应) |
| 6 | `world_anchors.city` | 魔都 / 江城 | **深圳** |
| 7 | `voice_style.signature_phrases` | "我林北辰,穷得只剩运气了..." | "我顾行舟,穷得只剩花钱这本事了..." |
| 8 | `timeline[0].event` | "林北辰大学毕业..." | "顾行舟大学毕业..." |

**8 块字段缺一即视为模板残留**。

## 标准修复流程(已踩坑 → 完整版)

```python
import codex

# ===== 步骤1: 全删 =====
codex.reset('fanqie')

# ===== 步骤2: 用 init_book 创建空 schema (但 init_book 不会自动填全部字段!) =====
data = codex.init_book(
    'fanqie',
    title='破财转运牌:花掉一块来一万',
    author='Riky',
    platform='fanqie',
)
# 此时 fields 长这样:
# {
#   'title': '...', 'author': 'Riky', 'platform': 'fanqie',
#   'created_at': '...', 'updated_at': '...',
#   'characters': [], 'rules': {}, 'timeline': [], 'hooks': [],
#   'current_state': {}, 'world_anchors': {},
#   'voice_style': {...},  # 这里会用默认 voice_style 不是空
#   'outline': {'volumes': []},
#   'chapters_meta': []
# }
# 注意: 'voice_style' 用的是默认模板, 不是空 → 也要覆盖!

# ===== 步骤3: 字段全部手写 =====
# 3.1 主角 + 配角
for c in [
    {'name': '顾行舟', 'role': '主角', 'age': 24, ...},
    {'name': '顾秀芝', 'role': '母亲', 'age': 48, ...},
    # ... 全部番茄角色
]:
    codex.add_character('fanqie', c)

# 3.2 规则
data = codex.load_book('fanqie')
data['rules'] = {
    'trigger': '花得冤的商业行为',
    'base_multiple': 200,  # ← 番茄 200x, 不是起点 10000x!
    'level_curve': {
        'Lv.1': {'multiple': 200, 'upgrade_threshold': 10000, 'daily_quota': 10000},
        'Lv.2': {'multiple': 500, 'upgrade_threshold': 100000, 'daily_quota': 100000},
        'Lv.3': {'multiple': 1000, 'upgrade_threshold': 1000000, 'daily_quota': 1000000,
                 'side_effect': '身边人帮省钱解锁'},
        'Lv.4': {'multiple': 5000, 'upgrade_threshold': 10000000, 'daily_quota': 10000000},
        'Lv.5': {'multiple': 10000, 'upgrade_threshold': None, 'daily_quota': None},
    },
    'ban_list': ['赌','毒','黄','骗','传销','洗钱','黑产'],
    # ... 全部番茄专属
}
codex.save_book('fanqie', data)

# 3.3 current_state / world_anchors / voice_style / timeline / hooks / chapters_meta 同上

# ===== 步骤4: 验证 =====
# 跑 fanqie_signals_check.py → 必须 ✅ 番茄 codex 干净
# 跑 audit Ch1 → 看 level_curve_score 是否 ≥85
```
