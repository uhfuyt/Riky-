# A+B 金手指反套路模式 — 模板与实战 2.0

[DS-0] **起源**: 番茄 Ch1 原版"固定 10000 倍"被用户当场否决 ("1 万倍返还不太合理剧情容易崩")。
**修正后**: 分级返利曲线 (A) + 日限额机制 (B) = 防止数字通胀 + 剧情可持续。
**v2 扩展**(2026-07-03): 番茄新机制 "花不完清零"+"劝你省钱" 副作用 + 起点 4-7 章"硬爽点"红线。

---

## A. 分级返利曲线 — 替代"固定 X 倍"

**原则**: 倍数随等级提升, **Lv.1 起步低 + 升级奖励高**, 给读者"成长感"。

### 已验证的 5 级曲线(番茄用)

| 等级 | 累计亏损阈值 | 返利倍数 | 日限额 |
|---|---|---|---|
| Lv.1 | 0-1 万 | 10000x | 1 亿 |
| Lv.2 | 1-10 万 | 20000x | 10 亿 |
| Lv.3 | 10-100 万 | 50000x | 100 亿 |
| Lv.4 | 100-1000 万 | 100000x | 1000 亿 |
| Lv.5 | 1000 万+ | 1000000x | 无限制 |

### 反例(必避)

- ❌ 起点 10x → 番茄固定 10000x: 同机制改数字,读者一眼"换皮"
- ❌ 番茄 10000x 一路到底: Ch1 破亿, Ch2 破万亿,**没有升级感**
- ✅ 番茄: 10000x 起步 + Lv.2 解锁 2 万 x + Lv.3 解锁 5 万 x... 给"成长感"

### 起点本曲线(已实现,5级)

| 等级 | 累计亏损阈值 | 返利倍数 | 升级奖励 |
|---|---|---|---|
| Lv.1 | 0-1 万 | 10x | — |
| Lv.2 | 1-10 万 | 20x | 日限扩 10 倍 |
| Lv.3 | 10-100 万 | 50x | 解锁"主动亏损任务" + 首次奖励 2 倍 |
| Lv.4 | 100-1000 万 | 100x | 解锁"信用透支" |
| Lv.5 | 1000 万+ | 200x | 副作用"想亏"压过"想赚" |

---

## B. 日限额机制 — 防止"花得停不下来"

**核心**: **每日返利累计达到上限后,系统当日不再返利,次日凌晨重置**。超出部分累积到次日,但有 5% 滞纳金。

### 为什么必须

- **没日限**: Ch1 主角一顿饭花 19.6 万 → 196 亿 → 1 万亿 → 100 万亿,5 章内剧情崩
- **有日限**: Ch1 主角当天只能花 1 万(返 1 亿)→ 接下来 Ch2-Ch20 每天必须想新办法"花 1 万"→ 每日焦虑/期待/剧情动力

### 剧情影响(番茄 Ch1 实战)

- 主角**不能无限制刷**,必须每天想新办法制造亏损(开店、做慈善、雇人乱花)
- "等待重置"变成每日焦虑/期待,**推动剧情前进**
- 滞纳金让"超额"有代价,不是纯爽

### 话术模板(写进章节)

> 系统提示:当日返利已达上限(1亿)。明日 00:00 重置。超出部分累积到明日(扣 5% 滞纳金)。

---

## C. 系统限制(防爆走的兜底)

| 限制 | 说明 | 剧情作用 |
|---|---|---|
| 触发=商业行为 | 日常消费(吃饭/交通)不算 | 主角必须"花得有理由" |
| 禁区 | 赌/毒/黄/骗/传销/洗钱/黑产 | 防擦边违规 |
| 信用透支 (Lv.3 解锁) | 预支未来返利的 50% | 给主角"借钱"渠道 |
| 隐藏费用 | 系统每月扣 1% 返利资金 | 防止"无限钱" |
| 副作用 Lv.3 | 周围人开始不自觉地"帮主角省钱" | 喜剧+剧情 |
| 副作用 Lv.5 | "想亏"压过"想赚",散发"败家气质" | 主角性格升级 |
| 副作用 Lv.7 | 系统可"反向锁定"反派钱流向主角 | 反派必败逻辑 |

## D. 实战模板(已验证:番茄《全球神豪》)

### Ch1 数据(应用 A+B 后)

- 19.6 万亏损 × 10000x = 196 亿(理论)
- 日限 1 亿 → 实际当天到账 1 亿
- 195 亿累积到后续 20 天,每天补 9000 万(扣 5% 滞纳金)
- **数学正确**: 检测器 plausibility.math_score=50 → 合理化总分 86.8(合格)

### 反例(已踩)

- ❌ Ch1 只写"19.6万→19.6亿"(少 10 倍): 数学错误, 合理化崩到 52.8
- ✅ Ch1 写"19.6万→196亿 + 日限1亿 + 195亿待补" + 系统提示界面

### 数字可信度双控(章内+章末,2026-07-03 新增)

| 约束 | 数值 | 触发处理 |
|---|---|---|
| 章内最大数字 ≤ 等级理论返利 × 1.5 | Lv.1=10000×1.5=15000 | 超 → 拆分/加过渡段 |
| 章末主角资产 ≤ 上章末 × 10 | Ch1末/Ch2末 ≤10倍 | 超 → 加 1-2 章过渡 |

### Day-N 时间线模板(防时间过密,2026-07-03 新增)

**问题**: Ch6 原版"7月8日"塞了 5 个大事件,被检测器 time_logic=68.2 标"时间过密"。

**修复**: 写到细纲开头的强制时间线表(每章"第N天 + 日期"):

```markdown
| 章 | 日期(7月) | 标题 | 主角等级 | 现金 |
|---|---|---|---|---|
| Ch1 | 7月2日 下午 | 系统激活 | Lv.1 | 4,356元 |
| Ch2 | 7月2-3日 | 第二个亏单 | Lv.1 | 51万 |
| Ch3 | 7月4日 早 | 王大龙登场 | Lv.2 | 51.8万 |
| **Ch4** | **7月5日 早** | **母亲来电** | Lv.2 | 51.8万 |
| **Ch5** | **7月5日 上午** | **第一次被问话** | Lv.2 | 51.8万 |
| **Ch6** | **7月8日 上午** | **Lv.3 升级 1个亿** | Lv.3 | 1亿+ |
| **Ch7** | **7月9日 中午** | **暖暖+母亲来江城** | Lv.3 | 1亿+ |
```

**铁律**:
- 单章最多跨一天(Ch2 = 7月2-3日 OK,Ch5 = 7月5日全天 ❌ 必须拆)
- 单章事件 ≤ 3 个(系统升级 + 大额转账 + 一个情绪高点 = 满载)
- 跨章不能有时空跳跃(Ch5 江城 → Ch6 不能突然在香港)

### 章节拆分模式(密度超限 → 拆)

**症状**: time_logic_score < 70

**修复案例**: 起点 Ch6 → Ch6 + Ch7
- Ch6: 仅 7月8日 上午(50万任务 + Lv.3升级) → 3500字
- Ch7: 仅 7月9日 中午(暖暖来 + 母亲来 + 蛋炒饭 + 苏婉清起诉) → 3500字
- 结果: Ch6 68 → 80, Ch7 = 83 双合格

## E2. 番茄A+B变体(2026-07-03v2):"花不完清零"+"劝你省钱"副作用

**背景**: 起点Ch1-3已发布+番茄Ch1已出但用户嫌"10000x太离谱"+ 两本雷同 → 需要番茄新规则跟起点根本不同。

**番茄新规则**(2026-07-03v2,顾行舟《破财转运牌》):

| 维度 | 起点(锁) | 番茄新 |
|---|---|---|
| 起步倍数 | 10x | **200x** |
| 核心约束 | 升级解锁 | **日清零**(24h内必须花完,否则返利扣50%) |
| 隐藏费用 | 无 | **每月扣2%**返利 |
| 副作用 | Lv.5"想亏"本能 | **Lv.2身边人开始"劝你省钱"** + **Lv.4散发"败家气质"** |
| 升级触发 | 累计亏损阈值 | **累计"冤枉花"(5万)+Lv.2** |

**"花不完清零"机制详解**:

```
每日24:00结算:
- 当日"花出去的钱" < 当日"应花额度" → 差额部分返利**减半**
- 当日"花出去的钱" ≥ 当日"应花额度" → 正常返利(200x)
- 当日"花出去的钱" > 当日"应花额度" 50%以上 → 触发"超额奖",返利×1.5

"应花额度" = 前一日主角现金的 10% (动态调整)
```

**"劝你省钱"副作用详解**:

```
Lv.2解锁后,主角身边的NPC开始"不自觉地劝主角省钱":
- 死党钱小宝:"哥,这餐厅太贵了,咱们去路边摊吧"
- 女主程晚棠:"行舟,你钱够花吗?我去做个兼职"
- 母亲宋桂枝:"儿啊,妈给你织了毛衣,别买新的了"
- 员工:"老板,这个供应商报价太高,我找了个便宜的"

→ 主角必须"反向操作"(花更贵的/拒绝省钱建议)才能维持返利
→ 喜剧冲突 + 推动剧情(主角得跟身边人"斗争")
```

**爽点公式变化**:

| 起点公式 | 番茄新公式 |
|---|---|
| 亏钱→返利(单次爽) | **被劝省钱→偏要花→花得冤→返利**(被动+主动双爽) |
| 1章1爽 | **1章3爽**(劝省/偏要花/冤花) |
| 反派打脸 | 反派打脸 + **自己人打脸**(员工劝省被怼) |

**Day-N时间线应用**(番茄新规则版):

| 章 | 日期 | 标题 | 顾行舟等级 | 当日花销 | 返利 |
|---|---|---|---|---|---|
| Ch1 | 7月1日 | 5块钱的怀表 | Lv.1 | 5元买怀表 | 1000元 |
| Ch2 | 7月2日 | 5万的路边摊 | Lv.1 | 5万(花冤了) | 1000万 |
| Ch3 | 7月3日 | 6小时花1000万 | Lv.1 | 1000万(日清零线) | 20亿(扣5%滞纳金) |
| Ch4 | 7月4日 | 第一家公司 | Lv.1→**Lv.2** | 注册"破财转运公司" | 50亿 + 副作用"劝省"启动 |
| Ch5 | 7月5日 | 花不完才是问题 | Lv.2 | 员工劝省被怼 | 100亿 |
| Ch6-10 | 7月6-10日 | 神豪日课 | Lv.2 | 每日花1亿 | 200亿/日 |

## G0. 2026-07-03 新增:**签约前4-7章"硬爽点"红线**

**用户原话**: "起点文章爽点前面不太够啊4-7章,重新检查下"

**问题诊断**(已重读起点4-7章):

| 问题 | 表现 | 严重度 |
|---|---|---|
| P1. 爽点稀薄 | Ch4主要是母亲电话+司机威胁,没"真实亏+巨返" | 🔴 致命(签约生死线) |
| P2. 跳级太突兀 | Ch6一笔"50万换1亿"=200x,被判定"硬塞钱" | 🔴 老白弃书 |
| P3. 因果链太顺 | Ch5主角反诉直接成功,无悬念 | 🟡 高 |
| P4. 母爱线单薄 | Ch4到Ch7见面=3章无情感升级 | 🟡 中 |
| P5. 同钩子复用 | "蛋炒饭"出现3次,审美疲劳 | 🟡 中 |
| P6. 数字闭环破 | Ch6系统说"20x→40x"下一行写"50x",设定打架 | 🔴 老白抓BUG弃书 |
| P7. 缺长期钩子 | 4-7章后无悬念锚点 | 🟡 中 |

**新规则(2026-07-03v2,签约前4-7章硬要求)**:

| 要求 | 标准 | 反例 |
|---|---|---|
| **每章必有1个"硬爽点"** | 真实亏一笔大钱+真实返利,数字闭环 | Ch4原版:只有"嘴硬",没数字爽点 |
| **每章爽点≥3个** | 含硬爽点+情感爽点+伏笔爽点 | Ch4原版:1个 |
| **每章钩子≥3个** | 主钩+副钩+暗钩 | Ch4原版:2个 |
| **数字曲线平滑** | 单章返利倍数跳跃 ≤ 2级 | Ch6原版:20x→200x(跳10倍)❌ |
| **同钩子不超2次** | 一个伏笔/桥段全卷累计出现次数 | "蛋炒饭"3次❌ |
| **章内逻辑自洽** | 系统提示+数字+状态前后一致 | Ch6:20x/40x/50x打架❌ |
| **第4-7章必有"差点被坑"** | 主角险境+反杀,张力 | Ch5原版:太顺,无险境❌ |

**修复案例**(起点Ch4-7重做方案):

| 章 | 原版 | 重做版 |
|---|---|---|
| Ch4 | 1个爽点(嘴硬) | **3个**(5万变50万+母亲信了+反威胁司机) |
| Ch5 | 2个(反诉+要律师) | **5个**(险境+10万变100万+录音反转+500万到账+律师到场) |
| Ch6 | 1个(50万换1亿) | **3个**(50万换1000万+升级20x→30x+伏笔) |
| Ch7 | 3个(父女/母亲/蛋炒饭) | **4个**(500万+200万变4000万+父女+母亲追问) |

**曲线平滑改造**(起点):

| 原版 | 重做版 |
|---|---|
| 20x → 50x(跳2.5倍) | **20x → 30x → 50x → 100x**(每级+50%) |
| Lv.2→Lv.3"奖励2倍"硬塞 | **删除"升级奖励2倍"机制**,改"每次升级倍数+50%" |
| Ch6 50万换1亿(=200x,违和) | **Ch6 50万换1000万(20x)**,数字"正常的200倍"=50万,返1000万 |

**铁律**(2026-07-03v2):
- 签约前4-7章是"读者决定追不追读"的关键窗,**爽点密度=追读率**
- 数字曲线必须"看起来合理",**跳级不能超过2级**(20x直接到200x=读者立刻弃)
- 每个"硬爽点"必须"真实亏+真实返+数字闭环",不能"嘴硬当爽点"
- 已被网络小说读者证伪的反模式(主角靠嘴炮/系统BUG获利)**必须删除**

### G. 与剧情 pacing 锁的关系

A+B 是 pacing 锁的 **核心机制**,Day-N 时间线法 + 章内/章末数字双控 + 4-7章硬爽点红线 是 **配套约束**。

详见 `web-novel-production/references/AI质量双门.md` 的 "🚨 用户真正在意的崩塌:剧情 pacing 锁" 章节。

**核心一句话**: 用户对网文质量的第一优先级不是 AI 味,是**数字可信度 + 硬爽点密度**。AI 味可以"凑合看",**数字通胀读者立刻弃书**,**4-7章爽点稀薄读者立刻弃读**。

## F. 何时用 A+B

**触发条件**:
- 用户开新书是"亏钱返利"/"送钱"/"投资返还"/"打折返利" 等反向爽点题材
- 用户担心"数字通胀崩盘"
- 用户对单章返利数字跳跃敏感(番茄用户尤其敏感)
- 2026-07-03新增:用户反馈"4-7章爽点不够" → 用G0红线

**反之不适用**:
- 起点稳健升级流(10x → 50x 已足够,不需要日限)
- 重生流(回到过去没"日"的概念)
- 修仙流(等级空间巨大,日限反而不自然)
