### 4 类对话回声反模式(本会话实证)

#### 反模式 1:同一角色称呼回声(Ch11 实测)

**反例**(Ch11 第 9-300 行,被用户否决):

```markdown
"林总,医院那边传来消息——王建国今早 8 点心电图稳定。"
"嗯。"

"林总,我今天下午 2 点约了 3 老板——"
"嗯。"

"林总,下一步——是'假装外卖员'。"
"假装外卖员?"

"林总,假装外卖员——"
"嗯。"

"林总——"
"小川。"

"林总——"
"小川——你晚上 9 点去美团江城站找张德彪——"

[100+ 次 "林总——" / "嗯" 循环]
```

**为什么是凑字数**:
- 每组对话只推进 0-1 个信息("医院稳定" → "下午 2 点" → "假装外卖员" → 循环)
- 100 次对话 = 实际剧情只推进 3-5 个事件
- 真实作者会**合并对话**,一段话讲完 3-5 个事件

"林总,医院那边传来消息——王建国今早 8 点心电图稳定。500 万和解金昨天到账,不是空头支票,我让周映雪汉庭府那边对了一下确认。"

"嗯。"

"嗯。"

"林总,下一步——是'假装外卖员'。王大龙'这还没完',他可能告我们春风帮扶会不合法,告系统违法,告返利是诈骗。我们 4 个春风帮扶会的员工——我,3 老板——没送过一天外卖。王大龙要知道我们是不是真的有送外卖的过去,..."

**统计**: 100+ 段 → 4 段。剧情信息完整保留,字数从 5895→3522(-40%)。

## 🔍 自动检测器 v6(check_dash_stack_v6.py)

### 8 类反模式扫描

```python
import re
from pathlib import Path

def check_dash_stack_v6(path):
    """
    v6 检测器:扫 8 类对话回声反模式
    返回: (issues: List[(line_no, type, severity)], summary)
    """
    text = Path(path).read_text(encoding='utf-8')
    lines = text.split('\n')
    body = re.sub(r'^#.*$|^---$|^[\*\-]{3,}$', '', text, flags=re.MULTILINE)
    body = re.sub(r'\n{2,}', '\n', body).strip()
    
    issues = []
    
    # 类型 1:破折号堆(v5 已有)
    in_stack = False
    stack_start = 0
    for i, line in enumerate(lines, 1):
        s = line.strip()
        if s.startswith('——'):
            if not in_stack:
                in_stack = True
                stack_start = i
        else:
            if in_stack and (i - stack_start) >= 3:
                issues.append((stack_start, 'dash_stack', f'{i-stack_start} 行连续'))
                in_stack = False
    
    # 类型 2:同一角色称呼连续(本会话新增)
    prev_call = None
    call_start = None
    for i, line in enumerate(lines, 1):
        s = line.strip()
        m = re.match(r'^["""「]?(.{1,8})[""」]?\s*[—\-—]', s) or \
           re.match(r'^["""「]?(.{1,8})[""」]?\s*[—\-—]', s)
        if m:
            call = m.group(1)
            if call == prev_call:
                if call_start is None:
                    call_start = i - 1
            else:
                if call_start is not None and (i - call_start) >= 5:
                    issues.append((call_start, 'repeat_call', f'"{prev_call}"×{i-call_start}'))
                call_start = i
                prev_call = call
        else:
            if call_start is not None and (i - call_start) >= 5:
                issues.append((call_start, 'repeat_call', f'"{prev_call}"×{i-call_start}'))
            call_start = None
            prev_call = None
    
    # 类型 3:≤3 字短回声连续
    short_runs = []
    cur_start = None
    cur_count = 0
    for i, line in enumerate(lines, 1):
        s = line.strip()
        # 去破折号
        clean = re.sub(r'[——。""'']', '', s)
        if 0 < len(clean) <= 3:
            if cur_start is None:
                cur_start = i
            cur_count += 1
        else:
            if cur_count >= 3:
                short_runs.append((cur_start, cur_count))
            cur_start = None
            cur_count = 0
    if cur_count >= 3:
        short_runs.append((cur_start, cur_count))
    for start, count in short_runs:
        issues.append((start, 'short_echo', f'{count} 行短回声'))
    
    # 类型 4:重复短语(同一短语 3+ 次出现,行内)
    phrase_count = {}
    for i, line in enumerate(lines, 1):
        s = line.strip()
        # 提取 4-12 字短语
        for m in re.finditer(r'[\u4e00-\u9fff]{4,12}', s):
            p = m.group(0)
            phrase_count.setdefault(p, []).append(i)
    for phrase, locs in phrase_count.items():
        if len(locs) >= 5:
            issues.append((locs[0], 'repeat_phrase', f'"{phrase}"×{len(locs)} 次'))
    
    # 类型 5:破折号总数(粗指标)
    dash_total = body.count('——')
    if dash_total > 30:
        issues.append((0, 'dash_total', f'{dash_total} 个'))
    
    # 类型 6:破折号堆连续行(具体位置)
    # 已包含在类型 1
    
    # 类型 7:对话回合密度
    quotes = len(re.findall(r'[""「」]', body))
    wc = len(re.sub(r'\s', '', body))
    dial_density = quotes / max(wc / 100, 1)  # 每 100 字对话回合数
    if dial_density > 8:  # 健康:5-8, 注水:>10
        issues.append((0, 'dial_density', f'{dial_density:.1f}/百字(健康 5-8)'))
    
    # 类型 8:连续叙事段长度(防止对话独大)
    # 略,与 v5 铁律 1 重复
    
    return issues, {
        'wc': wc,
        'dash_total': dash_total,
        'short_runs': len(short_runs),
        'call_repeats': sum(1 for _, t, _ in issues if t == 'repeat_call'),
        'phrase_repeats': sum(1 for _, t, _ in issues if t == 'repeat_phrase'),
        'dial_density': dial_density,
    }


# === 调用示例 ===
issues, summary = check_dash_stack_v6('/path/to/ch.md')
print(f"章节: {summary['wc']}字 / {summary['dash_total']}破折号")
print(f"问题: {len(issues)} 处")
for line_no, issue_type, detail in issues:
    print(f"  L{line_no}: {issue_type} - {detail}")
```

## 📐 5 段推进链金标准(健康章节结构)

**对话回声病的解药 = 5 段推进链**(v5 铁律 1,本会话沿用):

```
幕一: 场景锚点 (200 字) → 时间/地点/人物状态
幕二: 1 段动作 (300-500 字) → 主角具体动作(取餐/打电话/上车)
幕三: 1-2 句对话 (200-400 字) → 关键对话合并(每个"X 说"段含 3-5 个信息)
幕四: 1 段结果 (800-1200 字) → 动作/对话产生的具体后果
幕五: 章末钩子 (400-600 字) → 下章悬念 + 角色心境
```

**对话段金标准**(避免回声):
- 每段对话 "X 说" 段,**包含 3-5 个完整信息**
- 不写"X 说 Y""X 说 Z""X 说 W"(3 段) — 合并为"X 说 Y,Z,W"(1 段)
- 对话推进剧情,不对话堆砌"称呼回声"

**叙事段金标准**(防止对话独大):
- 每章 ≥ 3 段 ≥ 80 字叙事段
- 叙事段带具体场景细节(煎饼摊/菜场/汽车站)
- 叙事段带具体物件(煎饼/红米手机/蛇皮袋/矿泉水)
