# 长篇连贯性测试脚本 6 项检测 (2026-07-26 焊死)

> **触发**：长篇项目 > 20 章必须配套 `scripts/consistency_test.py`，跑全 6 项检测。
> 本文件配套主 reference: `chapter_consistency_9checklist.md`（C1-C9 写前自检）。
> 关系：**6 项 = 写后自动跑，C1-C9 = 写前手动跑**。两套互补，**任何一套失败 → 重写章节**。

---

## 一、6 项检测 vs 9 类检查对照

| 检测层 | 类型 | 工具 | 时机 | 失败动作 |
|---|---|---|---|---|
| **6 项自动检测** | 字数/伏笔/数字/人物/规则/章末 | `scripts/consistency_test.py` | 写后全章 | 必修该章 |
| **9 类手动自检** | C1-C9（时间线/数字/剧情反转/大纲越界/角色抢戏/倍数/日限/副作用/爽点） | `chapter_consistency_9checklist.md` | 写前+写后 | 必修该章 |

**铁律（2026-07-26 焊死）**：
- 写完一章 → **两套都跑**：先 6 项自动（30 秒），再 9 类手动（5 分钟）
- 任何一套失败 → 不允许 commit，必须重写或 patch

## 二、6 项检测详细规格

### 检测 1：字数合规

**算法**：
```python
import re
with open(file, encoding='utf-8') as f:
    text = f.read()
# 找正文结束位置（排除末段自检 + 章末标注）
body_end = text.find('**第')
for marker in ['**第一章 完**', '**第二章 完**']:
    idx = text.find(marker)
    if idx > 0: body_end = idx
body = text[:body_end]
clean = re.sub(r'^#.*$', '', body, flags=re.M)
clean = re.sub(r'\n+', '', clean)
hanzi_count = len(re.findall(r'[\u4e00-\u9fff]', clean))
```

**阈值**：2400-3600 汉字（3000±20%，字数标准 v7）

**失败动作**：超 3600 → 砍字（参考 `砍字与新书开坑实战_2026-07-26.md`）；不足 2400 → 扩字（参考 `扩字模式_v6_对话回声病_2026-07-07.md`）

### 检测 2：伏笔一致性

**算法**：
```python
# 解析 outline/设定.md 中的伏笔表
import re
pattern = r'\| (F\d+) \| (.+?) \| Ch(\d+) \| Ch(\d+) \|'
hooks = []
for m in re.finditer(pattern, outline_text):
    hook_id, content, planted, redeemed = m.groups()
    planted_n = int(planted)
    redeemed_n = int(redeemed)
    # 过滤占位行（"—" 占位）
    if '—' in content or '-' in content[:3]:
        continue
    hooks.append({...})
# 验证 1: 埋入章 < 回收章
# 验证 2: 回收章 ≤ 目标章数 (120)
# 验证 3: 埋入章 ≤ 已写章节数 (警告, 不是错误)
```

**反例（本会话实战）**：
- 表格里的 `—` 占位行被误判为伏笔 → 必须过滤

**失败动作**：planted >= redeemed → outline 错了；redeemed > 120 → 终局章号错了

### 检测 3：数字一致性

**算法**：锁死关键数字，全文 grep 反向变体

**关键数字表**（卷一为例）：
```python
LOCKED_NUMBERS = {
    "门外14人": ["十五个", "十三个", "十二个", "15个", "13个", "12个"],
    "收容队围城47人": ["48个", "46个", "49个"],
    "倒计时47天": ["48天", "46天", "50天"],
    "100+活人": ["99个", "101个"],
}
```

**失败动作**：命中反向变体 → 章节数字错了，必须 patch 修

### 检测 4：人物一致性

**算法**：解析人物谱 → 统计角色名 × 章号矩阵

**输出**：
```
林默: 出现 3 次 (Ch1-Ch3)
周磊: 出现 3 次 (Ch1-Ch3)
那个男孩: 出现 2 次 (Ch2-Ch3)
```

**失败动作**：角色前后矛盾 / 角色"前章已死还在说话" → 必修章节

### 检测 5：规则一致性

**算法**：6 条原文 + 反向变体黑名单

**锁死规则**（《末日便利店》）：
```python
LOCKED_RULES = {
    "R1": "本店禁止任何暴力行为",
    "R2": "本店不换记忆",
    "R3": "本店商品由店员自行定价",
    "R4": "概不赊账",
    "R5": "本店欢迎活人",
    "R6": "本店不得倒闭",
}
BAD_VARIANTS = {
    "本店禁止任何暴力行为": ["本店允许任何暴力", "本店不禁止暴力"],
    "本店不换记忆": ["本店可以换记忆", "本店换记忆"],
    "概不赊账": ["可以赊账", "欢迎赊账"],
    "本店不得倒闭": ["本店可以倒闭", "本店可以关门"],
}
```

**失败动作**：命中反向变体 → 章节破坏规则，必须重写

### 检测 6：章末钩子

**算法**：每章必带「第N章 完」+「末段自检」

```python
# 中文章号转换
cn_nums = "〇一二三四五六七八九十"
if ch_n < 11:
    cn_n = cn_nums[ch_n]
elif ch_n < 20:
    cn_n = "十" + cn_nums[ch_n - 10]
# ...
# 粗体兼容
end_markers = [
    f"第{cn_n}章 完", f"第{cn_n}章完",
    f"**第{cn_n}章 完**", f"**第{cn_n}章完**",
    f"第{ch_n}章 完", f"第{ch_n}章完",
    f"**第{ch_n}章 完**", f"**第{ch_n}章完**"
]
```

**失败动作**：未检测到 → 章节没标完/没写末段自检，必须补

## 三、5 个踩坑 + 修复（本会话实战 2026-07-26）

| 坑 | 症状 | 修复 |
|---|---|---|
| **1. 路径兜底** | `CHAPTERS_DIR = Path(sys.argv[1])` 移到 scripts/ 后找不到目录 | 加 `Path(__file__).parent.parent` 兜底 |
| **2. 中文章号转换** | `ch_n = "1"` 拼"第1章 完"但正文是"第一章 完" → 不匹配 | 加 `cn_nums = "〇一二三四五六七八九十"` 转换 |
| **3. 粗体标记** | 文中 `**第一章 完**` 带粗体，纯文本检测不到 | 加粗体兼容：4 种格式都试 |
| **4. 伏笔 regex 转义** | 表格分隔符 `\|` 在 Python 字符串里双重转义 | 用 raw string `r'\| (F\d+) \|'` |
| **5. 占位行误判** | outline 表格里的 `—` 占位行被当成伏笔 | 加占位符过滤：`if '—' in content: continue` |
