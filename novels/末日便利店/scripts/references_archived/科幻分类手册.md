# 科幻分类参考手册 (2026-07-04)

> ⚠️ **数据来源声明**: 基于行业知识 + 经典头部作品(《三体》《流浪地球》《全球高武》《深空彼岸》《暗月纪》等)经验。**科幻涉政涉科技争议大**——尤其涉及AI、外星、末世题材。

## 一、5种已验证的科幻金手指爆款模式

### 模式1: 末世求生型(《全球高武》《超级神基因》)
**核心**: 末世/灵气复苏/异变 → 普通人觉醒 → 一路升级到强者
**爽点公式**: 末世降临 → 主角觉醒异能 → 击败异族/丧尸 → 建立势力
**优势**: 升级感强 + 受众广(男频主战场)
**🔴红线**: 不能详细描写"瘟疫/病毒扩散机制"——涉公共卫生敏感

### 模式2: 星际文明型(《深空彼岸》《吞噬星空》)
**核心**: 主角有金手指/系统 → 在星际中崛起 → 称霸星域
**爽点公式**: 修炼科技 → 触发星际战争 → 跨文明对决 → 称霸银河
**优势**: 格局大 + 升级感强(吞噬星空模式)
**铁律**: 星球/种族名字要虚构,不能直接用"地球/America"

### 模式3: AI 觉醒型(《超神机械师》《全球进化论》)
**核心**: 主角是AI工程师/有AI系统 → 制造/觉醒超级AI → 改变人类文明
**爽点公式**: 设计AI → AI爆发 → 震惊人类 → 影响国际格局
**🔴红线**: 不能写"AI取代人类/AI威胁论"——涉政敏感(2026年AI恐慌期)

### 模式4: 异界穿越型(《我在异界当大佬》)
**核心**: 现代人穿越到魔法世界/异星球 → 用现代知识碾压 → 称霸
**爽点公式**: 知识碾压 → 装备碾压 → 势力碾压 → 反派跪服
**优势**: 接近玄幻的爽感 + 差异化的世界观
**铁律**: 异世界规则必须一致(不能"前期说不能飞,后期主角飞")

### 模式5: 时空穿越型(《时空之门》《我在两千年后造物》)
**核心**: 主角有时光机/时空系统 → 穿梭古今 → 改变历史 / 拯救未来
**爽点公式**: 穿梭 → 关键事件改动 → 蝴蝶效应 → 历史惊人反转
**优势**: 历史 + 科幻双重
**🔴红线**: 不能写"改变1840后历史"或"拯救建国后事件"

## 二、科幻头章5幕结构实战模板

### 幕一·开场冲突(500字)
- 时代/世界观设定:**地球末世/2050年星际/外星降临**
- 主角处境: 底层科研员/普通人/穿越者/重生者
- 数字锚点: 修为/科技等级/装备等级
- 刺激源: **外星第一波入侵/末世爆发/文明崩塌**

### 幕二·规则铺陈(500字)
- 觉醒/金手指瞬间(脑海一声响/手腕抖/手机屏幕一黑)
- 力量/科技系统一次说清: 等级、技能、禁区
- 主角反应: 不信 → 试探 → 接受
- 金句: "文明的火种,从来都不是天赐的,而是靠自己点燃。"

### 幕三·试探验证(500字)
- 主角展示第一招 → 震惊围观者
- 小事件验证金手指
- 关键钩子: **外星第一波入侵即将来袭**

### 幕四·第一爽点(500字)
- 一次完整的反杀/救援/胜利(击杀一只入侵者/拯救一群人)
- 围观震惊:普通人/军方/科研院
- 主角金句 + 反派压力(更强的敌人逼近)
- 内心独白: 使命感 + 个人的复仇交织

### 幕五·钩子反转(500字)
- 更大势力登场/更高级文明出手
- 暗钩子: 远方的信号/其他神秘的觉醒者
- 主线压住: 7天内必须准备第二波入侵防御

## 三、科幻爽点密度标准

| 阶段 | 每章爽点数 | 钩子数 |
|---|---|---|
| 头三章 | ≥4 | ≥3 |
| 卷一前30章 | ≥3 | ≥2 |
| 卷一中段 | 1-2 | 1-2 |
| 卷一高潮(每20章) | 5+ | 3+ |
| 卷二/卷三 | 1-2/章 | 1-2/章 |

**铁律**: 科幻比玄幻节奏稍慢,但**每个爽点必须有"科技感/未来感"包装**(装备名称/技能特效)

## 四、🔴科幻红线(必查)

### 安全度评级

| 题材 | 安全度 |
|---|---|
| 末世/灵气复苏 | ⚠️黄(避开瘟疫/病毒细节) |
| 星际/外星 | ✅绿(完全自由) |
| AI觉醒 | 🔴红(避免AI取代/威胁论) |
| 时间穿越 | ⚠️黄(避开1840后历史) |
| 黑科技/机械飞升 | ✅绿(完全自由) |
| 异世界穿越 | ✅绿(完全自由) |
| 现实近未来 | 🔴红(避免详细化) |
| 太空歌剧(星际战争) | ✅绿 |

### 🔴绝对禁止
- ❌ AI 觉醒取代/威胁人类叙事(2026年AI恐慌期)
- ❌ 详细描写瘟疫/病毒扩散机制
- ❌ 把外国领导人/科学家丑化
- ❌ 抹黑中国科技公司/科研机构
- ❌ 涉及"中国人打中国人"的未来战争
- ❌ 把当代武器(核弹/弹道)与未来战争挂钩

## 五、科幻伏笔5条起步包

- **F001**: 金手指源头 → 卷末回收(来自外星文明/神级系统/未来人)
- **F002**: 主角前世人 → 中段回收(前世是某星球的幸存者)
- **F003**: 反派文明 → 卷二揭露(反派身份为何,要避开现实映射)
- **F004**: 神秘信号 → 卷一末解释(可能有更大的神明级存在)
- **F005**: 上古文明的遗迹 → 卷三反杀(藏着人类真正的进化钥匙)

## 六、科幻口头禅库

| 类型 | 例子 |
|---|---|
| 热血型 | "这星海,我来保护。" |
| 智斗型 | "宇宙的黑暗森林,从来就不只是厮杀。" |
| 镇压型 | "在科技面前,所有的神话只是未解的方程。" |
| 反讽型 | "人类啊,自以为是宇宙中心太久了。" |
| 求索型 | "我们不是孤独的,但愿如此。" |

## 七、AI产科幻文 4 大陷阱

1. **科技乱配**: 量子计算机 vs 量子手机混用 → 严格按科学术语
2. **尺度失真**: 太阳系大小/光年/纳米乱用 → 查科学数据
3. **政治失语**: 未来国家描述 → 不能直接对应现实
4. **AI失禁**: 写到AI必须有"可控性"——不能写AI觉醒威胁人类

## 九、科幻开坑建议方向

### 🟢 方向1: 末世求生(签约最快)
- 主角: 普通青年
- 金手指: 灵气复苏/系统觉醒
- 反派: 异族/丧尸/恶劣环境
- 安全度: ⚠️黄

### 🟢 方向2: 星际崛起(差异化最强)
- 主角: 佣兵/学员/天才
- 金手指: 系统/时空系统
- 反派: 外星文明/异星族
- 安全度: ✅绿

### 🟢 方向3: 时空穿梭(历史科幻交叉)
- 主角: 工程师/科研员
- 金手指: 时空装置
- 反派: 时间特务组织
- 安全度: ⚠️黄(避开当代)
