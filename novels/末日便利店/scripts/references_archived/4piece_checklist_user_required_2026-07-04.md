# 4 件套必含 checklist (2026-07-04 焊死 — 用户钦定)

## 用户原话 (2026-07-04 v0.5.4)

> "注意剧情连贯性, 爽点装比打脸, 泡妞"

这是**用户铁律级硬偏好**, 跟 7 月 3 日的"4 件套铁律"一致, 但本次**用户主动重申** = 优先级升级.

## 4 件套逐项拆解

### 1. 爽点 (Pleasure Points)

**定义**: 数字冲击 + 反差 + 主播炫技

**男频公式**:
- **Lv.1 (起步)**: 单笔花 1 元变 200 元 → 主播炫技"我花 1 块, 系统返 200"
- **Lv.2 (升级)**: 单笔花 1 万变 1000 万 → 主播炫技"我花 1 万, 系统判商业+花冤, 返 1000 万"
- **Lv.3 (高级)**: 单笔花 50 万变 1 亿 → 主播炫技"50 万请调查公司, 2500 万到账"
- **Lv.5 (终极)**: 单笔花 1 亿变 1 万亿 → "让子弹飞一会儿, 10 万亿到账, 撒花!"

**单章爽点密度**:
- Ch1-3: 3-4 个 / 章
- **Ch4-6 (签约生死线)**: **5-7 个 / 章** (用户拍板重点)
- Ch7+: 3-5 个 / 章 (签约后稳定)

### 2. 装比 (Showing Off)

**定义**: 用钱买到**常人买不起**的场景, 制造视觉/感官冲击

**5 级场景升级表 (起点番茄通用)**:

| 章节段 | 场景 | 数字量级 |
|---|---|---|
| Ch1-3 | 送外卖 / 蹲路边摊 / 月租房 | 元/万 |
| **Ch4-6** | **五星酒店 / 60 万茅台 / 商务车 / 高档餐厅** | **万/十万** |
| Ch7-15 | 私人会所 / 商会 VIP / 慈善晚宴 | 十万/百万 |
| Ch16-30 | 收购 / 做局 / 反向控股 | 千万/亿 |
| Ch30+ | 飞机 / 游艇 / 海岛 / 跨国 | 十亿/百亿 |

**装比必含元素** (每章至少 1):
- ✅ 主角说出"这顿算我请" / "买这个送给我妈"
- ✅ 系统提示音/银行短信**当场到账**
- ✅ 周围人震惊反应 ("3 个老板都看傻了")
- ✅ 反派开始不安 ("王大龙咬了咬牙")

### 3. 打脸 (Face-slapping)

**定义**: 反派嘲讽 → 主角反杀闭环, **每章至少 1 次完整循环**

**3 步打脸模板**:
```
[场景 A] 反派嘲讽
  反派:"林北舟, 你这loser, 看什么看? 老子用钱砸死你"

[场景 B] 主角不接茬 (暗示后手)
  主角笑了一下, 拨了个电话

[场景 C] 反杀时刻 (数字冲击 + 反派破防)
  反派手机响 → 短信: "您账户 X 元已被划扣, 余额 0"
  反派跪了/被带走/上江城日报
```

**打脸对象池** (起点):
- 王大龙 (江城首富之子, 本地型)
- 张德彪 (外卖站长, 看人下菜)
- 苏婉清 (前妻回头型, 决绝型)

**打脸对象池** (番茄):
- 顾秀芝怀疑传销 (妈被主角用系统化解决)
- 便利店老板 (花冤钱反击, 让他服气)
- 程建国派人接程晚棠 (被主角挡住)

### 4. 泡妞 (Female Companionship)

**定义**: 新女主登场 + 暧昧升级 + 节奏把控

**节奏铁律** (7月3日已焊死, v0.5.4 重申):
- ❌ Ch20+ 才让女主出来 (读者等不及弃书)
- ✅ **Ch4 或 Ch5 让新女主因业务关系自然登场**
- ✅ Ch6-8 暧昧升级 ("缘分"三连)
- ✅ Ch10-15 确认关系
- ✅ 女主**不能跟主角前妻撞性格** (起点前妻"现实回头型" → 周映雪"聪慧独立不回头型")

**女主性格三件套** (避免"工具人"):
- ✅ 有自己的职业 (不为男主存在的花瓶)
- ✅ 有自己的家族/资源 (可反哺剧情)
- ✅ 有自己的秘密/伏笔 (卷末揭晓, 推动剧情)

**女主姓氏避雷** (双本同时跑):
- 起点女主: 周映雪 (江城周氏酒店二小姐)
- 番茄员工/暧昧: 楚映雪 (深圳, 注意!**不能叫周映雪, 跨本重名**)

## 何时不能省 4 件套

| 场景 | 可以省 | 必含 |
|---|---|---|
| 阶段性高潮章 (Lv 升级) | 否 | 必含爽点装比, 打脸可弱 |
| 纯过渡章 (搬家/接电话) | 否 | 至少爽点+1件套保底 |
| 番外 (回顾前情) | 可 | 4件套可弱, 但人设语气必须一致 |
| 数据卡章节 (纯数字) | 否 | 这种章节不写 |

## 如何判断一件套写得"够"

| 件套 | 不够的标志 | 够的标志 |
|---|---|---|
| 爽点 | "主角又赚了一千" | 主角**主动花冤**+ 系统返利倍数 + 主角炫技金句 |
| 装比 | "主角住在五星酒店" | 主角说出"这顿算我请"+ 周围人震惊反应 + 系统到账 |
| 打脸 | "反派很生气" | 反派嘲讽具体话 + 主角不接茬 + 反杀具体后果 (上新闻/被查) |
| 泡妞 | "有个女生在主角身边" | 女生有自己的台词 + 跟主角有具体对话 + 暗示关系进展 |

## 与"剧情连贯性"铁律的关系

4 件套是**形式**, 剧情连贯性是**内容**.

正确顺序:
1. 先列剧情连贯性清单 (事实清单 7 项 — 见 web-novel-production/references/起点ChN续写_接续约束与新女主避雷_2026-07-03.md)
2. 再按 4 件套填充每章
3. 检查 5 遍: 接续 + 4 件套 + 字数 + 钩子 + 人设语气

**反例**: 只追 4 件套不接续 → 装比用 Ch1-3 没有的"法拉利" → 用户喷"内容不连贯"
**反例**: 只追连贯性不写 4 件套 → 章节平淡读者弃书 → 用户喷"4 件套不够"
