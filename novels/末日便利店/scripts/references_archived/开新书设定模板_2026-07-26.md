# 开新书设定模板 (2026-07-26 焊死 — 末日便利店验证版)

> 本模板基于《末日降临，我的便利店禁止打烊》第 1 章产出 (commit 680c8c3) 验证通过。
> 适用: 单本新书第 1 卷 Ch1-Ch10 的设定文件 (写满后再考虑迁 novelforge codex.json)。

## 文件位置 (Riky- + Desktop + mempalace 三处同步)

```
Riky-/novels/<书名>/outline/设定.md         ← GitHub 真源
Desktop/我的网文/<书名>/outline/设定.md      ← 用户图形界面 (RustDesk 可见)
~/.hermes/mempalace/novel/outline/设定.md     ← DS-0 内接真源 (可选)
```

## 模板 7 块必含 (按顺序)

### 1. 类型 / 平台
```markdown
## 类型 / 平台
- 男频 / 女频
- 题材 (多标签用 +)
- 首投平台
- 卷一目标: 30 章 / 8-10 万字 / 1 卷 1 完整剧情弧
```

### 2. 一句话卖点
```markdown
## 一句话卖点
[1 行, 用于番茄简介 / 起点书封]
格式: [背景冲突] + [主角身份/金手指] + [核心矛盾]
例: 末日第十三天, 全城陷入规则污染; 我继承的那家 24 小时便利店, 成了方圆三公里内最后一块「不能违反的交易场所」。
```

### 3. 主角档案
```markdown
## 主角档案
- 姓名: [2 字 / 3 字, 不要和已有任何书主角重名]
- 年龄: [25-30 区间, 最有读者代入感]
- 原职业: [让主角具备"为什么能开这家店"的合理性]
- 性格: [3-5 个标签, 不要超过]
- 声线标签: [话多 / 话少 / 冷幽默 / 偏执]
- 口头禅: [2-3 个, 用于对话辨识度]
```

### 4. 金手指 (系统) 表
```markdown
## 金手指: <系统名>
[不是直接送无敌, 而是解锁某种能力]

| Lv | 解锁能力 | 升级条件 |
|---|---|---|
| Lv.1 | [...] | 开局默认 |
| Lv.2 | [...] | [...] |
| Lv.3 | [...] | [...] |
| Lv.4 | [...] | [...] |
| Lv.5 | [...] | [...] |

铁律: Lv.1 不能给战斗能力, 只能给"认知/经营/判断"能力. 升级条件必须有"经营动作" 不是"杀敌数".
```

### 5. 末日核心规则 (前后一致铁律)
```markdown
## 末日核心规则 (必须前后一致)
1. [规则 1 - 必有"店内"维度]
2. [规则 2 - 必有"等价交换"维度]
3. [规则 3 - 必有"时间"维度]
4. [规则 4 - 必有"危险等级"维度]
5. [规则 5 - 必有"商品/定价"维度]

铁律:
- 规则一旦定下, 后续章节不能推翻或放宽
- 规则之间不能自相矛盾
- 规则必须有"可被主角利用"的漏洞空间 (否则爽点出不来)
```

### 6. 卷一主线 (30 章分 3 段)
```markdown
## 卷一主线 (30 章)
- **第 1-10 章**: [开场 + 第一条规则 + 第一批顾客 + 第一个事件]
- **第 11-20 章**: [中期升级 + 反派登场 + 第一个契约]
- **第 21-30 章**: [真相揭露 + 最终危机 + 卷一终局]

## 卷一终局钩子
[30 章后主角到达什么状态 / 揭露什么秘密 / 留什么悬念给卷二]
```

### 7. 前 10 章细纲表
```markdown
## 前 10 章细纲 (章节目录)

| 章 | 标题 | 核心冲突 | 章末钩子 |
|---|---|---|---|
| 1 | [...] | [...] | [...] |
| 2 | [...] | [...] | [...] |
| ... |
| 10 | [...] | [...] | [...] |

铁律:
- 每章"核心冲突"必含 1 个具体事件 + 1 个新规则元素
- 每章"章末钩子"必指向下一章 + 留长线伏笔
- 前 3 章必出"金手指第一次验证", 前 5 章必出"反派伏笔"
```

## 反例 (2026-07-26 已踩)

- ❌ 没写规则表 → 写到 Ch3 时规则自相矛盾, 推倒重来
- ❌ 主角档案只写"性格坚韧" → Ch1 写出来主角没辨识度, 像模板
- ❌ Lv.1 给主角战斗能力 → 后续所有章都"以力破巧", 经营线废掉
- ❌ 卷一主线写"主角成神" → 30 章根本写不完, 烂尾
- ❌ 前 10 章细纲只有标题没有核心冲突 → 写到 Ch4 卡壳, 不知道该写什么

## Ch1 配套模板 (本会话 4619 汉字版, 验证可用)

参考 `chapters/<书名>_第1章_<标题>.md` 实际产出。

要点:
1. **开头即冲突** (玻璃门被推开 + 死人拿硬币, 不用任何铺垫)
2. **金手指第一幕** (硬币里传出"本店禁止任何暴力行为")
3. **第一次验证** (死人遵守规则, 成交瞬间碎成灰雾)
4. **第二个角色埋入** (周磊 + 旧世界同事关系 → 卷一长线伏笔)
5. **章末钩子指向下一章** (周磊名片背面: "林默, 乐淘四楼, 末日第一天, 你来过这里")

## 与 novelforge codex.json 的关系

| 阶段 | 用什么 |
|---|---|
| 新书 Ch1-Ch5 | 设定.md (本模板, 轻量) |
| 新书 Ch6-Ch10 | 设定.md + chapters_meta.json (半自动) |
| 新书 Ch10+ | 迁 codex.json (完整 novelforge) |
| 卷二起 | 必须用 codex.json (设定.md 不够用) |

迁 codex.json 的信号: 角色超过 6 个 / 伏笔超过 4 条 / 卷二开始有跨卷时间线。
