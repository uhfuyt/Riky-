
## 八、3 类历史教训焊死(2026-07-04)

### 教训 1: 子 Agent delegation API 频繁 404
- 现象: 子 Agent 返回 `API call failed after 3 retries: HTTP 404`
- **本质**: 子 Agent 平台工具调用不稳 — **不是本会话模式问题**
- 应对:
  - 检测: 若 `api_calls_made=0` + 短时间(< 30s) + status=completed = **假阳性**
  - 行动: **不用子 Agent**,改用主对话窗口直写
  - 重试: 单独派子 Agent 调试,而不是连派多次

### 教训 2: 服务器 IP 反爬屏蔽要诚实标注
- 现象: 起点 / 番茄 / 龙空 / DDG / Bing 全部用 209 byte 空壳页挡住
- **本质**: 新加坡机房 IP(100.90.63.122)被多家网站屏蔽 — **环境约束,不是工具坏了**
- 应对:
  - 检测: `curl -A 'Mozilla/5.0'` 拿 < 500 bytes + title "error" = 反爬命中
  - 行动: **不要硬爬**,改用"模型知识 + 三件套兜底"
  - 例外: 用户手动 patch 数据时 = 用 ChatGPT Web 或手动复制

### 教训 3: SKILL references 已有的低版是隐患
- 现象: 我派子 Agent 5 个分类,但发现 `web-novel-production/references/` 早就有了 5 个分类手册(6-8K)
- **本质**: 我没提前扫仓库,产生重复工作
- 应对: **任何产出前先 ls + grep related**,避免漏抄 `references/` 已有的成果
