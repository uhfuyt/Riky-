# 卷三重写方案：从"移动店铺"改为"垂直向下扩张"

## 核心改动逻辑

**老问题**：61章开始便利店"跨城移动"→拆了"固定安全屋"的核心设定
**新方案**：便利店原地不动，系统解锁的是"垂直向下扩张权限"

## 具体改动

| 旧版 | 新版 |
|------|------|
| 61 店铺第二次移动（跨城200公里） | 61 倒计时归零——解锁的不是移动，是向下 |
| 62-64 跨城传送、废墟探索 | 62-64 便利店往下挖，发现地下一层空间 |
| 65-68 废墟店长（另一城市） | 65-68 地下一层的"前任店长"（他一直在这里的地下） |
| 69-70 收容队跨城追踪 | 69-70 收容队围城升级，发现便利店在往下长 |
| 71-79 旧世界超市在另一城市 | 71-79 旧世界超市在便利店**地下三层** |
| 88-90 第二家便利店在废墟建 | 88-90 地下一层独立运营，同一栋楼两层店 |

## 地理逻辑

- 便利店：地面一层（不变）
- 地下一层：新空间，旧世界超市的上层遗迹
- 地下二层：旧世界超市主体
- 地下三层：旧世界超市核心（赊账系统的发源地）

**物理锚定不动，深度制造压迫感。越深越古老、越危险、规则越黑暗。**
