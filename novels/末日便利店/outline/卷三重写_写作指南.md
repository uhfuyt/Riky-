# 卷三正文重写写作指南（子Agent用）

## 核心设定（锁死，不可偏离）

**设定变更：** 便利店原地不动 → 倒计时归零后解锁"向下扩张权限"（不是跨城移动）
**地下结构：**
- 地下一层：空的，规则文字字体更旧（礼帽男人第一个实验的所在地）
- 地下二层：旧世界超市的遗迹，负数价签、赊账系统发源地
- 地下三层：旧世界超市核心（赊账系统的最终源头）

**8条核心规则（必须始终遵守）：**
1. 本店禁止任何暴力行为 → 违者强制清零
2. 本店不换记忆
3. 本店商品由店员自行定价
4. 每笔交易必须等价交换
5. 每日23:00-01:00为非人时段
6. 店门外24小时可见污染等级
7. 店员不可离开店铺超过100米超过10分钟
8. 本店概不赊账（林默自加）

**新增/变化：**
- 第10条规则"本店不得倒闭"——亮度已降至10%，形同虚设
- 倒计时归零≠结束——实际是"债务追索期"开始
- 便利店+地下层共用同一套系统底座（705机器的编码器在地下）

## 写作风格

**叙事视角：** 林默第一人称限制视角（只写他看到的、推理到的、感受到的）
**句式风格：** 
- 短句为主，节奏紧凑
- 场景细节丰富（温度/光线/触感/气味全写出来）
- 推理感强（林默通过观察得出结论的过程）
- 避免内心独白超过3句——用行动和发现代替情感描述

**每章结构：**
```
头部（~500字）：承接上章 + 新问题出现/新发现
中部（~1,500-2,000字）：核心内容（交易/探索/规则碰撞/冲突）
尾部（~500-800字）：新线索 + 章末钩子（悬念/秘密/代价）
```

**每章必须包含至少1个：**
- 交易场景（有人拿东西换东西，或有"等价交换"的博弈）
- 秘密/线索揭示（至少一个推进主线的新信息）
- 章末钩子（让读者想点下一章）

**目标字数：** 每章3,000字（±200字浮动）
**文笔参考：** 对标Ch001和Ch060的风格——冷静、细节扎实、不煽情

## 文件命名规范
`末日便利店_第XXX章_标题.md`
示例：`末日便利店_第061章_倒计时归零.md`
注意：分隔符统一用下划线 `_`，第XXX章后加下划线，标题用中文。
