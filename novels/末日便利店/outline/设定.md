# 《末日降临，我的便利店禁止打烊》 — 设定总览

## 类型 / 平台
- 男频 · 末日经营 + 规则怪谈 + 轻系统
- 首投：**番茄**
- 卷一目标：30 章 / 8-10 万字 / 1 卷 1 完整剧情弧

## 一句话卖点
末日第十三天，全城陷入规则污染；我继承的那家 24 小时便利店，成了方圆三公里内最后一块「不能违反的交易场所」。

## 主角档案
- 姓名：林默
- 年龄：27
- 原职业：连锁便利店区域督导，三个月前被总部以「门店亏损」为由裁员，合伙人卷款跑路，背着 18 万网贷
- 性格：观察细、会算账、不轻信、不冲动、能忍但不软
- 声线标签：话少、说话带点冷幽默、关键时刻能拍板
- 口头禅：「我不做赔本买卖」「货真价实，概不赊账」

## 金手指：安全区经营系统
不是直接送无敌，而是**解锁经营能力**：

| Lv | 解锁能力 | 升级条件 |
|---|---|---|
| Lv.1 | 商品鉴定 / 顾客危险评级 / 规则漏洞提示 | 开局默认 |
| Lv.2 | 安全范围扩大至 50 米 / 顾客契约（口头协议具法律效力）/ 物资合成 | 完成第 1 次「午夜事件」且无规则违约 |
| Lv.3 | 异常事件预警（24h 前）/ 商品保鲜时间消失 / 店员招募位 1 | 单日营业额达 500 末日币 |
| Lv.4 | 店铺可移动（每日一次）/ 分店位 1 | 解锁任一规则怪谈的真相 |
| Lv.5 | 跨区域传送（需付末日币）/ 主动关闭安全区 5 分钟 | 卷一终局任务完成 |

## 末日核心规则（必须前后一致）
1. **商店内禁止任何暴力行为**（含语言威胁），违者强制「清零」（记忆 + 随身物资）
2. **每笔交易必须等价交换**，店员不能主动赠送，找零必须真实存在
3. **每日 23:00-01:00 为「非人时段」**，期间进店的顾客不一定是人
4. **店门外 24 小时可见的「污染等级」**，等级越高，门外越危险
5. **商品定价必须由店员自行决定**，不能参考旧世界价格，否则商品作废

## 卷一主线（30 章）
- **第 1-10 章**：店铺继承 → 第一条规则 → 第一批顾客 → 午夜事件 → 第一个幸存者员工
- **第 11-20 章**：污染扩散 → 第一块「污染核心」被发现 → 反派「收容队」登场 → 第一个契约
- **第 21-30 章**：规则怪谈真相 → 店铺升 Lv.4 → 反派总攻 → 卷一终局（店铺可移动）

## 卷一终局钩子
店铺可以移动的瞬间，系统的隐藏创建者第一次显形：不是神，是一个**被困在规则里的旧世界店长**，他建这套系统是为了让「自己店里那场没救出来的人」活一次。
