# 《破财转运牌:花掉一块来一万》— 番茄版核心设定

## 一、世界观

**现代都市·深圳·2026年7月**

主角顾行舟,24岁,2026届毕业生,普通一本市场营销专业。

父亲顾建国3年前"病逝"(实际是被沈氏资本做空逼死,F001主线锚点),母亲顾秀芝(40岁)在老家摆煎饼摊,独自把他拉扯大。

毕业后投了200份简历,被拒20次。信用卡欠10万,网贷欠5万。

2026年7月1日,他坐大巴从老家到深圳,准备最后一搏找工作。卡里只剩**5块钱**。

**金手指触发**:在二手市场花5块钱买了块破旧怀表,打开盖子一看,内盖内侧有一行半透明的字,只有他看得见:

> **【破财转运牌·已激活】**
> 宿主:顾行舟 | 等级:Lv.1
> 累计花销:0元 | 累计返利:0元
> 规则:宿主每产生一笔"**花得冤**"的实际支出,返利200倍。
> 注:仅限商业行为。日常吃饭/交通/房租/水电不算。
> **特别条款**:每日返利有"日限额",24小时内花不出去,当日额度清零。
> **副作用提示**:等级越高,身边人越会"主动帮宿主省钱"(Lv.3后解锁)。

**核心反差**:别人拿到钱第一反应是"我发财了要省着花",他第一反应是"我得赶紧把它**花得冤**出去才能真发财"——而且**花不出去额度就清零**,逼他天天破产。

## 二、金手指规则(铁律)

### 等级曲线(起步200x,逐步提升)

| 等级 | 累计"花得冤" | 返利倍数 | 日限额 | 解锁新功能 |
|---|---|---|---|---|
| Lv.1 | 0-1万 | **200x** | 1万/日 | 基础返利 |
| Lv.2 | 1-10万 | 500x | 10万/日 | "主动花销任务"(可发起超额返利,但有失败惩罚) |
| Lv.3 | 10-100万 | 1000x | 100万/日 | "信用透支"(可预支未来返利50%) + 身边人"帮省钱"副作用 |
| Lv.4 | 100-1000万 | 5000x | 1000万/日 | 等级越高,身边人"帮省钱"力度越强 |
| Lv.5 | 1000万+ | 10000x | 无上限 | 系统本体开始出现(后期揭示) |

### "花得冤"判定(铁律)

| 算"冤" | 不算"冤" |
|---|---|
| ✅ 商业投资失败 | ❌ 日常吃饭(必须商业行为) |
| ✅ 进货被坑 | ❌ 房租水电(生活必需) |
| ✅ 请客被宰 | ❌ 交通通勤(工作需要) |
| ✅ 捐款 | ❌ 个人消费(买衣服/手机) |
| ✅ 投资朋友失败项目 | ❌ 赌博(灰色,系统不认) |
| ✅ 高于市场价买东西 | ❌ 灰色/黑色支出 |

### 数字曲线(防通胀)

- Lv.1: 5块→几天内过万 → 卷一主角资产过**百万**
- Lv.2: 升级后 500x → 卷一中段**千万**
- Lv.3: 升级后 1000x → 卷一中末**亿**
- Lv.4: 升级后 5000x → 卷二**百亿**
- Lv.5: 升级后 10000x → 卷三**万亿**

### 限制

| 限制 | 说明 |
|---|---|
| 触发 | 必须**商业行为** + **花得冤**(日常消费不算) |
| 禁区 | 赌/毒/黄/骗/传销/洗钱/黑产(系统不认) |
| 日限额 | 24小时内花不出去,当日额度清零(**逼主角天天破产**) |
| 副作用Lv.3 | 身边人开始"主动帮宿主省钱"(反向逼花钱的喜剧冲突) |
| 维护费 | 系统每月扣1%返利资金作为"保管费"(逼花出去) |
| 隐藏费用 | 怀表每月需要"特殊能量",主角必须继续花才能"养活"它 |

### 与起点《亏成首富从外卖开始》的差异化

| 维度 | 起点(已锁) | 番茄新规 |
|---|---|---|
| 起步返利 | 10x | **200x**(不是1万x,数字小但冲击力大) |
| 核心机制 | "亏商业行为" | **"花得冤"+24h花不完清零** |
| 触发难点 | 找"商业亏损" | 找"花得冤"的事 + 跟日限额赛跑 |
| 副作用 | Lv.5后"想亏"本能 | **Lv.3后"身边人帮省钱"(NPC反向施压)** |
| 系统形态 | 手腕数字 | **旧怀表打开盖子** |
| 起步现金 | 623块 | **5块**(更惨→代入感更强) |
| 起步城市 | 江城(苏北) | **深圳**(一线) |
