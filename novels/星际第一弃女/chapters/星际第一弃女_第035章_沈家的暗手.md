# 第三十五章 沈家的暗手

大比第四日，个人赛决赛。

姜晚星对阵沈烈的比赛，被安排在下午场。上午是团队赛的预赛，姜氏代表队三战两胜，勉强保住晋级席位。比赛打得极其艰难——沈氏代表队的团体配合堪称教科书级别，三场比赛下来，姜氏的队员们个个挂彩，最重的那个，是被机甲余波震伤，抬去了医务室。

队员们累得瘫在休息区，姜晚星却站在场边，看着对面沈氏代表队的训练区。她注意到一个细节：沈氏的训练区，今天特别安静——往常他们总会利用间隙加练，今天却一个人影都没有，像是刻意收起了所有动静。

“队长，”一个队员灌了口水，喘着气问，“下午的决赛，你真要一个人打？”

“嗯。”

“沈烈那台炎狱，听说能放出几千度的高温。”队员咽了口唾沫，“我们刚才在预赛里碰上沈氏的替补队员，都差点被烤熟。你一个人对上沈烈……”

“烤不熟我。”姜晚星说，“你们把预赛打好就行。决赛，交给我。”

“可队长，万一……”

“没有万一。”姜晚星打断他，声音平静，“你们信我，就好好活着走进决赛场。剩下的，我来。”

队员们看着她，张了张嘴，终究没再说什么。垃圾星上捡了二十年废铁的人，跟沈家实验室里养出来的机器，谁更硬——他们说不准，可他们说得出，这个队长，从来不吹牛。

沈烈没有来训练。

“他上午就不在。”一个队员凑过来，压低声音，“我听沈氏的人说，沈烈今天一早就被叫走了，好像是沈家那边来了人。”

“沈家来人了？”姜晚星皱眉，“谁？”

“不知道，看着像是个管事的中年人。他们进了贵宾室，一直没出来。”

姜晚星看着贵宾室的方向，目光幽深。沈观澜在她比赛前夜，忽然派人来见沈烈——这不是巧合。她想起陆临渊的话：沈观澜让她参赛，是想让某些人在大比上看到她的星痕共鸣。那么，今天这场比赛，就是沈家最想看的那一场。

“队长，”队员小声问，“下午的比赛，你没问题吧？”

“没问题。”姜晚星说，“你们去休息吧，下午的团队赛，交给我。”

队员们散去后，姜晚星独自留在场边。她低头，看着手腕上的星痕印记，指尖轻轻摩挲着那道蓝光。阳光从竞技场的穹顶洒下来，落在她身上，把她脚下的影子拉得很长。她忽然想起陆临渊昨晚的话，想起那个在模拟场阴影里一闪而过的红光——这两件事，会不会是同一个人做的？

“沈观澜。”她低声说，“你想看的东西，下午，我会让你看个够。”

下午两点，个人赛决赛，正式开始。

姜晚星驾驶星痕，站在格斗区中央。对面，沈烈的“炎狱”也缓缓升起——通体赤红的机甲，装甲缝隙间透出暗红色的光，像一块烧红的铁，连周围的空气都隐隐扭曲。它的脚下，地面被高温烤得发黑，升起一缕缕白烟。

“姜晚星。”沈烈的声音从炎狱的扩音器里传来，带着一丝沙哑，“我听说过你。垃圾星回来的，打赢了贺川。但贺川那套正面对抗的打法，在我这里，行不通。”

“是吗？”姜晚星说，“那试试。”

哨声响起。比赛开始。

沈烈率先出手。炎狱的引擎轰鸣，赤红色的机甲像一团火焰，直扑而来。它没有用拳脚——而是张开手掌，掌心凝聚起一团暗红色的能量，朝着星痕的方向，猛地轰出。

“炎狱·火雨！”

暗红色的能量弹在星痕身边炸开，化作无数细小的火星，铺天盖地地笼罩下来。每一粒火星都带着高温，落在装甲上，发出滋滋的声响。看台上响起一片惊呼——这是沈家实验室特制的高温战术，专门用来干扰对手的机甲系统。整个格斗区都被暗红色的光芒笼罩，连能量屏障都泛起一层扭曲的波纹。

驾驶舱内，温度警报声急促地响起。姜晚星看着仪表盘上飙升的温度读数，目光平静。

“高温干扰。”她低声说，“果然。”

她没有后退，反而操纵星痕，向前迈了一步。火星落在星痕的装甲上，溅起一片细碎的火花——然后，那些火花，在幽蓝色的纹路亮起的一瞬间，全都熄灭了。

“怎么回事？”沈烈的声音里带着一丝惊疑，“炎狱的火雨，对你无效？”

“你的火雨，是给普通机甲准备的。”姜晚星的声音从星痕的扩音器里传来，平静得没有一丝波澜，“星痕的装甲，是星纹钢——初代姜家家主在陨星带找到的材质。你的高温，烧不穿它。”

“星纹钢……”沈烈的声音沉下来，“你早就算好了？”

“我没有算你。”姜晚星说，“是你主子的算盘，打得太响了。”

沈烈的眼神，骤然一变。他操纵炎狱，猛地冲上来，拳头上凝聚着暗红色的能量，朝着星痕的驾驶舱狠狠砸下——高温无效，那就用近战格斗，正面解决。

姜晚星侧身，避开这一拳。星痕的反击随即而至——她没有用花哨的招式，而是用最朴素、最直接的打法，一拳，一拳，砸在炎狱的关节处。

“你的近战，只有中等水平。”她一边打，一边说，“沈家的实验室，把所有的资源，都砸在高温系统上了。他们忘了告诉你——机甲是拿来打仗的，不是拿来烧火的。”

轰！

星痕的重拳，砸在炎狱的右臂关节上。一声脆响，炎狱的右臂垂了下去，能量回路被震断，暗红色的光纹一阵明灭。

“你——！”沈烈怒吼，左拳横扫而来。姜晚星不闪不避，星痕的左手直接抓住炎狱的拳头，反手一拧，把炎狱的整条左臂，也卸了下来。

“你输了。”姜晚星说。

格斗区里，死一般的寂静。看台上，所有人都目瞪口呆地看着场中央——赤红色的炎狱双臂垂落，暗红色的能量光纹彻底熄灭，像一尊被砸碎的火神像。

“沈烈的炎狱……被卸了双臂？”解说员的声音都在发抖，“姜晚星，几乎是碾压式地赢下了这场决赛！”

“姜晚星获胜！晋级终极挑战赛！”

看台上，爆发出震天的欢呼声。姜氏代表队的队员们冲进场内，把姜晚星围在中间，欢呼着把她抛向空中。这是姜氏二十年来，第一次有选手打进终极挑战赛。有人红了眼眶，有人扯着嗓子喊，有人把队旗挥舞得猎猎作响。

姜晚星被队员们抛起来又接住，看着头顶那片蓝天，难得地露出一个笑容。

就在这时候，她手腕上的星痕印记，忽然烫了一下。

她的笑容，凝固了。

“小心。”星痕的声音在她脑海响起，“有杀气。”

姜晚星几乎是本能地，一个翻身落地，把身边的两个队员推倒在地：“趴下！”

话音未落，一道激光束，从看台的方向射来，精准地穿过姜晚星刚才站着的位置，打在格斗区的能量屏障上，溅起一片火花。

“刺客！”解说员的声音都变调了，“有刺客！安保！安保！”

整个竞技场瞬间陷入混乱。看台上，人群尖叫着四散奔逃，安保人员冲向看台方向。姜晚星蹲在格斗区边缘，目光死死锁着激光束射来的方向——看台第三区，一个穿着灰色风衣的人影，正快速向出口移动。

“星痕，追！”姜晚星翻身跃上机甲。

星痕的引擎轰鸣，黑色机甲腾空而起，跃过能量屏障，朝着看台方向追去。那人影见势不妙，拔腿就跑，翻过看台的围栏，朝竞技场外的地下通道冲去。

姜晚星驾驶星痕，紧追不舍。地下通道狭窄，机甲行动不便，她干脆跳出驾驶舱，徒手追了上去。

“站住！”她喊。

那人影头也不回，拐进一条岔道。姜晚星追到岔道口，那人已经不见了。她蹲下来，看着地面上一个新鲜的痕迹——那是那人影翻越围栏时，衣服刮在金属边缘留下的。衣料的纤维里，夹着一枚小小的金属徽记。

姜晚星把它捡起来，对着灯光一看，瞳孔微微收缩。

那是一枚徽记——盾形，中央刻着一只展翅的鹰，鹰爪下抓着一团火焰。

沈家的家徽。

姜晚星捏着那枚徽记，指尖微微收紧。她抬头，望向通道深处，那里已经空无一人。

“沈家。”她低声说，“你们终于，把暗手伸到赛场上了。”

远处，竞技场的警报声还在回荡。姜晚星把那枚徽记收进口袋，转身，朝竞技场的方向走去。她的脚步很稳，可握着徽记的那只手，指节发白。

“沈观澜。”她轻声说，“这笔账，我记下了。”

她回到竞技场的时候，安保已经封锁了全场。大赛组委会的官员们脸色铁青，正在向各方代表道歉。姜氏代表队的队员们看到她完好无损地回来，齐齐松了一口气。

“队长！你没事吧！”

“没事。”姜晚星说，“人没抓到，但留了个东西。”

“留了什么？”一个队员凑过来问，“是刺客的东西吗？”

“一枚徽记。”姜晚星说，“具体是什么，回头再说。你们今天的预赛打得不错，回去好好休息，明天还有团队赛决赛。”

“队长，明天我们一起上。”另一个队员攥着拳头，“今天你一个人扛了沈烈，明天轮到我们替你分担了。”

姜晚星看着他，难得地弯了一下嘴角：“好。明天，我们一起上。”

队员们互相击掌，陆续散去。姜晚星站在原地，看着他们离开的背影，眼底有一丝温度。这些二十来岁的年轻人，上大比之前，都只是军校里不起眼的普通学员——可这几天，他们一个个，都长成了战士的样子。

她走到陆临渊面前，把那枚徽记摊开在掌心：“认识这个吗？”

陆临渊低头看了一眼，眼神沉下来：“沈家的家徽。鹰爪火焰——沈氏本家的标志。这种徽记，只配发给沈家的核心成员和亲卫。”

“亲卫？”

“沈观澜的贴身护卫。”陆临渊说，“不是沈家随便哪个旁支都能佩戴的。刺客身上带着这枚徽记，说明他是沈观澜身边的人——或者是有人想让你以为，他是沈观澜身边的人。”

姜晚星看着他：“你觉得是第二种？”

“我不知道。”陆临渊说，“但我知道，沈观澜做事，一向干净。他如果真的想杀你，不会让刺客带着一枚能认出身份的家徽——这不像他的风格。”

“那如果是有人想嫁祸沈家呢？”

“那就更值得警惕了。”陆临渊说，“有人想让你和沈家，在大比上彻底撕破脸。而你如果认定了是沈家干的，下一步，就会跟沈家正面开战——到时候，渔翁得利的，是别人。”

姜晚星沉默了。她低头，看着掌心里那枚徽记，指尖轻轻摩挲着鹰爪的纹路。陆临渊的话，像一盆冷水，浇灭了她心里的怒火，也让她冷静下来。

“你说得对。”她说，“我差点，就中了别人的圈套。”

“你能想明白就好。”陆临渊说，“这枚徽记，先收好。我会让人去查，看看沈家的核心成员，最近谁有异动。”

“嗯。”姜晚星点头，忽然又问，“陆临渊，你今天晚上，有空吗？”

“怎么？”

“我请你吃烤星薯。”姜晚星说，“说好的。”

陆临渊愣了一下，随即笑了：“好。正好，我也饿了。”

“那走吧。”姜晚星说，“食堂师傅说，烤星薯要趁热吃，凉了就不好吃了。”

“你倒是记得清楚。”

“二十年前，有人给过我一块巧克力。”姜晚星说，“从那时候起，我就记住了，别人给的东西，要趁热收下。”

陆临渊看着她，眼里的笑意更深了些：“那今天这顿烤星薯，我记下了。改天，我请你吃更好的。”

窗外，竞技场的警报声渐渐平息。夜色降临，苍穹星的灯火次第亮起。姜晚星把那枚徽记收进口袋深处，望着夜色里沈都星的方向，目光幽深。

“沈观澜。”她轻声说，“不管是你，还是别人想嫁祸你——这笔账，我都会记在沈家头上。谁下的手，谁就得还。”
