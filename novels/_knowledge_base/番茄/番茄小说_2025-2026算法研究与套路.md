## 一、番茄 2025-2026 算法核心规则

### 1.1 番茄算法 vs 起点算法 关键差异

| 维度 | **番茄算法** | **起点算法** |
|---|---|---|
| 签约线 | **1万字 = 签约生死线** | 30万字 |
| 核心指标 | 读者读完率(0-10%) / 追读率 | 订阅率 / 月票 |
| 推荐权重 | 章节读完率+互动率(评论/收藏) | VPI(追读率) |
| 单章目标字数 | **2000-2500字**(底限) | 2500-4000字 |
| 节奏要求 | **3 章一爆点**(签约前必死线) | 10章一爆点 |
| 读者画像 | 偏年轻/下沉/碎片化 | 中年/付费/长篇 |
| 文风偏好 | **轻松+反讽+段子+爽感max** | 沉稳+权谋+长线爽 |

### 1.2 2025-2026 新增算法信号(实战验证)
- ✅ **抖音同步推送** = 番茄主打"刷到即爽",**开头3章必须有"可截图金句"**
- ✅ **章节读完率权重高** = 不要大段套话/背景说明,**每章直接进冲突**
- ✅ **互动率** = 章末"读者想骂/想笑/想回复"的钩子(对比起点的"读者想追")
- ✅ **稳定性** = 番茄读者更新敏感,断更=算法直接打回次级
- ✅ **短章优势**: 番茄单章 2000-2200 字比 4000 字更友好(读完率高)

### 1.3 番茄禁忌(2025-2026)
- ❌ **章节开头年月日**(用户 2026-07-03 反馈已焊死7禁)
- ❌ **"七月的X+热"** 雷同开头(2026-07-03 焊死)
- ❌ **作者注/数据卡/下章预告方括号**
- ❌ **AI味重** = 主角开口闭口金句、一堆排比、政治正确
- ❌ **章节超过2500字但不爆**(番茄读者秒弃)

## 二、2025-2026 番茄头部公式(8种)

### 公式1: **"遗产+系统激活"反讽流**(学"全球高武"/"我成 NPC")
- **核心**: 主角继承神秘遗产 → 系统激活 → 反讽吐槽系统
- **爽点公式**: 试一下 → 数字暴击 → 吐槽"系统你是不是有病" → 章末反转
- **典型开篇金句**:
  - "我卡里5块钱,系统说花钱返200倍。我说返你妈。"
  - "我顾行舟,穷得只剩花钱这本事了。"
  - "系统大大,加大力度啊,这点钱不够花的。"
- **反例**: 一上来主角感激涕淋/哭哭啼啼(番茄读者爱看反讽,不爱看苦情)

### 公式2: **"我在番茄的5块"开篇(图文流)**
- **核心**: 卡里 5 块 / 1 块 / 100 块的极低起点
- **爽点**: "穷到极致"→ 系统激活 → 一块钱也能闹翻天
- **优势**: 极低门槛带入 + 反差max
- **番茄比起点更爱**(因为读者更年轻、更爱反差)
- **门槛**: 父亲/母亲遗产由来必须合理(2026-07-03 用户铁律)

### 公式3: **"系统自黑型"主角**(番茄 2024-2026 新派)
- **核心**: 系统"勉强认可"主角 / 系统说话吐槽 / 系统强制激活
- **典型对白**:
  - 「系统: 您这破财转运牌,真就挑了个最穷的人绑定……」
  - 「系统: ……您试用期,我也没得选」
- **优势**: 一句话建立"轻松+反讽"基调
- **风险**: 不要让系统话太多(变AI味)

### 公式4: **"段子里嵌段子"嵌套爽**(番茄独家)
- **核心**: 主线剧情里嵌 2-3 个"小段子"(主角吐嘈对手/系统)
- **示例结构**:
  - 主线: 主角花5块→到账1000
  - 段子: 主角说"我现在比巴菲特还有钱,虽然他不知道我是谁"
  - 主线: 钱小宝登场
  - 段子: 钱小宝说"你这不叫神豪,你叫 '破产之神'"
- **优势**: 每个段子就是 1 个"可截图金句" = 抖音算法友好

### 公式5: **"打脸普通反派+大反派压轴"双层**(成熟套路)
- **核心**: 头10-30章打脸小反派(同学/邻居/亲戚) → 30-150章引出大反派
- **小反派打脸节奏**: 每3-5章一次
- **大反派钩子**: 第10章埋, 第30章露脸, 第60章正面冲突

### 公式6: **"打脸不只是有钱,还要有'创意外现'"**(2025-2026 微创新)
- **核心**: 主角每次打脸不只是掏钱,而是有"创意表演"
- **示例**:
  - 反派嘲讽主角 → 主角贴出转账 200 倍记录 → 配一句"误会,这是小钱"
  - 反派说"你穷" → 主角扫码买反派公司 50% 股份 → 配一句"买你公司送你的,不用谢"
- **优势**: 比"盲目装有钱"高级,番茄读者爱这种"又装又能打脸"的

### 公式7: **"父亲/母亲遗产+伏笔深埋"**(品质向番茄头部)
- **核心**: 系统/遗产由父辈预留,埋设 5+条伏笔
- **典型结构**:
  - 父辈: 「等我走了再拆」
  - 神秘人: 「欠你爸的人」
  - 反派家族: 跟父辈 3 年前有仇
  - 系统本体: 跟父辈有牵连
  - 终极伏笔: 父辈死亡真相
- **优势**: 番茄读者也爱看"剧情有深度"

### 公式8: **"大城市反差"(深圳/上海/北京 > 三线)**
- **核心**: 起点爱用"穷小子在小城翻身",番茄爱用"穷小子在大城市"
- **典型**: 顾行舟("宿迁学院毕业失业到深圳") / 林北辰(地铁涨主角)
- **优势**: 大城市消费/装逼/打脸场景 = 大数字跨度
- **番茄比起点爱**(因为读者更爱"现实代入感"大城市)
