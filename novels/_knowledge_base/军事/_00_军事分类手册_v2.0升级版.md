## 二、8 种已验证的金手指爆款模式(扩展原本 5 种)

### 模式1: **异世界军火商**(2024-2026 头部主推)
- **核心**: 主角带军火系统穿越异世界卖军火
- **爽点公式**: 卖装备 → 客户震惊 → 王国采购 → 富可敌国
- **优势**: 经久不衰,系列化易爆

### 模式2: **赛博朋克军事融合**(2025-2026 新)
- **核心**: 未来赛博世界 + 军火装备 + AI 辅助
- **爽点公式**: 设计 AI → 装备碾压 → 客户震惊
- **优势**: 2025-2026 新派爆款

### 模式3: **未来星际战争**(2024-2026 抬头)
- **核心**: 2050+星际战争 + AI 主导
- **爽点公式**: 装备研发 → 星战反杀 → 称霸星域
- **优势**: 格局大,网文天花板高

### 模式4: **直播/系统流军事**(2024-2026 新)
- **核心**: 主角觉醒军事系统
- **爽点公式**: 每日任务 → 完成 → 系统奖励 → 越级反杀
- **优势**: 节奏快,番茄读者最爱

### 模式5: **魂穿成武器/系统**(2025-2026 新)
- **核心**: 主角附身在武器上
- **爽点公式**: 装备觉醒 → 主人震惊 → 反杀
- **优势**: 创新感

### 模式6: **虚拟军事游戏**(2024-2026 新派)
- **核心**: 主角在游戏中当 NPC / 指挥官
- **爽点公式**: 在游戏里崛起 → 影响现实
- **优势**: "我成了 NPC"流派

### 模式7: **外星战争**(经典老)
- **核心**: 外星入侵地球,主角觉醒
- **优势**: 经典,但要谨慎处理"地球失败"等情节

### 模式8: **国际架空雇佣兵**(2020-2024 经典)
- **核心**: 主角是国际雇佣兵
- **优势**: 避开红线,适合国际战场
- **陷阱**: 2024-2026 上升势头减弱,头部位置让位给系统流

## 三、头章5幕结构实战模板(2025-2026 升级版)

### 幕一·开场冲突(500字)
- 必须包含: 主角极低起点/绝境(被陷害/被追/装备丢失) + 数字锚点 + 一个刺激源(被烙印/系统激活/老乡在门口)
- **2025-2026加**: 第一句必须有"段子金句"或"反讽"
- 反面教材: 一上来介绍军事背景

### 幕二·规则铺陈(500字)
- 系统激活瞬间 → 物理感(震动/界面/内心独白)
- 规则一次说清(装备/兑换/限制/禁区)
- **2025-2026加**: 系统吐槽主角"就凭你这穷小子当军火商?"

### 幕三·试探验证(500字)
- 主角做一件"小试"试探 → 数字反馈
- 主角"卧槽"反应(必须有反讽金句)

### 幕四·第一爽点(500字)
- 一次具体的"军事行为"事件(具体装备 / 反杀)
- 围观者震惊(队友/雇佣兵/反派)
- **2025-2026加**: 主角"嫌麻烦"吐槽金句

### 幕五·钩子反转(500字)
- 主角算账(下一步怎么放大)
- 1-2 个外部刺激(将军下令 / 异族入侵 / 神秘人跟进)
- **2025-2026加**: 章末"可截图金句"

|---|---|---|
| 头三章 | ≥3 | ≥3 |
| 卷一前30章 | ≥2 | ≥2 |
| 卷一中段 | 1-2 | 1-2 |

### 起点标准:
| 卷数 | 每章爽点数 | 钩子数 |
|---|---|---|
| 头三章 | ≥3 | ≥3 |
| 卷一前30章 | ≥2 | ≥2 战争钩子 |
| 卷一中段 | 1-2 | 1-2 |

## 七、章末钩子三件套

每章必须有:
- **主钩子**: 下章主线(具体事件,如"明早跟外星舰队决战")
- **副钩子**: 人物关系变化(将军/女主/反派)
- **暗钩子**: 一行环境描写 + 一句反讽金句
