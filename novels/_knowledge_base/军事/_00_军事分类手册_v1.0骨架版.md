# 军事分类参考手册 (2026-07-04)

> ⚠️ **数据来源声明**: 基于行业知识 + 经典头部作品(《最强兵王》《我是特种兵》《狼牙》《佣兵的战争》等)经验。**军事类涉政敏感极高,签约前必查红线和编辑反馈**。

## 一、5种已验证的军事金手指爆款模式

### 模式1: 兵王归来型(《最强兵王在都市》/《王牌特卫》)
**核心**: 主角是退役特种兵/佣兵王 → 回归都市 → 一路碾压反派/保护女主
**爽点公式**: 都市小反派嘲讽 → 主角出手 → 军方大佬接机/政要臣服
**优势**: 都市+军事跨界,受众广
**铁律**: 军衔描写必须符合现实,不能"上校指挥中将"

### 模式2: 抗战种田型(《亮血》《抗日之铁血兵魂》)
**核心**: 主角穿越/重生到抗战 → 用现代战术打日军 → 一路建功立业
**爽点公式**: 装备碾压 → 战术碾压 → 后勤碾压 → 杀敌立威
**优势**: 家国情怀 + 高潮爽点
**🔴红线**: 不能写"内战"、不能详细描述解放军内部作战

### 模式3: 军火专家型(《最强军火商》/《超级军火商系统》)
**核心**: 主角带军火系统 → 在异世界/平行时空卖军火 → 称霸军火市场
**爽点公式**: 制造军火 → 客户震惊 → 军队配置 → 战场称霸
**优势**: 系统流+军事双重
**铁律**: 军火型号不能直接对应当代型号,要用虚构型号

### 模式4: 军旅特种兵(《我是特种兵》《雪豹》)
**核心**: 主角新兵入伍 → 训练 → 选拔特种兵 → 退役 → 都市回归
**爽点公式**: 被欺负 → 反杀 → 长官赏识 → 选拔 → 立功
**优势**: 节奏稳 + 男频最爱
**铁律**: 训练细节要符合真实作战部队标准,不要科幻化

### 模式5: 谍战潜伏型(《暗算》《悬崖》)
**核心**: 主角是地下党员/军统特务 → 潜伏敌营 → 传递情报 → 抓内鬼
**爽点公式**: 任务下达 → 智斗 → 险中求生 → 揭露间谍
**优势**: 紧张感 + 智斗感
**🔴红线**: "内战"剧情需谨慎,只可写抗战时期,不能写解放战争

## 二、军事头章5幕结构实战模板

### 幕一·开场冲突(500字)
- 身份设定: 兵种(陆军/海军/武警) + 军衔(义务兵/士官/校官)
- 处境:**新兵挑衅/战场上受伤/退役迷茫**
- 数字锚点: 军衔/兵龄/已击杀数
- 刺激源: 战友被欺负/战事紧张/国仇家恨

### 幕二·规则铺陈(500字)
- 系统/能力/觉醒瞬间
- 关键场景:**部队/战场/雇佣兵场地**
- 装备描写: 主武器/副武器/装备/战术配件
- 金句: 军事热血金句"犯我中华者,虽远必诛"

### 幕三·试探验证(500字)
- 第一场小规模战斗/操练/反欺负
- 主角展露**一招制敌**
- 围观者(同班/战友/围观民众)震惊
- 关键钩子: 留下"更强的对手还没出现"

### 幕四·第一爽点(500字)
- 一次完整的小战斗/打脸反派
- **细节描写**: 战术动作/武器操作/配合
- 主角金句: "你们上,老子殿后"/"我一个人够了"
- 上级反应: 出现高官注视,准备提拔

### 幕五·钩子反转(500字)
- 上级任务/特殊任务/更大反派
- 外部刺激: 军方大佬/总统级人物出现
- 暗钩子: 神秘指挥官/特种战备/国家紧急任务

## 三、军事爽点密度标准

| 阶段 | 每章爽点数 | 钩子数 |
|---|---|---|
| 头三章 | ≥3 | ≥3 |
| 卷一前30章 | ≥2 | ≥2 |
| 卷一中段 | 1-2 | 1-2 |
| 卷一高潮(每20章) | 5+ | 3+ |
| 卷二/卷三 | 1-2/章 | 1-2/章 |

**铁律**: 军事要"高燃高节奏",**每个爽点必须有战术动作细节**,不是用嘴炮

## 四、🔴军事红线(必查,焊死)

### 安全度评级

| 时代 | 安全度 |
|---|---|
| 抗战-1949以前 | ⚠️黄(限"打日"主题,不能详细描写国共内战) |
| 1949-1979 | 🔴红(军事文学禁区) |
| 1979-至今 | 🔴红(当代部队,涉政敏感) |
| 未来/架空 | ✅绿(可写平行时空外星战场) |
| 历史名将(岳飞/戚继光/白起) | ⚠️黄(可写但避免和现役对比) |
| 雇佣兵(海外) | ✅绿(虚构国) |

### 🔴绝对禁止
- ❌ 不能写"内战"(国共内战/朝鲜战争)
- ❌ 不能详细描述酷刑/逼供
- ❌ 不能详细写当代军衔体系(写出番号=敏感)
- ❌ 不能将解放军与国民党军队对比"善恶"
- ❌ 不能写军事政变/军队哗变
- ❌ 不能详细写现役装备参数(精确到型号)

### 安全替代方案
- ✅ 写抗战时期(打日军) → 题材最安全
- ✅ 写现代退役兵都市回归 → 避免部队细节
- ✅ 写架空/未来战争 → 完全自由
- ✅ 写雇佣兵海外 → 用虚构国名

## 五、军事伏笔5条起步包

- **F001**: 主角前世身份 → 卷末回收(前世是某特种部队王牌)
- **F002**: 主角的师傅/老师 → 中段回收(军中战神/退隐的传奇人物)
- **F003**: 反派头目身份 → 卷二揭露(敌方王牌/敌方特务头子)
- **F004**: 神秘武器/装备 → 卷一末解释(实验室新型装备)
- **F005**: 军中大佬的支持者 → 卷三反杀(一直默默支持主角的高层)

## 七、AI产军事文 5 大陷阱

1. **军衔乱写**: 上校指挥中将 → 严格按真实军衔体系
2. **武器乱配**: AK装红点瞄、加特林打步兵 → 严格配装
3. **战术失真**: 单人破千人、坦克躲子弹 → 必查战术书籍
4. **政治失语**: 写到解放军现实题材必查编辑反馈
5. **后勤失真**: 千人行军吃罐头、是军官坐指挥部 → 符合后勤规则

## 九、军事开坑建议方向

### 🟢 方向1: 抗战种田(用户最稳)
- 时代: 1937-1945年抗日战争
- 主角: 八路军/国军/山大王/雇佣兵
- 金手指: 系统召唤现代装备/前世记忆/集火技能
- 安全度: ⚠️黄(不能详细写国共斗争)

### 🟢 方向2: 兵王归来(签约最快)
- 现代退役军人在都市创业/恋爱
- 时代: 2020年后
- 主角: 退役特种兵/王牌
- 金手指: 战场直觉/体能压制/军方关系
- 安全度: ⚠️黄(避开现役部队)

### 🟢 方向3: 架空未来战(差异化最强)
- 平行时空/异世界/星际战争
- 主角: 未来士兵/机甲驾驶员
- 金手指: 系统召唤/技能树/升级系统
- 安全度: ✅绿
