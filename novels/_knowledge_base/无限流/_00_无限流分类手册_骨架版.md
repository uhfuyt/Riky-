# 无限流分类参考手册 (2026-07-04)

> ⚠️ **数据来源声明**: 基于行业知识 + 经典头部作品(《无限恐怖》《诸天投影》《轮回乐园》《一世之尊》《超弦空间》等)经验。**无限流智斗感最强但门槛最高**,AI产出需要稳。

## 一、5种已验证的无限流金手指爆款模式

### 模式1: 主神空间型(《无限恐怖》《轮回乐园》原型)
**核心**: 主角进入主神空间/轮回乐园 → 完成副本任务 → 获得奖励 → 越来越强
**爽点公式**: 进入副本 → 克服恐惧 → 利用金手指破解 → 完胜 → 兑换奖励 → 实力飙升
**优势**: 副本独立成章,断更友好,爽感强烈
**铁律**: 副本设计必须有"明确规则 + 心理恐怖 + 智斗环节"

### 模式2: 诸天流型(《诸天投影》《我师兄实在太稳健了》)
**核心**: 主角穿越"诸天万界" → 进武侠位面/仙侠位面/科幻位面刷经历 → 成长
**爽点公式**: 进入位面 → 改变剧情 → 击败关键人物 → 获得位面核心 → 兑换系统
**优势**: 长篇稳定 + 受众广(穿越流的缝合)
**铁律**: 每个位面**规则必须提前说清**,否则读者代入不了

### 模式3: 召唤轮回者型(《超神机械师》《轮回者》)
**核心**: 主角发现自己有"轮回者"召唤系统 → 召唤其他世界的强者 → 组队打怪
**爽点公式**: 召唤 → 战场破敌 → 强化队伍 → 升级轮回者
**优势**: 系统流 + 团队感
**铁律**: 轮回者性格设定要鲜明(怕死型/智斗型/热血型/搞笑型),不能千篇一律

### 模式4: 末日求生+主神空间融合型(《全球崩坏》/《我被困在同一天》)
**核心**: 末世 + 主神空间 → 双重压力 → 通过副本换取资源
**爽点公式**: 末世压力 → 进入副本 → 通过 → 兑换关键道具 → 升级装备 → 反杀
**优势**: 双重压力 + 节奏稳
**铁律**: "同一天循环"不能写到主角精神崩(否则=抑郁题材)

### 模式5: 综漫穿越型(《无限流综漫》/《时崎狂三的综漫》)
**核心**: 主角穿越到动漫/影视/小说世界 → 借用原作剧情 → 改变剧情
**爽点公式**: 进入动漫 → 借用原作剧情 → 改变关键事件 → 收割原作女角色
**优势**: 受众广(二次元粉)
**🔴红线**: 不能在擦边色情/百合剧情上做太多笔墨

## 二、无限流头章5幕结构实战模板

### 幕一·开场冲突(500字)
- 日常位面设定: 现代都市/学生/上班族/底层
- 数字锚点: 副本进度/轮回者等级/积分
- 刺激源: 突然被拉到主神空间/穿越异界/接到副本任务
- 钩子: **第一个副本是什么**(读者最关心)

### 幕二·规则铺陈(500字)
- 主神空间规则一次说清: 任务/奖励/惩罚/退出机制
- 复制者/轮回者/团队构成
- 副本说明: 是什么世界、什么规则
- 主角反应: 不信 → 强制 → 接受 → 计算

### 幕三·试探验证(500字)
- 进入副本 → 第一关/第一个任务
- 主角分析局势 → 利用金手指
- 第一次小成功/小危机
- 关键钩子: 还有更大的副本BOSS没暴露

### 幕四·第一爽点(500字)
- 完成第一个完整副本 → 兑换奖励 → 实力大涨
- 围观队友震惊: 老轮回者惊讶
- 主角金句: "副本而已,有何难?"
- 内心独白: 满足 + 还有更大野心

### 幕五·钩子反转(500字)
- 副本次数/难度的升级暗示
- 团队矛盾/背叛伏笔
- 暗钩子: 主神空间自有目的/副本Boss的真相

## 三、无限流爽点密度标准

| 阶段 | 每章爽点数 | 钩子数 |
|---|---|---|
| 头三章 | ≥4 | ≥3 |
| 卷一前30章 | ≥3 | ≥2 |
| 卷一中段 | 1-2 | 1-2 |
| 卷一高潮(每20章) | 5+ | 3+ |
| 卷二/卷三 | 1-2/章 | 1-2/章 |

**铁律**: 无限流 = "副本独立章节"模式,**每个副本至少要有一个独立的爽点**

## 四、无限流红线(中等)

### 安全度评级

| 子类型 | 安全度 |
|---|---|
| 主神空间(规则清晰) | ✅绿 |
| 诸天流(轻规则) | ✅绿 |
| 恐怖氛围(密室/诡秘) | ⚠️黄(避开自杀式闯关) |
| 召唤轮回者 | ✅绿 |
| 综漫穿越 | ⚠️黄(避开擦边) |
| 时空穿梭 | ⚠️黄(避开1840后历史) |
| 末世+主神 | ✅绿 |

### 🔴绝对禁止
- ❌ 自杀式献祭/自我牺牲的渲染
- ❌ 详细酷刑/血腥描写
- ❌ 详细未成年受虐情节
- ❌ 强制百合/擦边色情
- ❌ 副本内政/政治敏感事件

## 五、无限流伏笔5条起步包

- **F001**: 主神空间的真正目的 → 卷末回收(主神有自我意识)
- **F002**: 主角前世 → 中段回收(前世是某轮回小队队长)
- **F003**: 早期队友的真实身份 → 卷二揭露(有轮回者卧底)
- **F004**: 副本的真相 → 卷一末解释(副本世界可能是真实世界)
- **F005**: 主神的来源 → 卷三反杀(终极Boss)

## 七、AI产无限流文 5 大陷阱

1. **副本规则乱**: 前期说不能飞,后期主角自己飞 → 锁规则
2. **奖励通胀**: 战力爆表太快,后期奖励全用过 → 限制奖励等级
3. **智斗失智**: 主角用卖萌/运气取胜 → 智斗必须有推理过程
4. **轮回者同质化**: 都"冷漠聪明"+ 性格无差 → 必有差异化
5. **主神疲软**: 主神发任务就发任务,没高潮 → 主神必须有自我意识

## 九、无限流开坑建议方向

### 🟢 方向1: 经典主神空间(粉丝基础最大)
- 主角: 普通青年被卷入
- 副本: 恐怖片/历史事件/末日场景
- 团队: 7-15人,性格各异
- 安全度: ✅绿

### 🟢 方向2: 诸天流(长篇首选)
- 主角: 穿越系统
- 副本: 武侠/仙侠/历史/科幻
- 节奏: 一个副本 30-50章
- 安全度: ⚠️黄

### 🟢 方向3: 末世+主神(2026年新趋势)
- 现实+副本双重压力
- 节奏: 副本节奏快
- 安全度: ✅绿

### 🟢 方向4: 召唤轮回者(系统流友好)
- 主角: 系统持有者
- 轮回者: 性格鲜明4-5种类型
- 节奏: 召唤 + 战场破敌
- 安全度: ✅绿
