| 算法 | 核心指标 | 套路偏好 | 签约线 |
|---|---|---|---|

### 0.3 2025-2026 新踩雷点(避雷清单升级)
- ❌ **赘婿类老套路** = 算法降权(读者疲劳)

- ✅ **现代技法 + 反讽** = 读者最爱
- ✅ **直播间流/考古流/外卖穿越** = 2024-2026新模板

## 一、8种已验证的金手指爆款模式(扩展原本5种)

### 模式1: **现代技法碾压古人**(2025-2026头部主推)
- **核心**: 主角带现代知识穿越 → 用现代技术碾压古人
- **爽点公式**: 古人难题 → 现代解 → 震惊古人 → 名利双收
- **典型**: 火药/水泥/印刷术/医药/机械 → 古人觉醒
- **优势**: 知识壁垒+爽感双重,2025-2026经久不衰
- **陷阱**: 技术太穿越=玄幻,必须挂历史

### 模式2: **系统签到流**(2024-2026新派)
- **核心**: 主角穿越激活签到系统 → 签到抽古代神器/功法/物资
- **爽点公式**: 签到 → 神器 → 震惊古人 → 反派跪服
- **优势**: 节奏快,番茄读者最爱
- **陷阱**: 系统奖励不能太强(避免"主角无敌没人看")

### 模式3: **直播/弹幕流**(2024-2026新)
- **核心**: 主角穿越古代被历史直播间评论 → 现代人"指点"
- **爽点公式**: 直播点醒 → 主角破防 → 调整策略 → 震惊观众
- **优势**: 双视角代入 + 现代读者强共鸣
- **陷阱**: 弹幕不能剧透太过,保持半遮半掩

### 模式4: **考古/文物流**(2025-2026新)
- **核心**: 主角在大英博物馆/文物局研究古代文物 → 魂穿回古代
- **爽点**: 现代考古研究 + 古代行动
- **优势**: 海外华人题材,适合"海外华人/反殖民"读者
- **铁律**: 不写具体流失文物的"被偷"经过(涉民族敏感)

### 模式5: **古井/地下室/仓库(空间流)**(2024-2026稳)
- **核心**: 主角继承家中古井/地下室 → 里面有现代物资无限供应
- **爽点**: 古今商品倒卖 → 发家 → 名利双收
- **优势**: 种田文经久不衰
- **陷阱**: 物资不能无限,要设消耗机制

### 模式6: **抖音/短视频流**(2025-2026新)
- **核心**: 主角穿越古代能拍抖音 → 现代设备/技术
- **爽点公式**: 拍古代场景 → 震惊现代观众 → 古代权贵震惊
- **优势**: 抖音读者爱看
- **陷阱**: 不能"穿越古代自带手机"太离谱

### 模式7: **外卖/快递穿越流**(2025-2026番茄爆款)
- **核心**: 主角是外卖小哥/快递员穿越 → 带着现在交通工具/工具
- **爽点**: 用外卖小哥经验/快递思维碾压古代
- **优势**: 番茄读者最爱"小人物翻身"
- **陷阱**: 不能用太现代的设备(避免玄幻化)

### 模式8: **家族百年传承流**(2025-2026新)
- **核心**: 主角继承祖辈百年家业 → 各代祖先秘密逐步揭开
- **爽点**: 揭示祖辈真相 → 激活祖辈遗产 → 名震四方
- **优势**: 群像感强,适合长篇
- **陷阱**: 多代时间线容易乱,要每代列清楚

## 二、头章5幕结构实战模板(2025-2026升级版)

### 幕一·开场冲突(500字)
- 必须包含: 主角极低起点状态(失业/破产/被遣返) + 数字锚点 + 一个刺激源(收到一个包裹/一条短信/父亲遗言)
- **2025-2026加**: 第一句必须有"段子金句"或"读者想截图的话"
- 反面教材: 一上来介绍世界观/历史背景

### 幕二·规则铺陈(500字)
- 系统激活瞬间 → 物理感(光芒/震动/内心独白)
- 规则一次说清(数字/倍数/限制/禁区)
- **2025-2026加**: 系统吐槽主角"怎么就绑定你这个穷鬼"

### 幕三·试探验证(500字)
- 主角做一件"小亏"试探 → 数字反馈
- 主角"我勒个去"反应(2025-2026必须有反讽金句)

### 幕四·第一爽点(500字)
- 一次具体的"花冤→返利"事件(数字明确)
- 围观者震惊
- **2025-2026加**: 主角"嫌赚太多"的吐槽金句

### 幕五·钩子反转(500字)
- 主角算账(明天怎么花更多冤)
- 1-2个外部刺激(母亲来电/反派登场/神秘人跟进)
- **2025-2026加**: 章末"可截图金句"必须有(如"我顾行舟,穷得只剩花钱这本事了")

## 三、爽点密度+故事节奏(2025-2026标准)

### 番茄标准:
| 卷数 | 每章爽点数 | 钩子数 |
|---|---|---|
| 头三章 | ≥3 | ≥3 段子钩子 |
| 卷一前30章 | ≥2 | ≥2 |
| 卷一中段 | 1-2 | 1-2 |

### 起点标准:
| 卷数 | 每章爽点数 | 钩子数 |
|---|---|---|
| 头三章 | ≥3 | ≥3 |
| 卷一前30章 | ≥2 | ≥2 庙堂钩子 |
| 卷一中段 | 1-2 | 1-2 |

**铁律**: 头三章必须高密度=稳签约线;30章后可降,但不能连续3章无爽点。

## 四、伏笔5条起步包(2025-2026升级)

开坑时必须在 bible.md 至少埋5条伏笔,2025-2026新主流:
- **F001**: 父辈神秘遗产(父亲/母亲死因悬念)
- **F002**: 系统本体(为什么绑定你 - 核心钩子)
- **F003**: 神秘人(欠父辈的人)
- **F004**: 反派家族(为什么害主角父辈 - 父仇线)
- **F005**: 系统真实身份(怀表/小瓶/仓库的源头)

每章产出后必须更新伏笔状态(已埋/已收/待回)

## 五、主角口头禅库(2025-2026新兴)

### 反讽型(2025-2026头部必备)
- "系统大大,加大力度啊"
- "这点钱,不够我亏的"
- "我顾行舟/林XX,穷得只剩XX这本事了"
- "我凭本事亏的钱,你管我?"

### 系统吐槽型(2025-2026新派)
- "您这系统,真就挑了个最穷的人绑定……"
- "宿主哭穷指数: 严重"

### 古代震惊型(历史特殊)
- "公/将军,您这……您怎么做到的?"
- "我大X朝百年未有之奇事!"

**铁律**: 主角前10章口头禅必须固定下来,后续沿用不能漂移

## 六、章末钩子三件套(2025-2026升级)

每章必须有:
- **主钩子**: 下章主线(具体事件,如"明早跟王大龙讨债")
- **副钩子**: 人物关系变化(母亲/女主/反派)
- **暗钩子**: 一行环境描写 + 一句反讽金句(读者想截图)

**2025-2026新**: 章末必须有"可截图金句"(1句话,10-30字,带反讽或反差)

## 七、AI产出3大陷阱

1. **数字漂移**: 第1章余额5块,第5章突然80万 → 必须每章更新 codex

3. **反派失忆**: 反派第1章戴金链子,第50章没了

## 九、新增:2025-2026新套路公式完整列表

- 主角现代考古魂穿回古代

- 优势: 2024-2026新模板,差异化高

- 主角穿越古代拍抖音
- 适合: 抖音读者转化
- 优势: 抖音算法同步推荐

### 外卖/快递穿越 ✅
- 主角外卖小哥/快递员穿越
- 适合: 番茄小人物翻身读者
- 优势: 2025-2026爆款公式

### 系统流(历史+系统融合) ✅
- 历史背景 + 现代系统
- 优势: 系统感给历史带来爽感

### 家族百年传承 ✅
- 多代时间线 + 祖辈遗志
- 优势: 群像长篇稳定

### 古代直播间+直播间观众互动 ✅
- 创新型,2025-2026头部实验
- 风险: 玩法要稳
