## 零、2025-2026 历史分类关键趋势(必读)

### 0.1 番茄 2025-2026 新头部特征
- 1万字签约生死线 = 头 10 章必有强烈钩子
- 章节读完率高 = **不写大段背景介绍,直接进冲突**
- 互动率高 = **章末有"读者想骂/想笑/想截图"金句**
- 段子文奖励高 = 反讽 + 现代技法
- 神豪 + 系统流 是 2025-2026 新头部主推

### 0.2 起点 2025-2026 新头部特征
- 30万字签约 = 考验长篇稳更
- 厚重庙堂权谋 + 群像 = 起点头部主流
- VPI 追读率高 = 章末不能太松,要有"想追"钩子
- 老牌作家**转型难度高**: 烽火戏诸侯转型慢,新人作家出头

### 0.3 共享趋势(2025-2026 全平台)
- **反对赘婿老套路** = 算法降权
- **喜欢现代技法碾压** = 新派最强
- **喜欢系统流 + 历史融合** = 跨分类爆点
- **架空优于写实** = 涉政敏感降低
- **父亲的死亡悬念** = 父仇线是经久不衰的钩子

## 二、6 本 2024-2026 新头部深度评测(我能确认的)

### 评测1: 《朕》(王梓钧) ⭐⭐⭐⭐⭐ 2024-2025 架空头部
- **作者**: 王梓钧(穿越写实的稳定头部)
- **核心**: 主角穿越成明朝皇帝,从基层开始治国
- **金手指**: 主角的现代知识/记忆
- **爽点公式**: 治国难题 → 现代解 → 朝堂震惊 → 收服武将/谋臣
- **2025-2026借鉴价值**:
  - 王梓钧的"穿越治政"流派是 2024-2026 稳定头部
  - 适合起点长篇(30万字签约)
- **风险**: 王朝选择避开明清敏感(可架空化)

### 评测2:《这位御史不太正经》⭐⭐⭐⭐ 2024-2025 番茄反讽头部
- **作者**: ⚠️ 我记不清作者名
- **核心**: 主角是御史但性格反讽,讲权谋但用反讽手法
- **金手指**: 主角聪明 + 现代思维
- **爽点公式**: 朝堂陷阱 → 主角反讽 → 反派下不来台
- **2025-2026借鉴价值**:
  - 2025-2026 番茄古风+反讽头部标杆
  - 适合番茄 1 万字签约
- **风险**: 反讽力度要节制

### 评测3:《十日终焉》(杀虫队队员) ⭐⭐⭐⭐⭐ 番茄 2024-2025 大爆款
- **作者**: ⚠️ 我对作者名有印象叫"杀虫队队员",**但不确定**
- **核心**: 限时生存游戏 + 智斗
- **虽然不是历史分类,但是 2024-2025 番茄爆款的代表案例**: 高密度情节+反讽+智斗 = 番茄算法最爱
- **历史分类借鉴价值**:
  - 高密度剧情节奏
  - 反讽 + 智斗的对白模式
  - 章末钩子"读者想破解"的设定
- **不直接迁移历史**,但**叙事手法可学**

### 评测4:《规则怪谈:欢迎来到疯狂动物园》⭐⭐⭐⭐ 番茄 2024-2026 头部
- **作者**: ⚠️ 我记不清作者
- **核心**: 规则流恐怖 + 动物园副本
- **历史分类借鉴价值**:
  - "规则流"思路可迁移到历史 = "古代底层规则"(如:科举制度/职场规则/人情世故)
  - 历史 + 规则 = "古代规则怪谈"
- **风险**: 历史规则映射不能涉政

### 评测5:《我在精神病院学斩神》⭐⭐⭐⭐⭐ 2024-2026 番茄爆款
- **作者**: ⚠️ 我记不清作者名
- **核心**: 主角在精神病院觉醒 + 神魔都市(类似她在番茄)
- **虽然不是历史,但代表 2025-2026 番茄爆款公式**:
  - 反差型开局(精神病院 = 绝地/反差)
  - 系统/规则隐喻
  - 章末反讽金句
- **历史借鉴**: 借鉴"反差开局" + "绝地求生" 思路

### 评测6:《考据流历史》- 类头部(以《明朝那些事儿》转型为基础)
- **作者**: 多个(以当年明月为代表)
- **核心**: 用现代学者方法考据历史细节
- **借鉴价值**:
  - 适合起点长篇
  - 适合深度读者
  - 风险: 容易被考据漏洞拖死
- **2025-2026 状态**: 仍然有,但不是爆款主力了

## 三、3 本经典头部对比(留作对比,2025-2026非主推)

### A.《赘婿》⭐⭐⭐⭐⭐ 2011-2019 经典
- 反例教材: 2025-2026 算法降权,**不是开坑方向**。
- 学点: 前期赘婿"装普通人"手法可借鉴。
- 致命坑: 庙堂戏过长 = 读者疲劳。

### B.《庆余年》⭐⭐⭐⭐⭐ 2007-2020 经典
- 反例教材: 不适合番茄读者,适合起点长篇读者。
- 学点: 群像 + 庙堂模板 = 起点长篇稳定。

### C.《唐家三公》⭐⭐⭐⭐ 2010-2019
- 学点: 安史之乱是最好用的家国情怀底色。
- 致命坑: 涉及吐蕃等少数民族要慎重。

## 四、2025-2026 新套路公式完整列表(8 种)

### 公式1: 现代技法碾压古人(2025-2026头部主推) ⭐⭐⭐⭐⭐
- **爽点公式**: 现代技法解古人难题
- **典型**: 火药/水泥/医药/印刷/机械
- **优势**: 经久不衰
- **陷阱**: 不能太超时代(避免玄幻化)

### 公式2: 系统签到流(2024-2026新派) ⭐⭐⭐⭐⭐
- **核心**: 签到抽古代神器/物资
- **优势**: 番茄读者最爱
- **陷阱**: 系统奖励要节制

### 公式3: 直播/弹幕流(2024-2026新) ⭐⭐⭐⭐
- **核心**: 被现代人评论/吐槽
- **优势**: 双视角代入
- **陷阱**: 弹幕要节制

### 公式4: 考古/文物流(2025-2026新) ⭐⭐⭐⭐
- **核心**: 现代考古魂穿回古代
- **优势**: 海外华人题材差异化
- **铁律**: 不写流失文物的"被偷"细节

### 公式5: 抖音/短视频流(2025-2026新) ⭐⭐⭐⭐
- **核心**: 主角穿越拍抖音
- **优势**: 抖音读者转化
- **陷阱**: 不能"穿越自带手机"太离谱

### 公式6: 外卖/快递穿越流(2025-2026番茄爆款) ⭐⭐⭐⭐⭐
- **核心**: 主角是外卖小哥穿越
- **优势**: 番茄读者最爱
- **陷阱**: 不能用太现代的设备

### 公式7: 系统流+历史融合 ⭐⭐⭐⭐⭐
- **核心**: 历史背景 + 现代系统
- **优势**: 跨分类爆点

### 公式8: 家族百年传承流(2025-2026新) ⭐⭐⭐⭐
- **核心**: 多代时间线 + 祖辈遗志
- **优势**: 群像长篇稳定
- **陷阱**: 时间线容易乱

## 五、推荐开坑方向 3 个(每个明确番茄/起点算法适配)

### 🌟 方向 A: 《外卖小哥穿宋:每天亏一笔救一座城》
- **定位**: 外卖穿越 + 系统流 + 北宋
- **核心**: 主角是外卖小哥,带系统穿越北宋,用"亏一笔救一座城"刷任务
- **金手指**: 每日签到 + 任务系统(每次完成任务亏钱,但能救一座城)
- **差异化**:
  - 北宋富庶+小人物翻身 = 双向反差
  - 任务系统给"亏钱"合理性
  - 不写明清政治敏感
- **番茄算法适配**: ✅ 高(短篇爆,1万字签约)
- **起点算法适配**: ⚠️ 中(长篇 OK,但 30万字签约压力大)
- **风险评估**: 北宋安全无政治敏感

### 🌟 方向 B: 《我在考古队挖出了祖宗》 ⭐⭐⭐⭐⭐
- **定位**: 考古流 + 家族百年传承 + 现代化笔记
- **核心**: 主角是现代考古队员,挖到一个古墓 → 觉醒家族百年传承
- **金手指**: 主角爷爷留下的"家谱"实时更新(每完成一个祖辈任务解锁新能力)
- **差异化**:
  - **双线结构**: 现代考古线 + 古代家族线(群像)
  - 适合起点长篇(30万字)
  - 适合多代群像读者
- **番茄算法适配**: ⚠️ 中(适合长篇集,不爆发)
- **起点算法适配**: ✅ 高(适合长篇稳更)
- **风险评估**: 涉及"祖辈"线索可架空处理
- **可写朝代**: 唐/宋/明初最稳

### 🌟 方向 C: 《这位御史说话太损,但皇帝爱听》 ⭐⭐⭐⭐⭐
- **定位**: 古风反讽 + 庙堂 + 御史(模仿2024-2026头部《这位御史不太正经》)
- **核心**: 主角是御史但反讽风格,在朝堂用段子和权术并存
- **金手指**: 主角现代人,有"现代嘴"(反讽)但有古代察举制保障
- **差异化**:
  - 番茄反讽风 + 起点庙堂权谋 = 跨平台
  - 朝代:宋(清议制度最活)
- **番茄算法适配**: ✅ 高(反讽 + 段子)
- **起点算法适配**: ✅ 高(权谋 + 长篇)
- **风险评估**: 宋朝安全,御史+清议制度有史实依据
- **金句储备**: 主角说话要"损但不毒"
