# 章节文件命名规范（2026-07-29 焊死）

## 规则
所有章节文件名必须使用 **三位数零填充** 格式：

```
<书名>_第NNN章_<标题>.md
```

## 示例
```
末日便利店_第001章_死在门口的男人.md
末日便利店_第002章_找零不能给.md
...
末日便利店_第010章_玻璃门上的新规则.md
...
末日便利店_第120章_卷四终局：末日结束.md
```

## 为什么
不零填充时，`ls`按字母排序会变成：
```
第1章 → 第10章 → 第100章 → 第101章 → ... → 第11章 → ...
```
零填充后排序正确：
```
第001章 → 第002章 → ... → 第010章 → ... → 第100章 → ... → 第120章
```

## 铁律
1. 从 Ch1 开始就用 `第001章`，不能等后面再补
2. 最大章节编号为 999（3 位数），超过 999 章需升级为 4 位数 `第1000章`
3. 修改文件名后必须同步更新 `outline/设定.md` 中的章节表格
4. 本规范适用于所有书
