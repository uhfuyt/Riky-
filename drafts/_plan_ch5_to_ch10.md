## Ch5 派出所一日游 (800字)

**时间**: Day 3, 09:00-15:00
**主线**: 派出所为母亲转1万元报警线服务 → 主角花冤表演 → 警察震惊 → 母亲必须来深圳
**字数**: 800字(细纲目标)

**前置事实锁**:
- Ch4 末: 转1万给母亲 → 返5百万 → 母亲以为是诈骗, 准备明早坐大巴来深圳
- Day 3 角色: 警察(新增)、顾行舟、钱小宝(陪同)
- 系统状态: Lv.2 500x, 日限10万, 累计花586万, 卡1001万+11.75亿待补

**Ch5 主线流程** (单章单事件):
1. 09:00 母亲到蛇口派出所报警"儿子可能被骗/被传销"
2. 09:30 主角接到派出所电话 → 主角 + 钱小宝去
3. 10:00 主角母亲视频: "行舟!你跟警察说清楚!"
4. 10:30 主角向警察"演示花冤" → 现场给张大爷便利店补5000块水电费 → 5000×500x = 250万秒到账
5. 11:00 警察惊呆 → 教育"涉嫌诈骗" → 主角出示转账记录+华强北便利店+银行流水
6. 11:30 警察叔叔:"小伙子你可能真没事,但你妈得亲自来当面确认"
7. 12:00 主角答应接母亲 → 母亲在电话那边长舒一口气

**数字校验**:
- Ch5 花销: 5000 + 午饭打车200 = 约5200元 (日限10万内)
- Ch5 返利: 5000×500 + 200×500 = 250万 + 10万 = 约260万
- 累计花销: 586万+0.52万 = 约586.5万
- 累计返利: 11.75亿+260万 ≈ 11.78亿
- 卡余额: 1318万+260万 ≈ 1578万
- Lv.2 500x 不变

**爽点**:
1. 警察惊呆 (1个)
2. 主角现场表演花冤 (反向打脸)
3. 主角决定接母亲来深圳 (温情+爽)

**钩子** (细纲明示):
- 母亲必须来 → 推动 Ch31 实际见面 (但细纲说 Ch5 后是 Ch6 租办公室,中间会跳)
- 警方"教育"已销案,不再找主角 → 主角能继续花冤

**母亲对话规范**:
- 用全名"顾秀芝"出现至少1次
- 不用"芝"或"秀芝"缩写

## Ch6 租办公室 (800字)

**时间**: Day 3 下午 14:00-18:00
**主线**: 主角决定开公司 → 福田CBD找办公室 → 押一付三200万 → 房东以为是诈骗 → 主角刷怀表演 → 签约

**前置事实锁**:
- Ch5 末: 警察销案, 主角可以安心花冤
- Ch5 数字末态: 卡1578万, 累计586.5万花, 累计返利11.78亿
- 怀表提示: 累计花销586.5万 → 距Lv.2升级(累计10万) 已超 58倍!?? 

**等等**, 番茄 codex 显示:
- Lv.1: 单日花满日限(1万) × 3天
- Lv.2: 累计花销≥10万, 升级后日限10万

但 Ch2-4 累计花销已经是**85万+1万+5000=86.5万**,远超 10万阈值. **矛盾!**

**修正逻辑**: 番茄细纲 setting 提到"累计花销≥10万"是 Lv.2 条件,但**用户已上传的 Ch1-3 是按"单日花满日限×3天"升级逻辑跑通的**. 矛盾处理: **以已上传 Ch3 末段为准** = "Day 3 16:42 升级 Lv.2 / 500x / 日限10万". **Ch5 末我们已经站在 Lv.2**. Ch6 也保持 Lv.2.

**Ch6 流程**:
1. 14:00 主角"+钱小宝"去福田CBD看办公室
2. 14:30 找到一栋甲级写字楼 → 房东要"押二付一"120万/600平/月租
3. 15:00 主角签合同 → 转账120万 → 系统判定"商业投资+花冤" → 120万×500x = 6亿 (日限10万,当天到账10万+5.99亿待补)
4. 15:30 房东以为诈骗 → 主角现场刷 → 银行短信10万+待补6亿 → 房东震惊
5. 16:00 签约 + 主角拍板:"这楼以后是我'破财转运'总部"
6. 17:00 主角贴招聘启事 (细化, 接 Ch3 已贴的便利店版)

**数字校验**:
- Ch6 花销: 120万 (押一付一,押一付三 → 这里用"押一付一"简化,200万封顶不超 Lv.2 日限? 不行,日限10万)
- **重新设计**: 押一付一 = 12万×... 实际上押一付一6万月租?
- 改用: "押一付三" = 押1+付3 = 4个月 = 4×6万 = 24万 → 主角付了24万
- 24万×500 = 1.2亿 → 日限10万 → 当天到账10万+1.19亿待补
- **修正后**: 押一付三24万 (Lv.2首次合理)

**爽点**: 24万→1.2亿 (1个, 装比)
**钩子**: 招聘启事贴出去 (接 Ch7 钱小宝拜师), 主角决定招人花冤
**母亲对话**: 不出现
