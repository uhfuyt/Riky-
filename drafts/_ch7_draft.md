## 二、Ch7 设计 (按细纲 Ch6-15 单王之路节奏, 但主角已升级)
**时间**: 7月7日 09:00-15:00 (大半天)
**Day-N pacing**: 单章单 Day, 单章单主线, 单章 1-2 个爽点

### 主线: 一个"小亏"事件
主角不再是外卖员, 但**"亏得冤"体质**还在. 设计一个**主角的日常/事业场景里的小亏**, 引出**Lv.3 副作用的隐约预兆** + **王大龙的反扑伏笔**.

### 候选主线 (择一):
**A. 主角去春风帮扶会"踩点"** (法人母亲何秀兰, 江城资本圈慈善机构, Ch45 才出现 — 时序太晚, PASS)

**B. 周映雪江城日报结果 + 王大龙反扑** (爽点足, 但跟 Ch6 末段"周映雪明天去谈"重复)

**C. 主角去汉庭府开个小差** — 周映雪/江城日报的事已交给她, 主角**回美团雨花区站跟张德彪对峙**, 因为他已经"富有"但张德彪还当他是小骑手. 这条最合细纲 Ch6-15 的"张德彪从嫌弃到怀疑"节奏.

**D. 一个新反派登场**: 王大龙的真正发力是 Ch15 派人砸电动车, Ch16 美团检查组. Ch7 应该埋伏笔不爆发. 

### 决定方案: **C + D**
主角 7月7日 9:00 起床, 想起昨晚睡在汉庭府套房(Ch6 末段暗示), 去美团雨花区站处理"退工"手续(他不要外卖员身份了). 张德彪还在嚣张. 主角懒得理, 但走时因为"规矩"赔了张德彪 5000块"误餐费补偿" — 系统判定"花冤" → 返 25万. 单爽点.
然后主角回汉庭府, 周映雪来汇报江城日报头条情况 — 但**她带了一个坏消息**: 王大龙**今早 7 点已经把王氏建材 100% 股权转给他爸王建国, 自己净身出户** — 主角的反诉打不响了.

### 数字校验:
- 主角前 1.3亿不动
- 7月7日花 5000 → 系统判定花冤 → 5000 × 50x = 25万 (日限额 50万以内全额到账)
- 累计花销: 1,220,595 + 5,000 = 1,225,595
- 累计返利: 14,661,900 + 250,000 = 14,911,900
- 等级: Lv.3 50x ✅ 不变
- 今日已花: 5000 / 日限Lv.3 = 100万 / 5000 → **今日剩余 99.5万**

### 钩子: 王大龙"净身出户"伏笔
- 字面: 王建国 (王大龙他爸) 突然成了王氏建材唯一法人, 主角要"反诉"的对象"消失了"
- 暗钩: 王大龙的反扑从"商业"转向"暴力" → Ch15 砸车 / Ch16 突击检查 / Ch25 收买苏婉清家暴
- 主角态度: "让他去, 我继续亏我的钱"

### 爽点:
1. 主角 5000 → 25万 (跟 Ch1 末"200变2000"同款, 但数字升级)
2. 张德彪跪送主角出门 (Lv.3 资产 1.3亿 / 主角决定 1.3 亿当外卖员"回退"到 0, 反讽)
